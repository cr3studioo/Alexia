- `DeviceRow` and `GuestRow` in `types.rs`, re-exported through the existing `pub use types::*`. `mod devices;` added in `lib.rs`.
- Choices the spec left open (each is written in the doc comments):
  - `device_put` replaces a row that has the same endpoint *or* the same id. It always stores `revoked_at = NULL`.
  - `fallback_mark` uses `INSERT OR IGNORE`. A second mark does nothing and the first `local_id` stays.
  - `guest_add` refuses any `code_hash` that is not 64 lowercase hex (`Error::Invalid`), so a raw code cannot be stored by mistake. `sha2` is not a store dependency, so the caller hashes the code.
  - `guest_claim` returns `Error::Refused` when a live guest already holds that chat; the code stays unspent. A removed guest's old chat is released, so the same person can be added back.
  - `guest_remove` also clears an unused code hash.
  - `guests()` returns guests that are not removed, oldest first.
  - `device()` and `device_by_endpoint()` also return revoked rows; `revoked_at` says which.
