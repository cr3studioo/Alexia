# P1-12 report

Status: done

What I built:
- `ask.rs`: `Asker::confirm` asks in the chat the turn came from (the channel whose `name()`
  matches); a scheduler job asks in the first channel's primary chat; Desktop, an unknown
  channel, an error, deny or no answer is false. Only `Some(true)` is true. The question text is
  `text` plus `"\n\n" + detail`. It waits at most 10 min (v2 `ANSWER_WAIT`), then cancels the ask
  and says "— no answer, so I didn't".
- `voice.rs`: `hear` adds each `audio/*` file's transcript to the content as if typed, or the
  honest "[a voice note I couldn't listen to: ...]" line on `Ok(None)` or an error (logged). The
  files stay in place. `wants_voice` reads kv `_core/voice_replies` (always / never / mirror,
  default mirror). `speak` returns only an `audio/ogg` note and skips texts over 1 000 chars.
