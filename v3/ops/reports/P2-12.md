Problems or doubts:
- The spec says the mode is in `_core.mode`. In v2 the permission mode actually lives in `_core.scope.mode`
  (serve.ts `scope()`), and `_core.mode` holds the compute mode (`combined`/`local`). `scope()` reads
  `scope.mode` first and falls back to `_core.mode` only when that is one of the four permission names.
- `paths_in` counts `\x` and `/x` as absolute on Windows, the same as Node's `isAbsolute`.
- The symlink test makes a junction with `cmd /C mklink /J` on Windows (this needs no admin rights)
  and a symlink on Unix. The dangling-link test checked to fail without the fix, pass with it.
