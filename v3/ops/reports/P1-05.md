Fixes this round:
1. Invariants: the OCR filter is now a whole-segment match on the id with separators turned
   into `-` (`-ocr-`), not a bare word entry. `node v3/ci/invariants.mjs` prints ok.
2. Seeds: all of v2 `SEEDED` ported (ovhcloud 6, aihorde 3, nara 3, cloudflare-ai 1). Rule:
   per provider, the seed comes first, then fetched/cached rows minus seeded ids (v2
   `Catalog.models`, seed wins on a clash). A seed is offered unless the provider's last
   `models()` was NeedsKey/Refused; a key-only row's seed waits until `models()` answered Ok
   (a no-list row answers Ok(empty) only when built with a key). Keyless rows are seeded
   from boot. Down leaves the last answer standing.
3. `chats` also drops `orpheus` (groq TTS), `veo` (google video) and any id containing
   `guardian`. Test cases added for each.
4. Refused drops a provider's cached entries like NeedsKey (test: `refused_key_drops_cached_entries`).
5. Temp file is `<file>.<pid>-<counter>.tmp` (test: `concurrent_refreshes_do_not_collide`).
