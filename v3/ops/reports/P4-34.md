Status: done

What I built:
- `agent.rs` gate: rule → proactive (scheduler) → local_only → guest, on every call. The audit
  row's gate is `local_only` when local-only blocked it, and `guest` for every guest call.
- `guest_turn(store, origin)`: the primary chat is the owner's; a live guest row is a guest; a
  store error (primary or guests) is a guest called "someone". Calls `Store::guest_of` directly,
  not `permissions::guest_of`, because that one folds a store error into "not a guest".
- Guest turn: `GUEST_PROMPT` (const in agent.rs, owner from `_core.display_name`, else "the
  owner") plus the guard line; no profile, personality, context or standing lines are read; the
  model is offered only `scope.guest_tools`; the checker is skipped (it could ask); a call to an
  unknown tool gets `GUEST_BLOCKED`, not "plugin removed".
- Guest args: any key named path/file/dir/folder (by word, so `filePath`, `out_dir`) or any
  string that looks like a path (slash, backslash, `~`, `C:`, `name.ext`; http(s) URLs allowed)
  blocks the call.
- `capture()` returns early for a guest, so both lanes skip memory (chat.rs calls it too).
- A guest's `/…` is text, not a command (a guest could otherwise `/approve` the owner's asks).
