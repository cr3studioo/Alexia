# P2-62 report

Status: done

What I built:
- `McpHost::start` learns plugin ids via kv `_core`/`known_plugins`. If the list is absent (first run), every id found is recorded as known and none is marked unreviewed. If it exists, new ids are appended to `_core.unreviewed` first, then to `known_plugins`. If it is unreadable or malformed, nothing is written and a warning is logged.
- `tools()` treats an unreadable or malformed `known_plugins` as everyone unreviewed (fail closed).
- `McpHost::set_reviewed(id, bool)` edits `_core.unreviewed`. Read and parse errors are returned and the list is not overwritten.
- `McpHost::hold(ids)` / `release()`: there is a held set, and `ensure_running` checks it under the plugins and spawn locks, so it covers calls, capability calls, lazy spawns, supervision respawns and reload respawns. A held plugin gives `Off { "<name> is paused while a game runs." }`. `call_capability` skips held providers and returns the paused sentence only if no other provider and no core fallback answers.
- `gpu::GpuEvent { StepAside { procs }, GameOver }`. `Watch::run(cancel, mpsc::Sender<GpuEvent>)` sends the process list it decided on, and ends when the receiver is closed, even while it has nothing to send.
