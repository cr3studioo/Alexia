Problems or doubts:
- `sqlite-vec = "0.1.6"` resolved to 0.1.9 in the lock; builds fine on MSVC.
- The foreign-file check runs before the newer-schema check (spec lists them the other way). A v2 file
  has app_id 0 and user_version 11, so checking newer first would tell the owner it is "from a newer Alexia".
- WAL is switched on only after the checks pass, so a refused file is left untouched.
- `record_request` also prunes older buckets of the same span, as v2 does. v2's third span (`month`) is not
  recorded: the spec names only minute and day, and the table accepts it later without a migration.
- Tests use `std::env::temp_dir()` folders instead of adding a `tempfile` dev-dependency; they are not
  deleted afterwards (Windows holds WAL files until drop), only cleared at the start of each run.
- `sessions_and_history` sleeps 5 ms so the ordering is decided by `updated_at`, not by an id tie-break.
