What I built:
- `tests/security.rs`: ten adversarial tests against real ephemeral nodes. There are three
  nodes, hub H, limb L and stranger S, plus a second limb L2 where it is needed. Each test
  asserts three things: the refusal, the layer that refused (via `x-alexia-connect-error`
  present or absent), and that the target's `on_link`/`on_op` callback was never called.
- A tracing subscriber inside the test file that captures every crate at debug. A new
  dependency was not allowed, so there is no tracing-subscriber.
- `src/pair.rs` (the spec allows this): `settle` checks `cancelled()` again after `device_put`
  and before the allowlist sync. A cancel that raced the row write now revokes it. The
  parameter is renamed `id` → `pairing` so it is not shadowed.
- `v3/ops/reports/P4-mesh-security.md`: the encryption, what crosses, the keychain services,
  what a stranger or a relay sees, a table of every test and the layer that refuses, and what
  is not covered.

Problems or doubts:
- `revoked_limb_is_cut_within_1s` holds both link ends to the spec's 1 s, measured from the
  start of `revoke`. That is the one tight bound and could flake on a very loaded machine.
- `no_secret_in_logs` cannot read the host secret. It fails on any run of 64 or more hex
  digits that is not a known endpoint id. If iroh logs some other 64-hex value at debug, the
  test fails falsely; the failure message prints the line.
- The global subscriber also sees the other tests' logs in this binary. Every node's endpoint
  and secret is registered in `start()`, so that only makes the check stricter.
- `serve_ops` does not check the node's own role. It is not reachable through pairing, so I
  did not escalate it; it is listed under "Not covered" in the security report.
- `limb_role_cannot_serve_ops_to_a_limb`: a limb registers no ops. connect refuses these
  requests (`peer_rejected`, then `operation_not_registered`), not a role check. The test
  shows the role check on L2's link path instead.
- The cancel-race test cannot force the exact window every run. It asserts the final state
  (no allowed device), which holds on every interleaving.
