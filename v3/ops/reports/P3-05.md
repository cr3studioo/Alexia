# P3-05 report

Status: done

What I built:
- `McpHost::call_capability_all(cap, args, ctx, per_call)` in `host.rs`: every enabled,
  not-refused/unhealthy, not-held provider of `cap`, called concurrently (`JoinSet`), each
  within its own `per_call`; errors, `isError` and timeouts dropped and logged at warn with the
  plugin id and an error kind only; output in resolution order (plugin id, the same order
  `call_capability` uses), not completion order. No provider → empty Vec. No core fallback.
- Helper `provide_one`: the lazy start (`plugin_tools`) runs in its own task, so a cold start
  that outlasts `per_call` is not dropped half way and is warm next time. The call uses
  `call_tool_within` with the time left (its own timeout sends `notifications/cancelled`),
  with a 250 ms backstop on the wait.
- `mcp-fixture` mode `provide`: `--cap/--answer/--delay-ms/--fail`, or `FIXTURE_PROVIDES`,
  `FIXTURE_ANSWER`, `FIXTURE_DELAY_MS`, `FIXTURE_FAIL=1` (args win; `FIXTURE_PROVIDES` with no
  mode means `provide`). The delay checks for cancellation.
