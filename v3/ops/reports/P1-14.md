# P1-14 report: v2 parallel tool calls (SP-16)

Status: done

What I built:
- `run()` in `packages/core/src/agent.ts` now handles a turn's calls in two passes.
  The gate pass goes one call at a time in the model's order: stop check, ceiling, `Step`,
  `on.step`, `on.phase`, then the guard and approval (one question at a time).
  The run pass starts every allowed call together with `Promise.all`. Refusals are already outcomes.
- `on.done` fires as each call finishes. Tool results go to `messages`, `added` and the store in call order.
- Ceiling inside a turn: the calls that fit run, then `finish('ceiling')`, as before.
- `permitted()` is split into `rule()` (gate) and `act()` (call). Nothing else called `permitted`, so I removed it.
- One call per turn behaves exactly as before, including `alexia/final`.

- packages/core/src/agent.ts
