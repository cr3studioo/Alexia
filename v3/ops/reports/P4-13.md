Status: done (built with cargo check; tests not run, see below)

What I built:
- `tools.rs`: list-time merging of `(<plugin>, <tool>)` across the hub and limbs into one tool `<plugin>__<tool>`
  with a `device` enum (hub + devices not `Stopped`) and the description "Which computer. Leave out for the one the owner is using."
- Schema = the hub copy's, else the first device's. Annotations are merged cautiously (destructive/open world if any copy is;
  read-only/idempotent only if all are; a hint every copy leaves out stays out). `reviewed` only if every copy is.
- A tool only one limb has keeps `<device>__<plugin>.<tool>`. Builtins are untouched.
- Call routing: `device` is stripped; `"hub"` goes to the local plugin, a device id to that server; with no device,
  `McpTooling::set_prefer` (same closure shape as `McpHost::set_prefer`) picks among online copies by the first `alexia/provides`
  entry, else the hub copy, else the first online. An unknown device fails with "X is not on Y. It is on: ...".
- `McpTooling::target(name, args)`: the resolved real id (`laptop__files.write` / `files__write`) for permissions and the silent list.
- An undo from a merged tool is named as offered and pinned with `device` to the copy that ran. The old `callable` is folded into this.
