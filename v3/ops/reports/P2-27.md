What I built:
- `Helpers` builtin (`helpers.run {tasks:[{goal}]}`, 1..=4 tasks, else refused with "1 to 4").
- Each helper: new session "Helper: <goal>", Task with parent = ctx.run, origin/background from ctx,
  max_steps = limits.helper_steps, run id "<parent>.h-<ms>-<n>" (unique across restarts). Run in a JoinSet under child cancel tokens.
- A failing helper becomes "could not finish: <why>"; the others still answer.
- Output: "Helper N (<goal>): <answer or why it stopped>" sections, joined by blank lines.
- Depth 1 is read from the store: a run whose live_runs row has a parent is a helper (survives restarts); no in-memory set.
- Sessions are made first; if any step fails, those already made are deleted and nothing starts.
- Sessions this module makes carry an invisible lead mark (U+2063); the 30-day sweep deletes only marked ones.
