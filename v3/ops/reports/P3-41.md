What I built:
- `quiet.rs`: `Proactive.unreadable` (`#[serde(skip)]`, default false) and `UNREADABLE_RETRY_MS = 60_000`.
  `load` parses field by field. A malformed field keeps its default and is logged by name only.
  A malformed `quiet`/`paused_until`, a non-object value or a kv read error sets `unreadable`.
  `save` returns Err(Invalid) when the config is unreadable. `gate_in` holds anything below Urgent for 60 s when it is unreadable, so job replies hold through `hold_until` and `lib.rs` is unchanged.
- `decide.rs` rule 5: `cfg.unreadable && u < Urgent` gives `Hold { now + UNREADABLE_RETRY_MS }`, before the pause and quiet hours.
- `notices.rs` `dispatch`: when the mutes read errors, the pass returns `Some(now + 60 s)` before anything is decided. The warn line logs the error kind only (new helper `quiet::error_kind`).
