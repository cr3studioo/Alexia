# P3-34 report (fix round, try 2)

Status: done

What I built:
- First round: `screenStateScript`/`windowsState`/`screenState` (windows.js), `screenStateScript`/`macState`/
  `screenState` (macos.js), `sameMoment` (moment.js), `structuredContent` in the `screenshot` handler, screen-check.mjs.
- Fix 1: the Windows probe prints `ConvertTo-Json` output with every non-ASCII UTF-16 unit escaped as `\uXXXX`
  (regex replace in PowerShell, then `Write-Output`). The pipe carries only ASCII, so the OEM code page cannot mangle it.
- Fix 2: new `lockedFrom(dict)` in macos.js, pasted into the JXA probe via `toString()`. A missing
  `CGSSessionScreenIsLocked` means unlocked only if the dictionary has `kCGSSessionUserIDKey` or `kCGSSessionOnConsoleKey`.
  Otherwise the result is `null`, and `macState` treats that as locked.
- Fix 3: `PROBE_TIMEOUT = 10_000` on both OSes. `screenState(signal, timeout)` races the run against an abort that
  fires at the deadline or on the caller's abort. It answers `{locked:true}` even if the child never exits, and it aborts the child.
