# P2D-18 report

Status: done

What I built:
- task.js `following().openUrl`: reads `front()` before opening (pid A), opens, then polls `front()` every 250 ms for up to 5 s (honours the abort signal) until a pid other than A is in front; that pid is the target. Answers `{ known }`.
- If nothing changes: A is the target only when A's process is a browser (`BROWSERS`: msedge, chrome, firefox, brave, opera, vivaldi, arc, safari; also matches `Google Chrome`, `Brave Browser`, `Microsoft Edge`, `.exe`). Otherwise the target is `UNKNOWN` (pid -1). With no reading of A, nothing counts as changed.
- `UNKNOWN` is refused inside `following()` before anything reaches the desktop: `type`, `key`, `click`, and new `look`, `press`, `scroll` reject with "I could not tell which window the page opened in, so I did not …". This is needed because windows.js treats pid -1 like "no pid" (unguarded, foreground window).
- runTask: an `open_url` that ends with `UNKNOWN` gets the detail "The page opened, but I could not tell which window it is in, so I will not type into it." and the plan hands back there, with the remaining steps, so nothing reads or acts on the window in front.
- index.js (coordinator approved): run_task's `look`, `press` and `scroll` now go through `win.look/press/scroll`, so they also refuse in the `UNKNOWN` state instead of using the foreground window. Same behaviour otherwise.
- replay.js: not changed. Its `open_url` never re-targets.
