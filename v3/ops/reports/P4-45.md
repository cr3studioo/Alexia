# P4-45: Bind the clipboard and file-courier tools to their capabilities

Status: done

## What I built
- device-clipboard: `clipboard_get`, `clipboard_set` and `clipboard_history` each bind their one capability through `_meta['alexia/provides']`, only where there is a clipboard backend (Windows, macOS). `clipboard_clear_history` binds nothing (no such capability is declared).
- file-courier: `file.stat`, `file.read_chunk` and `file.write_chunk` each bind their one capability, always (the file system is always there).
- A test in each plugin starts it over stdio, lists its tools and compares the bound capabilities with plugin.json `provides`.
