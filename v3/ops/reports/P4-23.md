What I built:
- Security 1 (git): read-only git runs as `git --no-pager <cmd> --ignore-submodules=all` (log/diff also `--no-ext-diff --no-textconv`). Its env sets GIT_CONFIG_NOSYSTEM, GIT_OPTIONAL_LOCKS=0, GIT_NO_LAZY_FETCH, GIT_PAGER=cat and GIT_CONFIG_KEY_n overrides: log.showSignature=false, gpg/openpgp/ssh/x509 program=git, core.fsmonitor=false, core.hooksPath=/dev/null, core.pager=cat, diff.external empty, format.pretty=medium, submodules off. The repo picks the names of filter and diff drivers, so `shell.js` first runs `git config --list -z` (directly, no shell, same env) and blanks every filter.X.clean/smudge/process, diff.X.textconv/command and pretty.X. If that read fails, nothing runs. The classifier refuses --show-signature, `%G` formats, --submodule, --ignore-submodules, --git-dir and the rest, also when shortened.
- Security 2 (install): installs only on an exact id or name match (case-insensitive). Otherwise it refuses and lists up to 5 hits, each with its publisher from `winget show`. `software_install` takes `publisher`, so the publisher is in the call the owner approves. If `publisher` is missing or wrong, nothing is installed and the answer names the real publisher. If the publisher is unknown, the install never happens. The same check applies to brew (the tap).
- Security 3: a network path is refused anywhere in the command: `[\\/][\\/]` in any mix and `\??\`.
- watch.js: the read position moves only past the bytes read (at most 1 MiB per poll) and reading carries on at the next poll. A StringDecoder keeps a UTF-8 character that a read cuts in two whole.
- software.install is bound on every system. On systems other than Windows and macOS it answers "Installing programs is not supported on this computer's system (<os>)...".
- brew paths are built with `path.join(sep, ...)`. Invariant 07 passes.
