Problems or doubts:
- Every Blocked becomes GUEST_BLOCKED, including the never-touch one and spoken boundaries. I did
  this on purpose so a guest never hears the owner's paths or words. The cost: P4-34's logs lose the
  real reason unless it logs `rule`'s ruling before calling `guest`.
- `guest_of` returns None on a store error (the fixed signature has no "unknown" answer), so a
  failed read treats the chat as not-a-guest. It is logged. P4-33/P4-34 should not count "not a
  guest" as "the owner" on their own; the owner's chat should be recognised positively.
- In Ask-risky mode a listed write tool that is not destructive is Blocked for guests, because
  `rule` asks for it. So in practice only read-only tools run for guests unless the mode is Full
  trust or Watch. That matches "never Ask", but the owner may expect otherwise.
