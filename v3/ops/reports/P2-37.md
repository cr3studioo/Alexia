# P2-37 report
Status: done

What I built:
- rusqlite `bundled` → `bundled-sqlcipher-vendored-openssl`, workspace-wide.
- `encrypt::encrypt`: refuses a missing file, an already encrypted file, or an existing
  `_core.store_key`. Takes an exclusive lock with busy timeout 0, so a running hub is refused.
  Then a 32-byte `getrandom` hex key and a raw-key `sqlcipher_export` into `alexia.db.enc`, with
  user_version and application_id copied. Every table's row count is checked. Then a hard link
  `.plain`, an atomic rename, and a best-effort zero-then-delete of the plain file and its -wal/-shm.
  Any failure before the swap deletes the key and the `.enc` file.
- `Store::open`: an encrypted file, or a new one while a key exists, gets `PRAGMA key = x'…'`. A
  missing, non-hex or wrong key returns the spec's sentence. An existing plain file opens as it is.
- `Store::is_encrypted`: the file does not start with "SQLite format 3\0". A missing, empty or
  non-file path (`:memory:`) counts as not encrypted. import.rs: `ATTACH … AS v2 KEY ''`.
