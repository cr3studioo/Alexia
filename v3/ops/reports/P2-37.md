# P2-37 report

Status: done

What I built:
- rusqlite `bundled` → `bundled-sqlcipher-vendored-openssl`, workspace-wide.
- `encrypt::encrypt(path)`: refuses a missing file, an already encrypted file, or an existing
  `_core.store_key`. Takes an exclusive lock (busy timeout 0, so a running hub means "The database
  is in use. Stop the hub, then encrypt it."). Then a 32-byte `getrandom` key, stored as hex, raw-key
  `sqlcipher_export` into `alexia.db.enc`, user_version and application_id copied, a row-count check
  on every table, a hard link `alexia.db.plain`, an atomic rename over `alexia.db`, then the plain
  file and its -wal/-shm are zeroed and deleted. That last step is best effort, as the doc says.
  Any failure before the swap deletes the key and the `.enc` file.
- `Store::open`: an encrypted file, or a new one while a key exists, gets `PRAGMA key = x'…'`.
  A missing, non-hex or wrong key returns the spec's sentence. An existing plain file opens as it is.
- `Store::is_encrypted`: the first bytes are not the "SQLite format 3\0" header. A missing, empty or
  non-file path (`:memory:`) counts as not encrypted.
- import.rs: `ATTACH DATABASE ? AS v2 KEY ''`.
