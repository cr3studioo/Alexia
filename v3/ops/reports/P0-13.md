- Where v2 and the spec differ, I followed the spec: `alexiaProtocol` = ALEXIA_PROTOCOL_MAX (v2 echoes the manifest's), `cacheDir` = cache/<id> (v2: a shared cache/), the -32050 sentence. Other error wording follows v2.
- Also matches v2: settings get/set include panel widgets (D86); compute/run and attachments/* check permission first (-32051).
- The shape of `_core/provenance` is not specified anywhere. I read `{<id>: {"installed_at": ms}}`; anything else falls back to id order.
- An `alexia/*` request holds a strong host reference while it is served, so a long capability call keeps the host alive until it ends.
- `purge` does not switch the plugin off. A later call would respawn it and recreate its own folder; switching it off is the caller's job.
