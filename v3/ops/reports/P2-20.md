- Step 0 (own commit 56aba01): `Agent::new`, `store`, `host`, `set_local_jobs` (OnceLock, second set warns), `local_jobs`; `host` on AgentParts; `steer`/`steps_done` on Task.
- The loop, ported from v2 `run()` and serve.ts `gate`. Each step re-lists tools, checks for struggle, builds the prompt via `prompt::system` (personality, profile and `context.current` read once per run through `caps`), runs `see_before_cloud`, trims to the first ranked candidate's window, then `Router::step` with Job::Plan/Step.
- Two-pass gate/run (SP-16): calls are gated in the model's order (scope read fresh each call, Ask → `ask.confirm`, the checker in Watch mode with a per-session tally), then the allowed calls run together in a JoinSet and results are stored in the model's order. Tool output is fenced with `prompt::untrusted` (TR-12). One audit row per call.
- Struggle (looping/stuck/spinning/grinding, latched once): the next plan avoids the struggling model, only if another candidate exists. Notes use v2's WHY lines. The free-failing note (B9) has no paid suggestion.
- At the ceiling, every dangling call is answered "not run: step limit reached" and a short assistant line is stored. Stop keeps the written text with `stopped: true`. `alexia/final` ends the run without another model turn. Bad JSON arguments become `{}`.
- Spoken boundaries are checked with heard/lifts before the run; a new one is saved and `boundary_ack` added as a note. Steer messages are read between steps, and also after a final answer, then the loop continues with them.
- Resume: `Trace::resume`, steps count on from n, and the ceiling bounds the total. Resuming without a run id is a BrainError.
- Brain::reply: a command goes to `commands::run`; otherwise the user turn is appended, a Task built from history, and the result mapped (Stopped → Cancelled, Refused → Unavailable).
