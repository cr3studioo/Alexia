What I built:

- Gateway hands the brain the merged inbound files minus `audio/*` (voice notes are already text).
- `Lanes`: a turn with any file goes to the task lane, checked before `lane(&content)`.
- Bridge `uploads(&Turn)`: image parts, then each file read with `tokio::fs::read` as
  `{ name, data: STANDARD base64, type }`; unreadable or >20 MB files skipped with a warn (name, size).
- Bridge stores the assistant row only when v2 wrote words; no words → user row + `Err(Unavailable(NO_REPLY))`;

  is cancelled and the prefix (without them) is cached. Blank replies store nothing, send no capture, return
  `Err(Unavailable(NO_ANSWER))`; `relay` skips the final flush on blank text.
