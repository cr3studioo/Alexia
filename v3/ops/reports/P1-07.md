# P1-07 report

Status: done

What I built:
- `lane(&Content) -> Lane` in `alexia-core/src/lane.rs`: rules only, no model. `/` gives Command;
  an image part, a URL, more than 400 chars or more than 3 lines, or a listed word/phrase at a
  word boundary gives Task; otherwise Chat. The word list covers the spec's English and Czech
  words plus the rule-5 questions; "did … reply" is a separate check. Curly apostrophes are
  normalised, so "what’s on" matches.
- `Lanes { chat, task }` implementing `Brain`. Chat goes to the chat brain, and on `NeedsTask`
  the same turn and draft go to the task brain. Command and Task go to the task brain.
  `Reply.spans` = `lane`, then `chat-escalated` (time the chat brain spent) when it escalated,
  then the inner brain's spans. Lanes checks the cancel token before any brain call and again
  before escalating.

Problems or doubts:
- `Reply.lane` for a `/command` is `Command`, even though the task brain answers it. The spec
  says "the lane that actually answered". Commands keep their own label so the dashboard can
  tell them apart. Change it to `Task` if that is wrong.
- Word boundaries are strict ("files", "running", "reopen" do not match). Czech inflections
  (e.g. "připomeňte") are not matched either, and escalation catches them. Words like "make"
  and "call" will sometimes send plain chat ("that makes sense" does not match, but
  "make sense" does) to the task lane. They are kept because the spec lists them.
- `now()`/`span()` helpers are duplicated from catalog.rs/chat.rs (private there; those
  files were off-limits).
