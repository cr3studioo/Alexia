What I built:
- `fit`: v2 `fit.ts` maths (KV cache padded to 256-token slots +10%, overhead max(1 GiB, 15% of weights)). Budget = min(free, total) VRAM minus headroom. Fits (10% spare) / Tight / TooBig; TooBig offloads as many whole layers as the budget holds (0 if none).
- `machine()` / `processes()`: `nvidia-smi` query-gpu, query-compute-apps and `-q -x`. Also tried by full path (v2's PATH lesson). Missing or failing gives `None`/empty, with one warning logged.
- `game_dirs`: Steam (registry `SteamPath` via `reg query`, `libraryfolders.vdf`), Epic `*.item` `InstallLocation`, plus the setting `_core` / `gpu.games` (JSON array of paths).
- `is_game`: graphics process, not ours, exe under a library dir (case-insensitive, path-boundary safe).
- `Watch`: polls every 5 s, `step_aside` once when a game starts, `game_over` once when it ends, returns on cancel. Hidden `with_source` injects the process list and poll interval.
- `headroom_mb`: setting `_core` / `gpu.headroom_mb`, default 1536.
