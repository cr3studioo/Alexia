What I built:
- windows.js: `act(element, how)` over UIA Invoke/Value(SetValue)/Toggle/SelectionItem/ExpandCollapse;
  element is `{pid,title,match}` or a point `{x,y}` (AutomationElement.FromPoint); how is one of
  invoke|toggle|select|expand|{set_value:text} or a list tried in order (`PRESS`). Returns
  `{done:true,via:"uia",how,x,y}` or `{done:false,found,disabled?,x,y}`. A pattern that throws is a miss.
  `clickBack`: GetCursorPos before, SetCursorPos after, in a `finally`, after the window guard.
- macos.js: same `act` via JXA: AXPress (else AXConfirm), AXPress, AXPick (else AXSelected), AXShowMenu
  (else AXExpanded), AXValue set when settable; element at a point via AXUIElementCopyElementAtPosition.
  A browser page answers a press by name first (`via:"page"`). `clickBack` posts a CGEventCreateMouseEvent
  move back to the kept point.
- index.js: `press` and `do` (click; type with new optional `match`) try `act` first, fall back to
  `clickBack` (+ type) only when no pattern fits. Result text says "pressed through accessibility" or
  "clicked with the mouse". Logs only the way taken, never element text. `click` tool also shows her cursor.
- ghost.js: `show(x,y)` → `alexia/capability/call cursor.show {x,y,label:"Alexia"}` when `alexia/answers`
  says a provider exists (cached 60 s); always settles within 200 ms; `show_cursor:false` turns it off.
