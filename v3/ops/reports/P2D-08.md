# P2D-08 report: Library (plugins and skills from the shelf)

Status: done

What I built:
- First round: `GET /api/library`, `GET /api/library/progress`, `POST /api/library/install` (v2 `library.ts` port: github and static `/v0/` shelves, sha256, revocation, newer-app refusal, zip/tgz with zip-slip checks, installs arrive disabled unless asked). `ALEXIA_LIBRARY_REGISTRY` is a test seam.
- Fix round (reviewer findings 1–5):
  1. Invariants: unit tests use the made-up id `sample`; the `/v0/<entries>/{id}.json` path is built from the const `REGISTRY_ENTRIES`, commented as the registry URL layout, not the plugins folder. `node v3/ci/invariants.mjs` passes.
  2. `block_of` steps over the whole whitespace char (`len_utf8`), so U+00A0/U+2028 no longer panic.
  3. `remove_tree` is async and waits with `tokio::time::sleep`; `rename_tree` likewise. `Staging::drop` tries once, then retries on its own named thread, never sleeping on a runtime worker.
  4. `replace` uses `swap_folder`: old folder renamed aside, new one copied, old one deleted only on success; on error the partial copy is removed and the old folder renamed back.
  5. Skill install: preauth and provenance are still written before the folder (so a board read in between does not mark it "unknown"), but if `create_dir_all`/`copy_tree` fails both are taken back (only what this install added) and the partial folder removed.
