## Fix round 1
- Tool spans: a span stays open through phase and progress events and closes only on a delta, another step's n, or the end of the stream. A step n already seen (its done event) never reopens, and v2's `phase{tool}` after a step sends no second Phase(Tool). The result is one span and one Phase(Tool) per step.
- `phase_and_step_frames_map` now scripts agent.ts's order (step, phase{tool}, progress, done with the same n) with pauses. It asserts one span per step, each lasting at least 200 ms and 100 ms.
- Cancel while the `/api/chat` POST is in flight (body sent, headers awaited) now POSTs `/api/stop` (harmless when idle, serve.ts:2505). No stop is sent while waiting between 423 retries, because that run is someone else's. New test: `cancel_while_waiting_for_headers_posts_stop` (the fake holds headers until `/api/stop`).
