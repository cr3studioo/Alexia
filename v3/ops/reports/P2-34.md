What I built:
- `LocalJobs` (local.rs): picks a model per job from `hf::installed`, runs it through `Runtime::serve` with `gpu::fit` layers, registers it with the router as a local provider.
- Vision: needs an mmproj; owner pin `_core.models.vision` wins, else the largest model that Fits (smallest if none). Embeddings: embedding arch (`*bert*`/`*embedding*`), pin under `local`. Checker: smallest instruct that Fits (none if none fits), pin under `check`, plus a smaller same-arch model as `--model-draft` when it fits in what is left of the GPU (SP-17).
- `describe` caches per SHA-256 of the image URL for the session; `embed` calls the new `Runtime::embed` (POST /v1/embeddings, results sorted by index, count checked).
- `set_paused(true)` makes every method return None before anything starts; `provider()` is None for Chat/Plan/Step/Code (D213).
- `see_before_cloud`: `_core.vision == "cloud"` keeps images; otherwise each image becomes "[Picture: description + OCR]", or a plain "cannot look at pictures" sentence when no local model is available or a game runs (the picture never leaves the PC).
- upcalls.rs: `host_caps` (["vision.describe","text.embed"] per installed model) and `host_call` on `Agent`.
