## Fix round
- Job Object: local.rs no longer imports `alexia_mcp::testing::Job`. Its CreateJobObjectW / KILL_ON_JOB_CLOSE code is copied into a private `job` module. alexia-core has no `windows-sys` (and Cargo.toml is out of bounds), so the five kernel32 calls and two structs are declared by hand with `extern "system"`; the child is assigned by its tokio raw handle instead of OpenProcess.
- stop_all vs a mid-start serve: `stop_all` bumps an `epoch`; `serve` records it under the starting lock and `wait_healthy` checks it every 200 ms, so a start that began earlier kills its child and returns an error. It does not take the starting lock, because an install holds that for minutes. Test: `stop_all_beats_a_server_mid_start` (fake held at "loading").
- Last use: each server has an in-use chat count (drop guard, so a dropped future still decrements); the idle stopper skips servers in use. Test: `long_chat_is_not_idled_out` (2 s idle limit, 5 s reply).
- CPU fallback: a failed or cancelled CPU install now removes `b11146.part`. No test: the CPU URL and digest are consts, so it cannot be reached without a real download.
