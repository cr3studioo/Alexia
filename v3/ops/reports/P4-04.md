# P4-04 report

Status: done

What I built:
- `alexia-mesh::node::Node`: runs `alexia_connect::start` in this process. The key comes from the keychain (`identity::load_or_create`) or is in memory when `ephemeral`. The per-launch secret is 32 CSPRNG bytes as hex, and there is no mailbox.
- After start it sends `PUT /v1/self/addresses` and then `sync_allowlist`. The allowlist is exactly the store's non-revoked devices. Each device's stored hints go to connect, with only `relayUrl` and `directAddresses` passed on.
- `revoke` revokes in the store and sends `DELETE /v1/allowlist/{endpoint}`, then emits `MeshEvent::Revoked`. `connect` (returns a `Reach`), `status`, `events`, `loopback` and `close` are as the spec says.
- Events task: reads connect's SSE stream. A `snapshot` replaces everything known. It emits `Online`/`Offline` only when a known device's reach changes, and records `device_seen`. It ignores event names it does not know.
- `control.rs`: `Control`, a typed loopback client using a bearer secret and `no_proxy`. It maps `peer_not_allowed` to `NotPaired` and `peer_unreachable` to `Unreachable`. It has an SSE reader that reconnects with a 250 ms to 10 s backoff.
