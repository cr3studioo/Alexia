# P0-05 report

Status: done

What I built:
- `namespace.rs`: an `impl Store` block with create_tables, insert, select, update, delete, count, raw, purge.
- Names: ns checked against `^[a-z][a-z0-9-]*$`, table/columns by `is_ident`, then double-quoted;
  physical name `p_<ns with - → _>_<table>`. Every value is a `?` parameter, including LIMIT/OFFSET.
- create_tables refuses with `Invalid` a new table whose physical name is already in sqlite_master or
  in another ns's record (`a`/`b_x` vs `a-b`/`x`). It records the tables in kv `_core` / `tables:<ns>` (sorted, deduplicated JSON array).
  Every other call refuses a table missing from that record with `OutOfNamespace("<table> is not one of this plugin's tables.")`.
- insert/update add columns from the JSON type (integer/bool INTEGER, other number REAL, else TEXT);
  `rowid` in an insert, an empty row, an empty `set` or an empty update/delete `where` → `Invalid`.
- `where` compiles to an AND of =, !=, <, <=, >, >=, IN, LIKE, IS NULL after `Operator::validate()`; unknown column → `Invalid`.
- purge: one transaction that drops the recorded tables, deletes the record, then kv and settings for the plugin.
- select returns text columns as text, never parsed (owner decision, follows v2 over spec step 5).
- raw: always `OutOfNamespace("Raw SQL is not available.")`.
