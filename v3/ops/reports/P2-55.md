# P2-55 report

Status: done

What I built:
- `conn.rs` `on_line`: the request task's `select!` is `biased;` with the request first, so
  the handler is polled once before a cancel that arrived in the same read can win. Commented.
- `wasm.rs`: `WasmPlugin::spawn` / `spawn_as` are `async`. The ready signal is a
  `tokio::sync::oneshot` awaited under `tokio::time::timeout(start_ms)`, so no runtime worker
  blocks during the compile. The compile stays on its own OS thread; timeout still kills the
  guest. A thread that dies without a word (panic) is now its own error, "failed to start".
- `wasm.rs`: `#[doc(hidden)] pub fn set_start_delay` (thread-local, so tests in parallel are
  unaffected) makes the compile thread sleep first, to stand in for a slow compile.
- `wasm.rs`: removed `#[allow(clippy::incompatible_msrv)]` on `pipes()`.
- `host.rs`: `start_guest` is `async` and awaits the spawn; its one caller awaits it.
