# P2D-05 report

Status: done

What I built:
- `chat.rs`: `/api/chat` streams v2's frames (`data: <json>\n\n`, `text/event-stream`, `no-store`) from `api.parts.brain` with `Origin::Window`. It covers delta, restart, phase (v2 shapes; v3 phases have no model, so "a model"), note, ask, step args/progress (stages and plan pass through)/outcome (files offered), learned, learn (`learned::offer`), error and done (`spent:0, cap:0, today {0,0}`). It never sends paid or paused. The 423 has v2's two sentences. Uploads are saved and refused by v2's `attach.ts` rules and sentences, then deleted after the turn. `again` follows v2's 409 rules. `private` is kv `private_sessions`. After an answer, `memory.capture` (task lane only, since the chat lane already captures) and `reply.finished` are fired and forgotten, unless the session is private.
- Window approvals: before the brain starts, the turn subscribes to the bus. Every `RunStarted` (Window, this session) is attached to `WindowQuestions`. All of them are detached when the turn ends **or the SSE stream closes** (watched with `tx.closed()`), so a closed window is never an Allow. `/api/stop` cancels the run and calls `cancel_open`. `/api/approve` calls `answer(allowed == true)`.
- `/api/command` runs through `commands::run` (Window). `/new` gives the window a new session (`set_session`, `moved:true`). `/help` adds `data`. The answer includes `setup` and `pins` (read from v2's kv keys) and `modeTransition` when it is set. `/api/not-her` ports v2 to `persona.not_her`.
- `offers.rs`: `Offers::keep`/`get`/`act` (random ids, keeps at most 500), `GET /api/file` with v2's headers and its 410/404, and `POST /api/file` (open refused with 409 for v2's executable extension list; `explorer.exe [/select,]<offer path>`, detached, exit code never read). The spawn is replaced by a recorder under `cfg(test)`.
- Hub: `Asker::with_window(.., WindowQuestions::default())`.
