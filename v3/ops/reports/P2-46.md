# P2-46 report

Status: done

What I built:
- `scope()`: any `kv_get` error on `scope`, `mode` or `boundaries` gives a closed Scope:
  AskEveryTime, no roots, not everywhere, one `Blocks::Everything` boundary ("Alexia could not
  read your permissions, so it asks before everything."). One `tracing::warn!` names the key,
  never a value. Absent keys keep the old defaults.
- `is_destructive()`: destructive when unreviewed, or when not read-only and
  `destructiveHint != Some(false)`. A comment names the divergence from v2's code and why.
- `paths_in()`: strings go through a new private `normalised()` first: `file://` (empty or
  `localhost` host; any other host is dropped) percent-decoded, `/C:/x` → `C:\x` on Windows;
  a leading `~`, `~/` or `~\` → `home()`; a leading `$VAR`, `${VAR}`, `%VAR%` expanded through
  `env_path`. An unset variable stays as written. Names that would make `var_os` panic (empty,
  `=`, NUL) are not looked up.
