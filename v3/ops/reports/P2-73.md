# P2-73 report

Status: done (clippy not run to the end, see below)

What I built:
- `Agent::reply` takes `Lane::Command` only for `Origin::Channel`; from Desktop/Scheduler a `/…` text is a task turn.
- `commands::run` guard (`owner_only`): from any origin but Channel, `/approve`, `/deny`, `/undo` and every plugin command (bare or `<plugin>.<name>`) answer "Commands are only taken from your own chat." and run nothing. Read-only built-ins still answer.
- `attach(turn)`: images up to 20 MB (`MAX_DOCUMENT`, the bridge's port) become `Part::Image` data URLs. Text-like files (`text/*`, json, xml, `.md`, `.csv`) up to 200 KB of valid UTF-8 are inlined as `"<name>:\n<text>"`. Anything else is named as unreadable, with a `tracing::warn!` that leaves out the contents. Files are read with `tokio::fs`, and the result is the stored user message.
- `background: matches!(turn.origin, Origin::Scheduler { .. })`.
