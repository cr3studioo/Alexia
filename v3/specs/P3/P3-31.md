## Goal
The real hub runs the proactivity engine: the scheduler is built with sources that fan out to
plugins over the MCP host, input on this PC after the night's idle counts as the owner being
up, and the owner can see and steer all of it: `alexia-hub notices`, `quiet`, `brief`,
`silent`, and the matching slash commands from their chat. Quick capture ("+ buy milk",
`/note ...`) lands in the tasks list or memory. This task is wiring and commands; the
behaviour lives in the tasks it depends on.

## Interfaces
```rust
// proactive.rs
pub struct HostSources { host: McpHost, per_call: Duration /* 20 s */ }
#[async_trait::async_trait]
impl alexia_scheduler::Sources for HostSources {
    // items: call_capability_all("notice.items", {now, horizon_days, tz_offset_min}), parse
    //   structuredContent.items (camelCase) into NoticeItem; a bad item is skipped and counted.
    // sections: call_capability_all("brief.section", {kind, now, tz_offset_min}); text non-empty.
    // poll: call_capability(cap, args): text blocks joined; isError → None.
    // done: call_capability_all("notice.done", {key}).
}
/// Windows: every 60 s, `GetLastInputInfo`; when input appears after ≥ 3 h idle, publish
/// `Event::Active { via: "pc" }`. Elsewhere: does nothing.
pub fn spawn_activity_watch(bus: Bus, cancel: CancellationToken);
```
`tz_offset_min` is the local offset now (`chrono::Local`).

Wiring in `run`: step 6 (INTERFACES §2.6) uses `Scheduler::with_sources(store, bus, agent,
Arc::new(HostSources::new(host.clone())))`. `spawn_activity_watch` starts in step 11.

CLI (each prints plain lines, exit 0; errors are sentences, exit 1):
```
alexia-hub notices [--week | --last N]   id, when, state, urgency, source, text (newest first)
alexia-hub quiet [HH:MM HH:MM [low|normal|high|urgent]]   show or set quiet hours
alexia-hub quiet pause <minutes> | resume
alexia-hub brief --now [morning|evening|weekly]   refuses with "The hub is not running." when
                                         hub.lock is free; otherwise writes kv `_core`/`brief.ask`
                                         = {kind, at}, which the running scheduler's brief clock
                                         picks up within a minute (P3-09)
alexia-hub silent list | allow <tool id> | remove <tool id>   kv `_core`/`silent`; `allow`
                                         refuses a tool whose annotations say openWorldHint
                                         true, with "That one reaches outside your computer, so
                                         she always asks." (needs the plugin's tool list:
                                         `McpHost` started without the scheduler)
alexia-hub mute list | remove <id>
```

Slash commands (owner-only, as `/approve` is, `commands.rs`):
- `/brief [evening|weekly]` → the `brief_now` builtin (P3-09) by tool name.
- `/quiet` (show), `/quiet 23:00 07:00`, `/quiet 2h` (pause), `/quiet off`.
- `/notices` → the last 10 notices, one line each.
- `/silent` (list), `/silent allow <tool id>`, `/silent remove <tool id>`: same refusal as
  the CLI for open-world tools.
- `/mute <source>` and `/mute` (list).
- `/note <text>` and a message that starts with "+ " (DY-10) → `tasks.add {text}` through the
  host if something provides it, else `memory.remember {text}`, else "Nothing here can keep
  notes yet." Answer "Noted." with a 📝 reaction where the channel supports it.
