# P3-13: Memory: recall by meaning, sources, corrections, forget

Model: sonnet
Depends on: P3-02
Feature IDs: ME-10, ME-11, ME-12 (and recall quality for everything that reads memory)

## Goal
The memory plugin finds things by meaning, not only by shared words: each fact gets an
embedding from the host's `text.embed` (local, MO-07), and recall ranks by similarity blended
with v2's keyword and recency ranking. Without `text.embed` it degrades to v2's ranking and
says so once in its status. Every fact records where it came from (which channel, which
conversation, which day, said or worked out, or which document) and every answer that shows a
fact shows that. When the owner corrects her ("no, it's Brno, not Prague"), capture writes
the new fact as a replacement, not a second truth. Forget on command keeps working from every
channel, including clearing the capture buffer first.

## Interfaces
- Manifest: `requires` gains `{ "cap": "text.embed", "why": "to find what you said by what it
  means, not only by its words", "optional": true }` if the manifest schema has `optional`;
  if not, the plugin still works without a provider (rule 5: degrade with a sentence).
- `text.embed` is called as `alexia/capability/call` `{cap: "text.embed", arguments: {texts:
  [string]}}`. Read the exact argument and result shape from
  `v3/crates/alexia-core/src/upcalls.rs` (the `"text.embed"` arm, around line 879) and use it
  as is. Vectors are stored as a column `vec` (JSON array of numbers rounded to 5 decimals)
  and `vec_model` (the model name, when the host says it), so a model change re-embeds.
- New fact columns: `src_channel` (e.g. "telegram", "window"), `src_session` (number),
  `src_doc` (path or title, for document facts), alongside v2's `source` (stated|inferred).
  The host passes the turn's origin in `_meta["alexia/privateContext"]` or the call's arguments
  (read how `memory.capture` is called today in `alexia-core/src/chat.rs:291` and
  `alexia-api/src/chat.rs`; P3-16 adds `channel` and `session` to those arguments; until then
  the columns stay null).
- Rank: `score = 0.6 * cosine + 0.3 * keyword (v2's, normalised 0..1) + 0.1 * recency`, ties by
  newest. Below cosine 0.25 and no keyword hit → not returned.
- Every line that shows a fact ends with its source, for example "(you said it on Telegram,
  12 Nov)" or "(worked out from a chat on 3 Oct)" or "(from “Thesis plan.docx”)".
- Corrections: capture's prompt to the sorting model (in `capture.js`) gains a rule: a message
  that contradicts a remembered fact ("no", "actually", "not X but Y", Czech "ne, …", "vlastně")
  yields a `replaces` of that fact's id. The facts handed to that prompt carry their ids.
- Backfill: at start and after `sort_now`, embed up to 50 facts without `vec` per pass.

## Steps
1. `search.js`: cosine over plain arrays, the blended rank, pure and tested.
2. `index.js`: embed on `remember`/capture, backfill, the source columns, the output suffix,
   the status line ("● 312 remembered, found by meaning" / "● 312 remembered, by words only:
   nothing here can embed text").
3. `capture.js`: correction rule and ids in its prompt; tests with a scripted sampler.
