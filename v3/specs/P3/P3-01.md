# P3-01: P2D carry-over: one home for alexia-api's helpers, stale allows gone

Model: sonnet
Depends on: P3-00
Feature IDs: none (P2D phase review LATER L1, L2)

## Goal
The helpers `alexia-api` copied between modules live once, in `util.rs`, and every module uses
that copy. `js_string` had diverged; the copy kept is gate's, because the gate is the security
path, and a test pins its behaviour. The `#[allow(dead_code)]` attributes left by the P2D-01
scaffold are removed, so real dead code shows up again.

## Steps
1. For each pair in the review's L1 list, diff the copies and confirm they behave the same.
   Note any difference in the commit message.
2. Move one copy into `util.rs`, delete the others, fix imports. `plugins.rs` calls
   `js_string(Some(v))`; its `js_number` is deleted. The five `const CORE` copies and the
   `"_core"` literals in `chat.rs` and `plugins.rs` use `util::CORE`.
3. Remove the four stale allows (gate.rs:31-32, json.rs:13, lib.rs:84, local_models.rs:1700).
   If clippy then reports something really unused, delete it rather than re-allowing it. The
   allows on fields in `local_models.rs` (75, 97, 103, 106) give reasons and stay.
