**New §3.6, P3 capabilities.** Arguments and results are JSON. Results are a `CallToolResult`
whose `structuredContent` holds the shape below and whose text is a readable version.
- `notice.items` `{now: Ms, horizon_days: u32, tz_offset_min: i32}` → `{items: [NoticeItem]}`
  (camelCase on the wire: `dueAt`, `notBefore`).
- `notice.done` `{key}` → `{closed: bool}`: the owner said a notice is done; the provider
  whose key it is closes the thing behind it, every other provider answers `closed: false`.
- `brief.section` `{kind: "morning"|"evening"|"weekly", now, tz_offset_min}` → `{title, text}`.
- `calendar.events` `{from: Ms, to: Ms}` → `{events: [{id, title, start, end, allDay,
  location?, attendees: [email], calendar}]}`; `calendar.create` `{title, start, end,
  location?, attendees?}` → `{id}`, `openWorldHint: true`.
- `mail.list` `{since?: Ms, query?: String, limit: u32}` → `{messages: [{id, threadId, from, to,
  subject, snippet, at, unread, labels}]}`; `mail.read` `{id}` → `{text}`; `mail.send` `{to,
  subject, text, replyTo?}` → `{id}`, `openWorldHint: true`, `destructiveHint: false`.
- `contacts.find` `{query}` → `{contacts: [{name, emails, phones, birthday?}]}`.
- `tasks.add` `{text, due?: "YYYY-MM-DD", list?: String}` → `{id}`.
- `page.text` `{url}` → `{text}`: a web page's main text, at most 20 000 chars (what a
  `Trigger::Watch` on a page polls, PR-16).
