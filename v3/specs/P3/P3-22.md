# P3-22: Day planner: daily plan, smart scheduling, leave-now, meeting prep

Model: sonnet
Depends on: P3-03
Feature IDs: DY-16, DY-03, PR-10, PR-11

## Goal
The `day-planner` plugin turns the calendar (whoever provides `calendar.events`) and the
owner's tasks into a plan for the day, which is a section of the morning brief (DY-16). It
finds free time and proposes slots for something the owner wants to fit in, creating the event
only through `calendar.create`, which asks (DY-03). It warns when it is time to leave for an
event that has a place (PR-10) and, an hour before a meeting, gathers what is known about it:
the people (memory), related mail and documents (PR-11).

## Touch only these paths

## Interfaces
- `requires`: `calendar.events` ("to see your day"), `calendar.create` ("to put a slot in your
  calendar when you say yes"), and optionally `memory.recall`, `mail.list`, `find_document`'s
  capability if P3-18 declares one (otherwise skip documents), `tasks.add` (none needed to read
  tasks: use `notice.items`? no: read tasks through a `tasks.due` capability only if P3-26
  declares one; until then the plan has the calendar only).
- Settings: `travel_minutes` (number, default 30: fixed travel time, no paid maps API, D212),
  `home` (text, optional: a place label like "Home"; events at that place need no travel),
  `prep_minutes` (default 60), `day_starts` (default 08:00), `day_ends` (default 22:00).
- `brief.section` tool: for `morning`, "Today:" and one line per event (time, title, place), then
  free blocks over 1 h; for `evening`, tomorrow's first event and when to leave for it; for
  `weekly`, the week ahead by day.
- `notice_items`: leave-now items for events with a `location` not equal to `home`, `dueAt` =
  start − travel_minutes, urgency High when within 30 min, key `planner:leave:<event id>`;
  meeting-prep items for events with attendees, `notBefore` = start − prep_minutes, Low, text
  "<title> at <time>: <n> people, I've gathered what I know." with the prep in `why`.
- `find_time {what, minutes, within_days?, after?, before?}` (read-only): up to 3 free slots.
- `book_slot {what, start, minutes}` (not read-only): calls `calendar.create`; the owner's
  permission mode and D214 decide if it asks (it is open-world, so a proactive run always asks).
