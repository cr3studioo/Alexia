# P3-00: P2D carry-over: private sessions atomic, no user name in fixtures

Model: opus
Depends on: none
Feature IDs: none (P2D phase review LATER L3, L5)

## Goal
The list of private conversations (kv `_core`/`private_sessions`) is read and written in one
place, and every change to it is one atomic store operation, so two chats marked private at the
same moment are both kept. Today `chat.rs:551` and `editor.rs:148` each read, modify and write
the list with no lock, and a lost mark puts a private chat on the board and into learned skills
(`learned.rs:419`). Separately, the owner's Windows user name leaves the contract fixtures: the
temp paths become a placeholder that the replay fills at run time.

## Interfaces
```rust
// alexia-store, impl Store
/// Read-modify-write of one kv value inside one transaction, under the store's connection
/// mutex: `f` gets the current value (None when absent) and returns the new one (None deletes
/// the key). Returns what was written. No other writer can interleave.
pub fn kv_update(
    &self,
    ns: &str,
    key: &str,
    f: impl FnOnce(Option<serde_json::Value>) -> Option<serde_json::Value>,
) -> Result<Option<serde_json::Value>>;
```
```rust
// alexia-api/src/private.rs
pub(crate) const PRIVATE: &str = "private_sessions";   // kv ns `_core`
/// An unreadable value reads as empty.
pub(crate) fn sessions(api: &Api) -> Vec<i64>;
pub(crate) fn is_private(api: &Api, session: SessionId) -> bool;
/// Adds `session` through `Store::kv_update`; idempotent; the list only grows (v2).
pub(crate) fn mark(api: &Api, session: SessionId) -> crate::Result<()>;
```
Callers of `board::is_private` (`editor.rs:81`, `learned.rs:419`) switch to
`private::is_private`.

Placeholder: the fixtures hold `%TEMP%` (the six literal characters) where the recorded path
had `C:\Users\<name>\AppData\Local\Temp`. Before comparing, `contract.rs` replaces `%TEMP%` in
expected values with `std::env::temp_dir()` (trailing separator trimmed, as the JSON string
the hub would write).

## Steps

2. Create `private.rs`; make `chat.rs`, `editor.rs`, `board.rs` and the `learned.rs` call use

3. In the two fixture files replace the user-specific prefix with `%TEMP%`; teach
   `contract.rs` to fill it. Then grep all of `alexia-hub/tests/` for `Users\\`.
