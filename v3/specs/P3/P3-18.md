# P3-18: Document library and notes sync

Model: sonnet
Depends on: P3-03
Feature IDs: ME-07, ME-08

## Goal
The `notes-library` plugin reads the documents and notes in folders the owner chose, keeps a
short summary and an embedding per file, and lets her find them later by meaning ("the PDF
about the scholarship"). A notes app is synced by pointing it at the notes folder: Obsidian
vaults and any folder of Markdown files work, with links and tags kept. It re-reads only what
changed. It never writes to the owner's files.

## Touch only these paths
- `plugins/notes-library/**`   (fill: `index.js`, `scan.js`, `parse.js`, `plugin.json`, `README.md`, `test/*.test.js`)

## Must not touch
`package.json` (P3-03 made it; no new dependency), other plugins, crates.

## Interfaces
- `requires`: `fs.read_scoped` ("to read the folders you choose"), `text.embed` ("to find a file
  by what it is about"), `document.extract` ("to read PDFs and Word files"). Without
  `document.extract`, only text and Markdown files are read, and the status says so.
- Settings: `folders` (the setting type for folders in `manifest.md`; each must be inside the
  owner's chosen roots), `notes_folder` (one folder treated as a notes vault), `every` (choice:
  hourly | daily, default hourly).
- Tables: `files` (`path`, `size`, `mtime`, `sha256`, `title`, `summary`, `vec`, `tags`,
  `links`, `at`).
- Tools: `find_document {query, limit?}` (read-only; title, path, summary, why it matched),
  `read_document {path}` (read-only; the text, at most 20 000 chars, via `document.extract` for
  PDF/DOCX), `notes {tag?}` (read-only), `reindex {}` (not read-only, not destructive).
- Summary: one sampling call per new or changed file (≤ 3 sentences), skipped for files under
  200 chars (the text is the summary).
- Notes vault: `[[wikilinks]]` and `#tags` parsed into `links`/`tags`; `.obsidian/` and
  dot-folders skipped.
- Status line: "● 214 files from 3 folders, last read 10:02".

## Steps
1. `parse.js` (frontmatter, wikilinks, tags; pure) and `scan.js` (walk, change detection by
   mtime+size then sha256; pure over an injected fs) with tests.
2. `index.js`: tools, the timer, status.
3. `README.md`: what it reads, what it never does, how to point it at an Obsidian vault.

## Tests
