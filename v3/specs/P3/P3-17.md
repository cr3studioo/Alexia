# P3-17: Memory screen

Model: sonnet
Depends on: P3-15
Feature IDs: ME-03

## Goal
The memory plugin's panel (which the existing UI already renders, plugins screen → Memory)
becomes the memory screen: besides v2's tree, it shows people, goals, upcoming dates, the
timeline of days, and for every fact its source and whether it is locked. Row actions let the
owner correct, lock, unlock, pin or forget a fact from there. No UI code changes: everything
goes through the panel schema (`docs/spec/ui-schema.md`).

## Touch only these paths
- `plugins/memory/plugin.json`   (change: `panel.widgets`)
- `plugins/memory/index.js`   (change: the row tools the widgets read)
- `plugins/memory/test/panel.test.js`   (create)

## Must not touch
`packages/ui` (if a widget type you need does not exist, stop and ask through the
coordinator), other memory files beyond calling them, other plugins, crates.

## Interfaces
Widgets added after the tree, each with `rows` pointing to a read-only tool returning the
row shape `ui-schema.md` defines for that widget type:
- **People** (`table`, rows `people_rows`): name, relation, birthday, last came up; detail
  `about_person`.
- **Goals** (`table`, rows `goal_rows`): goal, since, last touched, state; row actions
  `goal_done`.
- **Coming up** (`table`, rows `date_rows`): what, when, kind, from the `dates` table, next 30 days.
- **Your days** (`table` or `list`, rows `day_rows`): the timeline, newest first, 60 days.
- The tree's facts and `about_memory` gain the source line (P3-13) and a "🔒 locked" tag;
  row actions `lock` (unless tag locked) and `unlock` (when tag locked) next to v2's pin
  actions.

Row tools are read-only, not open-world. The panel never shows locked facts' text unless the
panel call carries `unlocked: true`. The window is the owner at the keyboard (`Origin::Window`),
so the hub passes it (P3-16); a test asserts the plugin respects the flag either way.

## Steps
1. Read `docs/spec/ui-schema.md` and v2's existing widgets in this manifest; copy their style.
2. Add the row tools and widgets.
