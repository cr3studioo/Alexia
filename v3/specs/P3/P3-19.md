# P3-19: Screen memory

Model: opus
Depends on: P3-03
Feature IDs: ME-06

## Goal
When the owner turns it on, the `screen-memory` plugin keeps the text of what was on this PC's
screen every few minutes (OCR of a screenshot, the image thrown away at once), so she can
answer "what was that error I saw this morning" or "the flight price I had open yesterday".
It ships **off**, keeps text only, keeps 14 days, and skips moments that must not be kept: a
private chat open in the window, a password field focused, a game running, the lock screen,
or an app on the owner's exclusion list.

## Touch only these paths
- `plugins/screen-memory/**`   (fill: `index.js`, `capture.js`, `filter.js`, `plugin.json`, `README.md`, `test/*.test.js`)

## Must not touch
`package.json` (no new dependency), the computer and ocr plugins (use them by capability),
other plugins, crates.

## Interfaces
- `requires`: `computer.screenshot` ("to see the screen when you have turned this on"),
  `image.ocr` ("to keep only the words, never the picture"), `text.embed` ("to find it by
  meaning"), `fs.own_dir` ("for the screenshot while it is read").
- Settings: `on` (toggle, default **false**), `every_minutes` (choice 2 | 5 | 10, default 5),
  `keep_days` (choice 3 | 7 | 14, default 14), `skip_apps` (text, comma-separated process
  names; defaults: `KeePassXC.exe, 1Password.exe, Bitwarden.exe`).
- Table `moments` (`at`, `app`, `title`, `text` (≤ 4000 chars), `vec`).
- Capture loop: only while `on`. Take a screenshot through `computer.screenshot`, OCR it
  through `image.ocr`, **delete the image file before anything else**, then filter, then store.
- Filter (`filter.js`, pure): drop when the foreground process is in `skip_apps`, when the
  window title contains "password", "heslo", "sign in", "přihlášení" (case-insensitive), and
  when the foreground window covers the whole screen with no title bar (games and full-screen
  video; plugins cannot see the hub's game list). Then redact rather than drop: card numbers
  (Luhn-valid 13–19 digits), IBANs, and `sk-`/`ghp_`/`xox` token prefixes become `[removed]`
  (the host's credential redaction is not available to plugins, so this plugin has its own).
- Tools: `screen_recall {query, from?, to?}` (read-only), `screen_forget {from, to}`
  (destructive: true), `screen_status {}`.
- Daily prune of rows older than `keep_days`.

## Steps
1. `filter.js` and the redaction with tests first.
2. `capture.js`: the loop, image deleted in a `finally`.
3. `README.md`: what is kept, what never is, how to turn it on and off, how to forget a span.

## Tests

## Notes for the worker
- No Rust. Cargo checks, if run: `CARGO_BUILD_JOBS=1`.
- This is the riskiest plugin in P3 for privacy (PHASE.md *Owner needs* 8). When in doubt,
  drop the moment. Never log OCR text, window titles or app names with their text.
- Screenshots go only through `computer.screenshot` (the computer plugin runs in the owner's
  session after P2D-12); this plugin never captures the screen itself.
- Invariants: capabilities, never plugin names; no user paths; no secrets kept (that is what
  the redaction is for); text never in logs.
