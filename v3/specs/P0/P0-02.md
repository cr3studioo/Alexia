Model: opus
Depends on: P0-01

## Goal
After this task `alexia-store` exports every data type the other crates share: ids, messages,
the plugin storage grammar, ledger rows, `Layout`, `data_dir()`, and the crate's `Error`. No
database code yet. These types are what `alexia-mcp`'s wire params and every store task build
on, so they land first and alone.

## Interfaces
Copy these from INTERFACES.md §2.1 **verbatim** (derives, serde attributes and field names
included): `Ms`, `data_dir`, `Layout` and its six methods, `SessionId`, `MessageId`, `Role`,
`Part`, `Content`, `ToolCall`, `MessageBody`, `Message`, `Session`, `Scalar`, `Operator`, `Cond`,
`Where`, `Row`, `Dir`, `Select`, `DeleteScope`, `Usage`, `Try`. Add `#[derive(Clone, Debug,

Defined here:

```rust
// error.rs
#[derive(Debug, thiserror::Error)]
pub enum Error {
    #[error(transparent)] Sqlite(#[from] rusqlite::Error),
    #[error(transparent)] Io(#[from] std::io::Error),
    #[error(transparent)] Json(#[from] serde_json::Error),
    /// The keychain failed. The String is a full sentence, never a secret.
    #[error("{0}")] Keychain(String),
    /// A sentence the owner reads: newer schema, not a v3 file, import already done, …
    #[error("{0}")] Refused(String),
    /// storage.md: an identifier or statement outside the plugin's namespace (-32052 on the wire).
    #[error("{0}")] OutOfNamespace(String),
    /// A malformed filter, identifier or value (-32602 on the wire).
    #[error("{0}")] Invalid(String),
}
pub type Result<T> = std::result::Result<T, Error>;

// types.rs
impl Operator {
    /// Exactly one field set; `is_null` only `Some(true)`; `in_` non-empty. Else `Error::Invalid`.
    pub fn validate(&self) -> Result<()>;
}
/// `^[a-z][a-z0-9_]*$`, the column and table name rule from storage.md.
pub fn is_ident(s: &str) -> bool;
```

`lib.rs` declares `mod error; mod layout; mod types;` and re-exports everything public from them
at the crate root (`pub use types::*;` etc.).

`Cargo.toml` adds `serde`, `serde_json`, `thiserror`, `rusqlite` (all `.workspace = true`).
`rusqlite` is needed only for the `#[from]` in `Error`.

## Steps
1. Add the dependencies.
2. Write `error.rs`, `types.rs`, `layout.rs` as above.
3. `data_dir()`: `ALEXIA_V3_DATA` if set and absolute; else Windows `%LOCALAPPDATA%\AlexiaHub`,

5. Write the tests.

## Tests
In `tests/types.rs`:
- `message_body_round_trips_v2_json`: a v2 body with `content` as a string, one with `content`
  as parts (text + image), one with `calls`, one with `callId`, `provider`, `notes`, `bad`,
  `stopped`, `typed`, and one with an unknown key `"future": {"x":1}` all deserialize and
  serialize back to the same `serde_json::Value`.
- `role_serializes_lowercase`: `Role::Assistant` ↔ `"assistant"`.
- `operator_validate`: zero fields and two fields are `Error::Invalid`; `is_null: Some(false)`
  is invalid; `in: []` is invalid; each single field alone is valid.
- `operator_rejects_unknown_keys`: `{"eq":1,"bogus":2}` fails to parse.
- `cond_parses_bare_scalar_and_operator`: `5`, `"x"`, `null`, `{"gt":3}` parse to the right
  variants.
- `is_ident_rule`: accepts `a`, `a_1`; rejects `A`, `1a`, `a-b`, `a b`, `""`.
- `layout_paths`: every `Layout` method returns `root.join(...)` as listed.
- `data_dir_honours_env`: with `ALEXIA_V3_DATA` set to an absolute temp path, `data_dir()`
  returns it; set to a relative path, it is ignored. (Set and restore the variable inside one
  test; the env is process-wide, so keep all env-touching assertions in this one test.)
