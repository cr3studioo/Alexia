# P0-01: Cargo workspace skeleton

Model: sonnet
Depends on: none
Feature IDs: SP-12, EX-01

## Goal
After this task `v3/` is a cargo workspace with the seven crates from INTERFACES.md §1, each
compiling, with the internal dependency edges of §1.1 already declared. Every later task adds code
to a crate that already exists, so no two tasks fight over `v3/Cargo.toml`. The release profile
is size-optimised now (SP-12: one small binary).

## Touch only these paths
- `v3/Cargo.toml`   (create)
- `v3/Cargo.lock`   (create, committed)
- `v3/crates/alexia-store/Cargo.toml`, `v3/crates/alexia-store/src/lib.rs`   (create)
- `v3/crates/alexia-mcp/Cargo.toml`, `v3/crates/alexia-mcp/src/lib.rs`   (create)
- `v3/crates/alexia-core/Cargo.toml`, `v3/crates/alexia-core/src/lib.rs`   (create)
- `v3/crates/alexia-gateway/Cargo.toml`, `v3/crates/alexia-gateway/src/lib.rs`   (create)
- `v3/crates/alexia-scheduler/Cargo.toml`, `v3/crates/alexia-scheduler/src/lib.rs`   (create)
- `v3/crates/alexia-hub/Cargo.toml`, `v3/crates/alexia-hub/src/main.rs`   (create)
- `v3/crates/alexia-hub/tests/skeleton.rs`   (create)
- `v3/crates/alexia-limb/Cargo.toml`, `v3/crates/alexia-limb/src/main.rs`   (create)

(18 files, all a few lines; one cohesive change.)

## Must not touch
`connect/` (not a workspace member, not a dependency in P0), `packages/`, `plugins/`,
`src-tauri/`, `.github/`, the root `.gitignore` (it already ignores `v3/target/`), `v3/specs/`,
`v3/ops/`.

## Interfaces
`v3/Cargo.toml`, exactly INTERFACES.md §1.2, plus this release profile appended:

```toml
[profile.release]
# SP-12: one small binary. Same choices as connect/, minus panic=abort (a panicking task must
# not take the supervisor down with it).
opt-level = "s"
lto = true
codegen-units = 1
strip = true
```

Every crate's `Cargo.toml`:

```toml
[package]
name = "<crate>"
version.workspace = true
edition.workspace = true
rust-version.workspace = true
license.workspace = true
publish.workspace = true

[lints]
workspace = true

[dependencies]
# internal edges only, from INTERFACES.md §1.1:
```

| Crate | Kind | `[dependencies]` now |
|---|---|---|
| `alexia-store` | lib | none |
| `alexia-mcp` | lib | `alexia-store = { path = "../alexia-store" }` |
| `alexia-core` | lib | `alexia-store`, `alexia-mcp` (path) |
| `alexia-gateway` | lib | `alexia-store`, `alexia-core` (path) |
| `alexia-scheduler` | lib | `alexia-store`, `alexia-core` (path) |
| `alexia-hub` | bin `alexia-hub` | all five libs (path) |
| `alexia-limb` | bin `alexia-limb` | `alexia-mcp` (path) |

Each `src/lib.rs` / `src/main.rs` is the SPDX line and a one-line `//!` doc saying what the crate
is (the "One line" column of §1.1). The two `main.rs` files contain `fn main() {}`.

## Steps
1. Write `v3/Cargo.toml` (§1.2 verbatim + the profile above).
2. Create the seven crates with the manifests and source files above.
3. `cd v3 && cargo generate-lockfile && cargo build --workspace`; commit `Cargo.lock`.
4. Write `crates/alexia-hub/tests/skeleton.rs`: runs `env!("CARGO_BIN_EXE_alexia-hub")` and
   asserts it exits with success.
5. Run the Done-when commands.

## Tests
- `alexia-hub/tests/skeleton.rs::hub_binary_runs`: the hub binary builds and exits 0. (P0-14
  deletes this file when the real CLI lands.)

## Done when
- `cargo fmt --all --check` passes in v3/
- `cargo clippy --workspace --all-targets -- -D warnings` passes in v3/
- `cargo test --workspace` passes in v3/
- `cargo metadata --format-version 1 --no-deps` in v3/ lists exactly 7 packages, each with
  `"license":"AGPL-3.0-only"`
- `cargo build --release -p alexia-hub` produces `v3/target/release/alexia-hub.exe` (on Windows)
- `git status --porcelain` shows nothing under `v3/target/`

## Notes for the worker
- Workspace dependencies in §1.2 are declared but unused until later tasks pull them in with
  `dep.workspace = true`; that is expected and not a warning.
- Every `.rs` file starts with `// SPDX-License-Identifier: AGPL-3.0-only` (INTERFACES.md §0.2).
- Don't add `alexia-connect`: INTERFACES.md §1.1 lists it for the binaries, but nothing in P0
  uses the mesh, and pulling iroh into the lockfile now only slows every build.
- Windows: `cargo` on the owner's PC is 1.96; `rust-version = "1.85"` is the floor, keep it.
