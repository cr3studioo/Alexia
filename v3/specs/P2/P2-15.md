# P2-15: Trimming the step trace

Model: opus
Depends on: P2-01
Feature IDs: SP-01 (Alexia.md *Trimming the step trace*)

## Goal
After this task a long task fits the window of whichever model answers the next step: recent
steps verbatim, older ones collapsed into a running summary, raw tool output dropped once seen,
and the tool call/result pairing kept whole so no provider refuses the history.

- `v3/crates/alexia-core/tests/trim.rs` (create)
