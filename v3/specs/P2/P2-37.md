# P2-37: Encrypted database at rest

Model: opus
Depends on: P2-02, P2-03, P2-10
Feature IDs: TR-09

## Goal
After this task the hub's database can be encrypted at rest with SQLCipher: `Store::encrypt`
converts a plain `alexia.db` in place under a random 256-bit key kept in Credential Manager
(`alexia` / `_core.store_key`), and `Store::open` uses the key whenever it exists. Memory, chats,
the audit log and plugins' tables are all in that one file, so all are covered. The v2 importer
still reads a plain v2 file.

## Touch only these paths
- `v3/Cargo.toml` (rusqlite `bundled` → `bundled-sqlcipher-vendored-openssl`), `v3/Cargo.lock`
- `v3/crates/alexia-store/{Cargo.toml, src/db.rs, src/encrypt.rs (create), src/lib.rs, src/import.rs}`
- `v3/crates/alexia-store/tests/encrypt.rs` (create)

## Must not touch
`secrets.rs`; in `import.rs` only the ATTACH line changes (step 3); other crates.

## Interfaces
```rust
impl Store {
    /// As before; if `secrets::get("_core", "store_key")` is set, `PRAGMA key` first. A wrong or
    /// missing key on an encrypted file: Err("The database is encrypted and its key is missing or wrong.").
    pub fn open(path: &Path) -> Result<Store>;
    pub fn is_encrypted(path: &Path) -> Result<bool>;
}
pub mod encrypt {
    /// Generate a key, store it, `sqlcipher_export` into `alexia.db.enc`, verify every table's row
    /// count, swap atomically, overwrite then delete the plain file and its -wal/-shm. Refuses if the
    /// hub is running (the file is locked) or the key already exists.
    pub fn encrypt(path: &Path) -> Result<()>;
}
```

## Steps
1. Switch the feature workspace-wide (every crate uses the workspace rusqlite). Record build time
   and binary size before/after in the report.
2. Key: 32 bytes from the OS RNG (`getrandom`, added to `alexia-store` with a why line: std has
   no CSPRNG), hex, given to SQLCipher as a raw key (`x'…'`) so no KDF delay at open.
3. `ATTACH` of v2's plain file: `ATTACH ? AS v2 KEY ''`.
4. Never log or print the key; errors quote nothing.

## Tests
`encrypt_then_open_reads_everything`, `plain_bytes_absent_after` (a marker string not found in the
file), `wrong_key_sentence`, `refuses_twice`, `v2_plain_file_still_imports_into_encrypted_store`,
`unencrypted_store_still_opens_without_key`.

## Notes for the worker
- Vendored OpenSSL builds need Perl and NASM on Windows; `windows-latest` has Strawberry Perl. If
  CI cannot build it, stop and escalate rather than switching crypto libraries.
- "Overwrite then delete" is best effort on an SSD; say so in the doc comment, do not claim more.
- Owner needs: the key backup decision (PHASE.md). `alexia-hub encrypt` itself is P2-38.
