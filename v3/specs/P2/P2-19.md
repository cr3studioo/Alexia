# P2-19: Trace, runs and the audit log

Model: opus
Depends on: P2-01, P2-03, P2-14
Feature IDs: TR-08, AC-12, SP-13 (checkpoints), TR-03 (nothing secret written)

## Goal
After this task every run leaves a record a person can read later: one `runs` row (v2's trace
shape: steps, phases, models, timings, how it ended), one `audit` row per tool call (what, the
gate, the decision, the result), a `live_runs` row while it is going, and `RunStarted`/`RunStep`/
`RunEnded` on the bus. Everything written is redacted first. `activity` searches it and `replay`
prints a run as text.

## Touch only these paths
- `v3/crates/alexia-core/src/trace.rs`
- `v3/crates/alexia-core/tests/trace.rs` (create)

## Must not touch
Everything else.

## Interfaces
```rust
pub struct Trace { /* run, session, origin, store, bus, body */ }
impl Trace {
    pub fn begin(store: Arc<Store>, bus: Bus, run: RunId, session: SessionId, origin: Origin,
                 background: bool, parent: Option<RunId>) -> Result<Trace>;
    /// (review 4 #1) A run whose `live_runs` row survived a restart: no `live_begin`,
    /// `live_touch(run, steps_done, now)`, `RunStarted` again, the note "Resumed after a restart
    /// at step <n>.", and step numbers (trace and audit) continue from `steps_done`.
    pub fn resume(store: Arc<Store>, bus: Bus, run: RunId, session: SessionId, origin: Origin,
                  background: bool, parent: Option<RunId>, steps_done: u32) -> Result<Trace>;
    pub fn phase(&self, p: Phase);
    pub fn model(&self, asked: &str, answered: &str, first_byte_ms: Option<u32>);
    pub fn note(&self, line: &str);
    pub fn step(&self, step: &Step);                              // live_touch, RunStep
    /// One audit row. `gate`: "run" | "ask" | "blocked" | "checker".
    pub fn audited(&self, step: &Step, plugin: Option<&str>, gate: &str, decision: &str, why: Option<&str>) -> Result<i64>;
    pub fn end(self, end: &RunEnd) -> Result<()>;               // save_run, live_end, RunEnded
}
pub struct ActivityRow { pub at: Ms, pub run: String, pub tool: String, pub decision: String, pub ok: Option<bool>, pub summary: String }
pub fn activity(store: &Store, query: Option<&str>, limit: u32) -> Result<Vec<ActivityRow>>;
/// v2 `asText`: the run as a person reads it, step by step with each decision and why.
pub fn replay(store: &Store, run: &str) -> Result<Option<String>>;
```

## Steps
1. Port `packages/core/src/trace.ts` (`Run`, `TraceStep`, `ending`, `took`, `summary`, `asText`,
   `KEPT`), cited. Prune to 200 / 30 days on `end`.
2. Redact (`redact::redact_json`, `redact_text`) args, results, notes and summaries before any
   write; results cut to 2000 chars.
3. `RunStep.summary` is v2's one-line summary, redacted (INTERFACES §4).
4. `resume` (phase review 4 finding 1): `live_begin` is a plain INSERT on `run_id` (store, merged),
   so a resumed run must never call it. `resume` updates the surviving row with `live_touch` and
   starts its step counter at `steps_done`. The crashed run's `runs` body was never saved
   (`save_run` happens at `end`), so the resumed body starts fresh with the note; `save_run` is an
   upsert, so `end` writes one row for the run id.

## Tests
