# P2-02: MCP host P2 interfaces: host calls, reviewed, wasm stub

Model: opus
Depends on: P2-01
Feature IDs: SP-10, TR-06, EX-12, MO-06, MO-07 (the mcp shapes they need)

## Goal
After this task `alexia-mcp` has every public shape P2 needs, so P2-18, P2-21, P2-22, P2-23 and
P2-24 can be built against it: core can answer a capability itself (`Upcalls::host_call`), a
hosted tool says whether it was reviewed, a plugin can be reloaded, and `entry.run == "wasm"`
has a home (`wasm.rs`, stub). `wasmtime` and `wasmtime-wasi` are in the lock file.
