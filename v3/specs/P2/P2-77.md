# P2-77: Router: a local job never leaves the computer; compare redacts with notes, stops on cancel, counts its usage

Model: opus
Depends on: P2-68, P2-73
Feature IDs: TR-04, MO-10, MO-12, MO-14; phase review 6 finding 6; review follow-ups from P2-36

## Goal
- **Local pins go to the cloud** (finding 6, `alexia-core/src/router.rs:531-562`). For
  `Job::Local` (`alexia/local`, "kept on this computer"), the pin loop queues a pinned catalog
  model (`provider/model`) or a `subscription:` pin without checking `is_local`. Only the ranked
  loop is guarded. A pin on the local job sends a private request to the cloud: redacted, but no
  longer private.
- **Compare** (`alexia-core/src/compare.rs`):
  - `ask` joins `provider.chat` with the collector and never selects on `cancel`, so a provider
    that ignores the token keeps `/compare` waiting after a stop.
  - `redact_request_known(..).0` drops the redaction kinds, so the owner never gets the
    "Removed … before sending." note the race gives.
  - `record_answer(.., &Attribution::default())` writes usage rows with no session.

After this task a local job only ever runs on a local model, and a comparison stops on a stop,
says what it removed, and is counted against its conversation.

## Steps
1. Pin loop: when `ask.job == Job::Local`, a found candidate that is not `self.is_local(..)` is
   skipped with the note `"Skipped the pinned model {pin}: this job stays on this computer."`.
2. `compare::ask`: `tokio::select!` the joined chat/collector against `cancel.cancelled()`; on
   cancel return `ProviderError::Cancelled` and record no try.
3. Keep the redaction kinds from both requests and turn them into `notes` with the same wording
   the race uses (reuse its helper if it is reachable from `compare.rs`; do not copy it).
4. `record_answer` gets `Attribution { session, ..Default::default() }`.
5. If P2-25's `commands.rs` calls `compare`, pass the turn's session and append `notes` to the
   reply as the agent appends router notes.
