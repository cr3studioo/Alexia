# P2-13: The safety checker

Model: opus
Depends on: P2-01
Feature IDs: TR-02

## Goal
After this task, in *Watch and warn me*, every call the fixed rules let run is reviewed by a
second model asked narrow yes/no questions (v2 `QUESTIONS`), and a flagged call stops for the
owner. After 3 blocks in a row or 20 in a session the checker gives up and the mode falls back to
asking (v2 `GIVE_UP`). The checker never replaces the rules.

## Touch only these paths
- `v3/crates/alexia-core/src/checker.rs`
- `v3/crates/alexia-core/tests/checker.rs` (create)

## Must not touch
Everything else.

## Interfaces
```rust
pub const QUESTIONS: &[&str];
pub struct GiveUp { pub in_a_row: u32, pub in_a_session: u32 }
pub const GIVE_UP: GiveUp = GiveUp { in_a_row: 3, in_a_session: 20 };
#[derive(Default)] pub struct Tally { pub in_a_row: u32, pub in_a_session: u32 }
pub struct Review { pub answers: Vec<Option<bool>>, pub flagged: bool, pub why: Option<String> }
/// `model`: the local checker model (P2-34) as a Provider and its id. None: no checker can run.
pub struct Checker { /* ... */ }
impl Checker {
    pub fn new(model: Option<(Arc<dyn Provider>, String)>) -> Checker;
    pub fn set_model(&self, model: Option<(Arc<dyn Provider>, String)>);
    /// None when no model can run now; the caller then asks the owner instead.
    pub async fn review(&self, step: &Step, task: &str, scope: &Scope, cancel: CancellationToken) -> Option<Review>;
}
pub fn read_answers(said: &str) -> Review;
pub fn as_ruling(review: &Review, step: &Step, tally: &Tally) -> Ruling;
pub fn counted(tally: Tally, review: &Review) -> Tally;
pub fn given_up(tally: &Tally) -> bool;
```

## Steps
1. Port `packages/core/src/checker.ts` (questions, prompt, `readAnswers`, `asRuling`,
   `counted`, give-up) with v2's sentences.
2. The checker's prompt carries the step's tool, words and redacted arguments (`redact::redact_text`
   when P2-14 lands; until then call the stub, which P2-14 fills), and the task text, never
   history.
3. A model error, a timeout (20 s) or an unreadable answer is `None` (ask the owner), never a
   silent pass.

## Tests

`timeout_asks`, `three_in_a_row_gives_up`, `twenty_in_session_gives_up`, `no_model_is_none`.
