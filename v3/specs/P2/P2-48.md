# P2-48: Hub: the P2 CLI verbs

Model: opus
Depends on: P2-38
Feature IDs: TR-03, TR-08, AC-10, AC-12, MO-05, MO-09, MO-13, MO-14, TR-01, TR-09; phase review 4 finding 7 (P2-38 split)

## Goal
After this task the owner can see and steer the P2 core from the command line: the activity log,
runs and their replay, pending approvals, local models and pins per job, game folders, scope
folders, database encryption, and a plugin's `password` setting. P2-38 does the wiring and
deletes the bridge. This task adds only the verbs.

## Touch only these paths
- `v3/crates/alexia-hub/src/main.rs` (CLI parsing and the verbs' bodies only, not `run`'s wiring)
- `v3/crates/alexia-hub/tests/cli_p2.rs` (change; P2-38 created it)

## Must not touch
Library crates, `Cargo.toml`, `Cargo.lock`, `bridge.rs`, `media.rs`, `v3/ci/invariants.mjs`,
`tests/telegram_e2e.rs`, `tests/agent_e2e.rs`, `tests/v2_plugins.rs`.

## Interfaces
CLI added (INTERFACES §2.6):
```
alexia-hub activity [--last N] [TEXT]     AC-12: one line per audited call, newest first
alexia-hub runs [--last N] | runs show <id>   TR-08: list runs; replay one as text
alexia-hub approvals                       AC-10: pending questions with ids
alexia-hub models [list]                   installed local models, pins per job, fit on this GPU
alexia-hub models import <repo> <quant> | models import-file <path>   MO-13
alexia-hub models use <job> <model|subscription:<cli>|local:<id>|auto>   MO-14, MO-05
alexia-hub models games add|list|remove <folder>   MO-09
alexia-hub scope add|remove|list <folder>  TR-01 folders
alexia-hub encrypt                         TR-09 (refuses while the hub runs)
alexia-hub secret set|clear <plugin>.<key>  TR-03: a plugin's declared `password` setting
```

## Steps
1. Each verb calls the library function that its task wrote: `trace::activity`/`replay`, the
   store's runs and approvals, the `local`/`hf`/`gpu`/`router` pins, `permissions::scope` plus the
   scope kv, and `encrypt`. Only parsing and printing live here.
2. `secret set <plugin>.<key>` is allowed only for a key that a discovered manifest declares as
   `password` (`Manifest::password_keys` over `McpHost::scan`). It is stored as `<plugin>.<key>`.
   An unknown key gets P2-10's sentence and what was typed is never echoed.
3. Add `USAGE` help text for every new verb.
