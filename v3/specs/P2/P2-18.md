# P2-18: Tooling over the MCP host

Model: opus
Depends on: P2-02
Feature IDs: SP-01, SP-14 (tool progress), AC-11 (reads `alexia/undo`)

## Goal
After this task the agent has a `Tooling` that lists every enabled plugin's visible tools plus
core's builtins, re-asked each step, and calls them with the conversation context, progress and
cancellation. A result becomes a `ToolOutcome` the v2 way: text blocks joined, `resource_link`s as
produced files, `alexia/final`, `alexia/card`, and (new) `alexia/undo`. A plugin that vanished
mid-task is an outcome the model re-plans around, not an error.

## Touch only these paths
- `v3/crates/alexia-core/src/tools.rs`
- `v3/crates/alexia-core/tests/tools.rs` (create)

## Must not touch
Everything else (`alexia-mcp` is used, not changed).

## Interfaces
```rust
pub struct McpTooling { /* host, builtins */ }
impl McpTooling { pub fn new(host: McpHost, builtins: Vec<Arc<dyn Builtin>>) -> McpTooling;
                  pub fn add_builtin(&self, b: Arc<dyn Builtin>); }
impl Tooling for McpTooling { /* ... */ }
/// `<plugin id>__<tool>`, v2's namespacing; a builtin keeps its own name.
pub fn namespaced(plugin: &PluginId, tool: &str) -> String;
pub fn outcome_of(result: &CallToolResult) -> ToolOutcome;
/// v2 `toolWords`.
pub fn tool_words(name: &str, description: Option<&str>) -> String;
```

## Steps
1. Port `packages/core/src/tooling.ts` (`PluginTooling`, `outcomeOf`, `stagesOf`,
   `PROGRESS_CEILING_MS`) and `trace.ts` `toolWords`, cited.
2. `list()`: `host.tools()` minus `hidden`, plus builtins; `reviewed` from `HostedTool.reviewed`.
3. `call()`: split the namespaced name; `CallCtx.conversation = session id`, `cancel` from the
   ctx, progress frames forwarded as one-line strings; `alexia/call-context` as V3-0 already sets.
   `CallError::Gone` → `ok:false` "That tool is gone (its plugin was removed). Plan without it.";
   `Off`/`Timeout`/`Rpc` → their sentences; unknown name → "There is no tool called …".
4. `alexia/attachmentInputs` on a tool and `alexia/attachmentContext` on the call: pass through as
   v2 does (port the part of `tooling.ts` that sets them).
