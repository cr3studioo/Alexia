# P2-04: Tools on the OpenAI-compatible wire

Model: opus
Depends on: P2-01
Feature IDs: SP-01; phase review 3 finding 4

## Goal
After this task `OpenAiCompat` can serve the agent loop: a request with tools is sent with
OpenAI's `tools`, assistant turns carry `tool_calls`, tool turns carry `tool_call_id`, and a
streamed answer's tool calls are assembled and come out as `ChatChunk::ToolCall`. Today it
refuses any request with tools and drops tool-role turns (`openai.rs:153`, `:272`).

## Touch only these paths
- `v3/crates/alexia-core/src/openai.rs`
- `v3/crates/alexia-core/tests/openai.rs`

## Must not touch
`router.rs`, `catalog.rs`, `provider.rs`, other crates.

## Interfaces
Unchanged (`Provider for OpenAiCompat`). On the wire:
```json
{"tools":[{"type":"function","function":{"name":"<wire name>","description":"…","parameters":{…}}}],
 "messages":[{"role":"assistant","content":"…","tool_calls":[{"id":"…","type":"function",
              "function":{"name":"<wire name>","arguments":"<json text>"}}]},
             {"role":"tool","tool_call_id":"…","content":"…"}]}
```

## Steps
1. Port `packages/core/src/provider.ts`'s tool mapping and stream assembly (cite the functions
   in the code comment): `MessageBody.calls` → `tool_calls`; `call_id` → `tool_call_id`; streamed
   `delta.tool_calls[i]` pieces (`id`, `function.name`, `function.arguments`) joined per `index`
   and emitted as one `ChatChunk::ToolCall` each when the stream ends (`finish_reason` or `[DONE]`).
2. **Wire names.** OpenAI names must match `^[a-zA-Z0-9_-]{1,64}$`; core tool names may hold `.`
   (builtins like `schedule.add`) and be longer. Map each name to a wire-safe one per request
   (replace other characters with `_`, cut to 64 with a short hash suffix on collision) and map
   back on the way in; a tool call naming an unknown wire name is passed through unchanged so the
   loop reports it as an unknown tool.
3. A tool turn whose call id has no matching assistant call in the request is sent as a user
   note ("A tool answered: …") rather than dropped, so strict providers don't 400 (v2 P1-24 rule:
   every call id has a result, and every result a call).
4. Image parts keep working beside tools.
5. Remove the "refuses tools" branch and P1-22's note's workaround.
