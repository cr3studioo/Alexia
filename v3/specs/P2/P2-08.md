# P2-08: Media takes a cancel token

Model: sonnet
Depends on: P2-07
Feature IDs: CH-05 carried over; phase review 3 finding 11

## Goal
After this task Stop ends a voice transcription or a spoken reply that is still running. `Media`
takes the turn's `CancellationToken`, and the hub's `McpMedia` passes it to
`call_capability` instead of `CancellationToken::new()`.

## Touch only these paths
- `v3/crates/alexia-gateway/src/{channel.rs, voice.rs, gateway.rs}`
- `v3/crates/alexia-gateway/tests/ask_voice.rs`
- `v3/crates/alexia-hub/src/media.rs`

## Must not touch
`ask.rs`, `channels/`, core, hub `main.rs`.

## Interfaces
```rust
#[async_trait] pub trait Media: Send + Sync {
    async fn transcribe(&self, file: &InFile, cancel: CancellationToken) -> Result<Option<String>>;
    async fn speak(&self, text: &str, cancel: CancellationToken) -> Result<Option<OutFile>>;
}
```

## Steps
1. Change the trait and its fakes; the gateway passes the turn's token (a child of it).
2. `McpMedia` sets `CallCtx.cancel` from it. A cancelled call returns `Error::Cancelled`.

## Tests
`cancel_ends_a_slow_transcription`: a fake media that waits on its token; Stop while
transcribing → returns within 100 ms, no turn reaches the brain.
