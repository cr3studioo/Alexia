# P2-36: Compare two models

Model: sonnet
Depends on: P2-17
Feature IDs: MO-10

## Goal
After this task `/compare <question>` asks the two best free models the same question at once,
shows both answers labelled A and B with their model names, and the owner keeps one (buttons, or
"/keep a"). The kept answer is stored in the conversation as the reply; the other is dropped.

- `v3/crates/alexia-core/src/compare.rs`
- `v3/crates/alexia-core/tests/compare.rs` (create)
- `v3/crates/alexia-core/src/router.rs` (change; CEO 2026-11-21: only pub(crate) visibility and shared bookkeeping helpers such as record_request/record_answer that the race also uses)

## Must not touch
Everything else.

## Interfaces
```rust
pub struct Compared { pub a: (String /* model */, String /* text */), pub b: (String, String), pub a_failed: bool, pub b_failed: bool }
/// Two different providers, run fully in parallel (not a hedge: both finish).
pub async fn compare(router: &Router, req: &ChatRequest, cancel: CancellationToken) -> Result<Compared, ProviderError>;
/// The reply text with both answers and the question "Keep A or B?"
pub fn present(c: &Compared) -> String;
```

## Steps
1. Take the top two of `router.ranked_for` from different providers; call each `Provider::chat`
   directly with the redacted request (`redact::redact_request`); record both tries.
2. Keeping: `commands.rs` (P2-25) asks `Ask::confirm`-style with two buttons through the agent's
   asker ("A" = yes, "B" = no) and appends the kept text; this module only produces and presents.
