# P2-11: Channels exception narrowed to service names

Model: sonnet
Depends on: P2-01
Feature IDs: invariant 1; phase review 3 finding 6

## Goal
After this task check 1 no longer skips `crates/alexia-gateway/src/channels/` wholesale. A
plugin-folder name in that folder passes only (a) in `channels/<svc>/` when the name equals
`<svc>`, the service the file speaks to, or (b) on a line marked `// invariant: v2 import`
(INTERFACES §8 item 9, written by P2-01). `channels::v2_secret_names` carries that marker.

## Touch only these paths
- `v3/ci/invariants.mjs`
- `v3/crates/alexia-gateway/src/channels/mod.rs` (the marker comment only)

## Must not touch
Other source files.

## Interfaces
None.

## Steps
1. In check 1, replace the `channels/` skip with the two rules above.
2. Add `// invariant: v2 import` to the `v2_secret_names` table line(s).
3. A self-test in `invariants.mjs` (its existing pattern): a temporary file naming a plugin in
   `channels/mod.rs` without the marker fails; with it passes; `channels/telegram/` naming
   `telegram` passes; naming `voice` fails.
