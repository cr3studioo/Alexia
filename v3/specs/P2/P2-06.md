# P2-06: The asker exists before the gateway

Model: opus
Depends on: P2-01
Feature IDs: CH-07 carried over, AC-10 groundwork; phase review 3 finding 2 (and 12, gateway helper)

## Goal
After this task the hub can build the approval asker first, hand it to the `Agent`, and only then
build the `Gateway` with the agent as its brain. Today `Gateway::new` needs the brain and
`asker()` exists only after it, a cycle V2Bridge papered over with `set_ask`.

## Touch only these paths
- `v3/crates/alexia-gateway/src/{lib.rs, gateway.rs, ask.rs}`
- `v3/crates/alexia-gateway/tests/{gateway.rs, ask_voice.rs}`

## Must not touch
`channels/`, `channel.rs`, `voice.rs`, core, hub (the hub still compiles: see step 4).

## Steps
1. Make `ask.rs`'s `Channels` the public `ChannelSet`; `Asker` public, built from it.
2. `Gateway::with_channels` takes the set; `Gateway::add` pushes into it.
3. Replace `gateway.rs`'s private `ms_since` with `alexia_core::ms_since` (review 12).
4. The hub's `main.rs` must still compile untouched: keep `Gateway::new` and `asker()` as thin
   wrappers (`asker()` returns `Asker::new(self.channels.clone(), store, bus)`), each marked
   `// P2-38 deletes this`.
