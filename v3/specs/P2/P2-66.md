## Goal
`alexia-mcp`'s tests leave a folder in `%TEMP%` per test, each with a copy of the `mcp-fixture`
executable (several MB). Every `root(tag)` helper removes the folder before the test and never
after: `tests/alexia_layer.rs:20`, `compute.rs:27`, `host.rs:20`, `manifests.rs:13`,
`purge.rs:107/174/242`, `reload.rs:19`, `supervise.rs:23`, `types_p2.rs:34`, `wasm.rs:24`.
Only `tests/manifest.rs` (`Scratch`, line 298) cleans up.

After this task the crate's tests leave nothing in `%TEMP%`.

   `("purge-fail")`.
