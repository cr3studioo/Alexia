# P2-40: Every v2 plugin on the Rust host

Model: sonnet
Depends on: P2-38
Feature IDs: SP-01, EX-01 carried over (PHASE.md done-when 3)

## Goal
After this task the `v2-conformance` test proves every v2 plugin works through the Rust host with
the Rust agent behind it: every folder under `plugins/` loads and lists its tools, `hello`'s
sampling round trip answers with and without `alexia/tools`, `crasher` and `vanisher` behave as
checks 3 and 4, and the vanisher mid-task is re-planned around.

## Touch only these paths
- `v3/crates/alexia-hub/tests/v2_plugins.rs`

## Must not touch
Anything else, including `plugins/` and every v2 path.

## Interfaces
None. Runs with `--features v2-conformance`, Node and a built checkout (`pnpm install && pnpm build`).

## Steps
1. Discover every plugin folder from the checkout at test time (never a hard-coded list: invariant 1).
   Each: enabled, `tools()` non-empty or the manifest declares none, no `Refused`/`Unhealthy`.
2. `hello` sampling: drive a tool of `hello` that calls `sampling/createMessage` (read its source to
   find it; if none does, call `Upcalls::sample` through the host as the plugin would and say so),
   with fake providers; then with `_meta["alexia/tools"] = true`.
3. `vanisher` during an agent run: the folder deleted between steps → the next step's request has
   no vanisher tools and the run still answers.
4. Plugins needing secrets or hardware (voice, computer…) only need to load and list; record in the
   report which ones were only listed.

## Tests
The above in `v2_plugins.rs`.

## Done when
- `cargo fmt --all --check` passes in v3/
- `cargo clippy --workspace --all-targets -- -D warnings` passes in v3/
- `cargo test --workspace` passes in v3/
- `node v3/ci/invariants.mjs` passes from the repo root
- On the PC: `cargo test -p alexia-hub --features v2-conformance --test v2_plugins` passes, output in the report

## Notes for the worker
- Plugin ids may appear in test code only as values read from manifests, never as literals, except
  the three fixtures v2 itself ships for conformance (`hello`, `crasher`, `vanisher`), which
  INTERFACES §7 V2 names.
