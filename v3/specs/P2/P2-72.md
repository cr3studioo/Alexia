# P2-72: Agent exposes its parts

Model: sonnet
Depends on: P2-20
Feature IDs: none

## Goal
Modules built on the agent loop (commands P2-25, upcalls P2-21, resume P2-26, helpers P2-27,
undo P2-28) need the Agent's router, tools, bus, ask and layout. They are in the private
`parts` field with no accessor. Add one read-only accessor so those tasks never edit agent.rs.

## Touch only these paths
- v3/crates/alexia-core/src/agent.rs   (change: add one method)
- v3/crates/alexia-core/tests/agent.rs (change: add one test)

## Must not touch
Every other file. No other change to agent.rs: no field, visibility or behaviour change.

## Interfaces
```rust
impl Agent {
    /// The parts the agent was built from (router, tools, store, bus, ask, checker, caps,
    /// layout, limits, host). Read-only.
    pub fn parts(&self) -> &AgentParts;
}
```

## Steps
1. Add `parts()` next to the existing `store()` / `host()` accessors.
2. Add the test.

## Tests
- `parts_exposes_what_agent_was_built_from`: build an Agent the way the existing tests do, and
  assert `Arc::ptr_eq(&agent.parts().store, agent.store())` and that `parts().limits` equals the
  limits passed in (or another field the test fixture sets).
