# P2-22: MCP: compute/run locally, host-answered capabilities

Model: opus
Depends on: P2-02
Feature IDs: SP-01 (plugins keep working), MO-06, MO-07 (the host half)

## Goal
After this task `alexia/compute/run` works on the hub: a plugin asks for a compute capability and
the host runs the hidden compute tool of the enabled plugin that declares that operation, on this
machine (V3-4 adds paired devices). And `alexia/capability/call` falls through to
`Upcalls::host_call` when no plugin provides the capability, with `answers()` counting
`host_caps()`.

## Touch only these paths
- `v3/crates/alexia-mcp/src/{serve.rs, host.rs, bin/mcp-fixture.rs}`
- `v3/crates/alexia-mcp/tests/compute.rs` (create)

## Must not touch
`supervise.rs`, `conn.rs`, `wasm.rs`, other crates.

## Interfaces
Wire (INTERFACES §3.4): `alexia/compute/run {cap, arguments?, inputs?:[{name,path,mime}]}` →
`{text?, files:[abs path]}`. Rust: no new public items beyond P2-02's.

## Steps
1. Port v2's local compute path (`packages/core/src/compute/` `service.ts`/`workers.ts`, the
   local branch only), cited: find the provider by `manifest.compute.operations[].cap`, call its
   tool carrying `_meta["alexia/compute"] = {op}`, map the result's `resource_link`s to files
   copied into the caller's own dir.
2. `call_capability`: plugins first; none → `up.host_call(...)`; still none → `-32050`.
   `answers(cap)` true if a manifest provides it or `host_caps()` lists it.
3. Inputs: paths must be inside the caller's own dir or uploads (refuse others, -32602).

## Tests

`host_call_used_when_no_plugin`, `plugin_wins_over_host`, `answers_counts_host_caps`.
