# P2-20: The agent loop

Model: opus
Depends on: P2-07, P2-12, P2-13, P2-14, P2-15, P2-16, P2-17, P2-18, P2-19, P2-45
Feature IDs: SP-01, TR-01, TR-02, TR-12, SP-16 (parallel tool calls), CH-08 (steering)

## Goal
After this task `Agent` is the task brain: plan → act → observe → repeat, ported from
`packages/core/src/agent.ts` `run()`. Every step re-asks the router; tool calls are gated one at
a time in the model's order and the allowed ones run together; a refusal or a failure is an
outcome the model plans around; struggle (looping, stuck, spinning, grinding) moves the next
planning step to a stronger free model; the step ceiling ends it with every dangling call
answered; Stop keeps what was written. Steer messages are read between steps.

## Steps
0. First, in its own commit (phase review 4 finding 11): fill `Agent::new`, `store`, `host`,
   `set_local_jobs` and `local_jobs` (`OnceLock<Arc<LocalJobs>>`; a second `set` is ignored with a
   warning; `local_jobs` is `self.local_jobs.get().map(|j| &**j)`), add `host` to `AgentParts` and
   `steer`/`steps_done` to `Task`, and a test `agent_builds_without_running`. P2-21/25/26/27/28's
   tests construct an Agent and need only these.
1. Port `run()` with its comments' reasons kept short and cited: `struggling` (four signals),
   `WHY` lines as notes, the two-pass gate/run (SP-16), `unanswered` for capped and stopped calls,
   `alexia/final` ending, `shape = failed ? planning : tools` as `Job::Plan` / `Job::Step`,
   `parse` of bad JSON args to `{}`. Drop every paid/pause/allowance branch (D212).
2. Each step: `tools.list()`; route with `Router::step(job)`; trim to the winner's window
   (`trim::budget_for`, use the first candidate's context as v2 does); system prompt from
   `prompt::system` with personality/profile/current context read once per run through
   `caps` (`persona.personality`, `memory.profile`, `context.current`, v2's
   `CORE_CAPABILITIES` names; none installed → stock floor); `local::see_before_cloud(self.local_jobs(), …)`
   on the messages before routing (P2-34 fills it; the stub passes through).
3. Gate per call: `permissions::rule` with `permissions::scope` read fresh each call (a boundary
   spoken mid-task applies to the next call); `Ask` → `ask.confirm(origin, Question)`; in
   *Watch and warn me*, `checker.review` on calls the rules let run, `None` → ask; checker
   tally per session, give-up → ask. Every decision → `trace.audited`.
4. Spoken boundaries: the user turn is checked with `permissions::heard`/`lifts` before the run
   starts; a new boundary is saved and acknowledged with `boundary_ack` as a note.
5. Drafts: `Phase` frames as v2 (`Choosing`, `Tool`, `Writing`), `Delta`, `Restart`; send
   `DraftFrame::Steerable` once the first step begins; between steps `task.steer.take()`: each
   message is appended as a user row and the loop continues with it.
6. Trace: `Trace::begin` at the start, `step`, `end`; a run id is `r-<ms>-<n>`. With
   `task.steps_done = Some(n)` (needs `task.run`; None there is a bug → `BrainError`):
   `Trace::resume(.., n)` instead of `begin`, the loop's step count starts at n, and the ceiling
   (`max_steps`, else `limits.max_steps`/`background_steps`) bounds the total, n included
   (phase review 4 finding 1).
7. Free models failing (v2 B9) note, minus the paid suggestion.
8. Vanisher half of check 4: a tool that is gone between steps → outcome, next step re-plans.
