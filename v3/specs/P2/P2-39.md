## Steps
`agent_e2e.rs`, each a `#[tokio::test]` against one hub process:
1. `task_calls_a_plugin_tool`: provider scripts a `hello__greet` call then an answer; the owner sees
   the answer; one `audit` row with decision `ran` (read the store file after stop).
2. `risky_call_asks_and_runs_on_approve` / `…_not_on_deny`: fixture's `undoable` `set` tool (not
   read-only) → two buttons; press Approve → runs; Deny → the answer says it did not.
3. `steer_mid_task`: a second message during step 1 reaches step 2's request (provider sees it);
   the run is not cancelled.
4. `resume_after_kill`: kill the hub after step 1 of 3, restart, the run finishes; the owner gets
   "Picking up where I stopped".
5. `scheduled_job_fires`: model calls `schedule.add` for 2 s from now; a `Say` arrives.
6. `undo_reverses`: after (2), `/undo` → fixture's `unset` called, "Undone: …".
`telegram_e2e.rs`: remove the fake v2 core; the task-lane assertions now check the fake
providers' requests instead of `/api/chat`; latency assertions unchanged.
