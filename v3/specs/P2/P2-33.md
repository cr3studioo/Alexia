# P2-33: Hugging Face import and GGUF split files

Model: opus
Depends on: P2-01
Feature IDs: MO-13, MO-02 (reads what fit needs)

## Goal
After this task the owner can bring any GGUF model to the hub: from a Hugging Face repo (a quant
picked by name, split files `-00001-of-0000N` downloaded and kept together) or from a file already
on disk. Every file is verified, its metadata (architecture, layers, context, KV size) read for
`gpu::fit`, and the model recorded as installed.

## Touch only these paths
- `v3/crates/alexia-core/src/hf.rs`
- `v3/crates/alexia-core/tests/hf.rs` (create)

## Must not touch
Everything else.

## Steps
1. Port `gguf.ts`, `hf.ts` (`repo`, `group`, `quantOf`, `resolveUrl`), `importModel.ts`, and the
   resume logic of `download.ts`, cited. HF token from `secrets::get("_core", "hf_token")` when
   set, sent only to `huggingface.co`.
2. Split files: all parts present and their headers agree, or the import fails naming the missing part.
3. An `mmproj*.gguf` in the same quant folder is the vision projector (MO-06).

## Tests

`missing_part_named`, `quant_grouping_like_v2`, `resume_after_cut` (local HTTP server cuts at
half), `digest_mismatch_deleted`, `token_only_to_hf`.
