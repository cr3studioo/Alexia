# P2-57: Local models: hashing off the runtime, cache repair, plain paths; GPU parsing and games

Model: sonnet
Depends on: none
Feature IDs: MO-08, MO-09, MO-13; review follow-ups from P2-33 and P2-32

## Goal
Edges in `hf.rs` and `gpu.rs` that their reviewers found.

`hf.rs`:
- `hash_file` reads a whole model file, several GB, inside an async fn and blocks a tokio worker.
- A damaged cache entry is never repaired. A directory or unreadable file where a model file
  should be makes `fetch` fail the same way on every retry.
- `import_file` canonicalises the path. On Windows that gives `\\?\C:\…`, which is passed on to
  llama-server, and some builds reject it.

`gpu.rs`:
- `parse_xml_processes` does not decode XML entities, so `C:\Games\A&amp;B\game.exe` never
  matches a game folder.
- `reg query` output is read as UTF-8. It is in the OEM code page, so a non-ASCII Steam or Epic
  path is mangled.
- `Watch` calls `game_over` on the first poll that sees no game. One missed poll, or an
  `nvidia-smi` that failed once, makes it step aside, then return, then step aside again.
- `parse_compute_csv` splits on the first commas, so a process path with a comma in it loses its
  memory figure.

## Steps
1. `hf.rs` `fetch` (about line 893): run both `hash_file` calls in
   `tokio::task::spawn_blocking`. Cancellation: check `cancel` before and after; a hash in
   flight is allowed to finish.
2. `fetch`: if `dest` or `part` exists but is not a regular file (a directory, say), or hashing
   it fails with an I/O error, remove it (`remove_dir_all` for a directory) and download again.
   If removing fails, return that error, as today. `import_repo_at`'s `create_dir_all` (about
   line 1027): if a file sits where the directory should be, remove it and retry once.
3. `hf.rs` `import_file` (about line 1111): strip the verbatim prefix from canonical paths
   (`\\?\C:\x` → `C:\x`, `\\?\UNC\s\x` → `\\s\x`). It is the same rule as `permissions.rs`'s
   private `unverbatim`. Copy the six lines rather than share them, with a comment naming the
   twin.
4. `gpu.rs` `parse_xml_processes` (about line 237): decode `&amp; &lt; &gt; &quot; &apos;` and
   numeric `&#N;`/`&#xH;` in every tag value.
5. `gpu.rs` `reg_query` (about line 285): read the registry in a form that is not in the OEM
   code page. Use `reg export <key> <temp file> /y`, which writes UTF-16LE, and decode it with
   `String::from_utf16`, or another way that needs no new dependency. Keep the same parsing
   above it and delete the temp file.
6. `gpu.rs` `Watch::run` (about line 406): `game_over` only after 3 polls in a row see no game.
   `step_aside` stays immediate. Make the count a `const` with a comment.
7. `gpu.rs` `parse_compute_csv` (about line 220): take the pid from the first field and the
   memory from the last (`rsplitn`). The process name is everything in between.
