# P2-74: Scheduler: no slash-command prompts; only a shutdown keeps a stopped one-shot

Model: opus
Depends on: none
Feature IDs: AC-09, TR-01; phase review 6 finding 1 (high, the scheduler half); review follow-up from P2-56

## Goal
- `Scheduler::add` (`alexia-scheduler/src/lib.rs:166`) and the `schedule.add` builtin accept any
  prompt, including one that starts with `/`. A model-made job `{prompt: "/approve 7"}` is the
  prompt-injection path of phase review 6 finding 1. P2-73 stops core from running it as a
  command; this task stops it being stored at all.
- `fire` (`lib.rs:322`) treats every `Err(BrainError::Cancelled)` as "shutdown cut the turn
  short" and puts the one-shot back as due. The brain also returns `Cancelled` when the run
  itself was stopped (`RunEnd::Stopped`) while the scheduler's token is still live, so a
  one-shot that was stopped fires again at the next start.

After this task no job can hold a slash command, and a one-shot is kept only when the
scheduler's own token was cancelled.

## Touch only these paths
- `v3/crates/alexia-scheduler/src/lib.rs` (change)
- `v3/crates/alexia-scheduler/tests/scheduler.rs` (change: add tests)

## Must not touch
Every other file, including `alexia-core` and `v3/specs/INTERFACES.md`.

## Interfaces
None. `add` returns the existing `invalid(..)` error for the new case.

## Steps
1. `add`: when `prompt.trim_start()` starts with `/`, return
   `invalid("A job's prompt is an instruction, not a command: write what Alexia should do.")`.
   The builtin passes the message to the model as today.
2. `fire`: `stopped` is `cancel.is_cancelled()` (the token `fire` was given), not the error
   variant. A `Cancelled` from the brain while the token is live is recorded as `"stopped"` in
   `job_runs`, and the one-shot is finished like any other.

## Tests
- `slash_prompt_refused` (`add` with `"/approve 1"` and with `"  /undo"`: both `Err`, no job row)
- `stopped_run_finishes_one_shot` (a fake brain returning `Cancelled` while the scheduler's
  token is live: the one-shot is gone from `jobs()`)
- P2-56's shutdown test for a cut-short one-shot still passes.

Each new test must fail without its fix.
