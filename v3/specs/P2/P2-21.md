# P2-21: Upcalls: sampling, tasks for plugins, elicit, roots, attachments

Model: opus
Depends on: P2-20, P2-02
Feature IDs: SP-01 (every plugin keeps working), TR-01 (roots), AC-10 (elicit asks)

## Goal
After this task `Agent` is core's `alexia_mcp::Upcalls`, so plugins get from the Rust hub what
v2's `serve.ts` gave them: `sampling/createMessage` answered through the router (plain), through
the agent loop (`_meta["alexia/tools"]`), or kept on this computer (`alexia/local`, with
`alexia/format`); a slash command typed into a plugin's conversation runs as a command;
`alexia/stream` progress frames; `alexia/lengths` personality sizes; `elicitation/create`
asked through `Ask`; `roots/list` from the permission scope; `alexia/attachments/*` over the
store's attachments tables.

## Touch only these paths
- `v3/crates/alexia-core/src/upcalls.rs`
- `v3/crates/alexia-core/tests/upcalls.rs` (create)

## Must not touch
`agent.rs` and every other file.

## Steps
1. Port `serve.ts`'s `sample` (≈ lines 545–760), `asTask`, `asCommand`, `privately`, `streamer`,
   `declaredFor` (min_tier and `modelPreferences` → `Job::Plan` when capable), cited.
   Plain sampling: `Router::step(Job::Step)` with the plugin's `plugin` attribution and
   `background` when nobody is watching (v2 §4 F: plugins keep off the second half of a
   day-limited tier; port `underHalf`/`spent` as a filter over `request_count`).
2. `alexia/tools` → `Agent::run` with `Task { plugin, background, origin: Origin::Desktop … }`
   on a session the plugin's conversation maps to (kv `_core.plugin_sessions`, v2's); the
   approval question goes to the owner's primary chat.
3. `alexia/local`: `Router::step(Job::Local)`; refused with v2's sentence when no local model can
   run (local providers come from P2-31/P2-34; until wired, always refused).
4. Elicit: one yes/no form → `Ask::confirm`; any other schema → v2's refusal code.
5. Attachments: port `packages/core/src/attachments/index.ts` lease/release/live/register/share
   over the store (`attachments`, `attachment_leases`), files under `layout.uploads()`.
6. Personality lengths (`alexia/lengths`): port `sizedFor`/`sizeFor` from `router.ts`.
