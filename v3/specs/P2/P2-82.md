# P2-82: MCP: a WASM start that is given up on stops the module; compute never follows a link to a network path

Model: opus
Depends on: P2-66
Feature IDs: SP-10, TR-06; review follow-ups from P2-55 and P2-61

## Goal
- **A dropped WASM start** (`alexia-mcp/src/wasm.rs:283-298`). The module runs on its own
  thread; `killed` is set and the epoch bumped only in the timeout arm. When the caller drops the
  `spawn_as` future while it waits on `ready_rx` (the host's start was cancelled, the hub is
  stopping), nothing sets `killed`, so the module thread keeps running with nobody to talk to.
- **A link to a network path** (`alexia-mcp/src/serve.rs:212`, `inside()`). `inside()` refuses a
  network path as written, then calls `std::fs::canonicalize`. A local symlink or junction whose
  target is `\\host\share\…` is followed by that call, so Windows talks SMB to the host (and can
  send the owner's NTLM hash) before the roots check refuses the result.

After this task a given-up WASM start always stops its module, and compute never touches a
network path, however it is reached.

## Steps
1. `wasm.rs`: a small drop guard created before the wait, holding `engine` and `killed`. Its
   `Drop` does `engine.increment_epoch()` and `killed.store(true)` unless disarmed; disarm it only
   on `Ok(Ok(Ok(())))`. The timeout arm then needs no code of its own.
2. `serve.rs` `inside()`: before `canonicalize`, walk the path's prefixes; for each one that is
   a symlink or junction (`symlink_metadata`), `read_link` it and refuse when the target is a
   network path (`crate::is_network_path`, also for `\\?\UNC\…`). After `canonicalize`, refuse a
   result that is `\\?\UNC\…`. A `// ponytail:` comment notes that a link created between the
   walk and the canonicalize is not covered (the plugin cannot create links outside its folder).

## Tests
- `wasm.rs`: `dropped_start_stops_module` (start the fixture, drop the future before it is ready,
  e.g. with a 1 ms `timeout` around `spawn_as`; the module thread ends: its `done` fires or the
  fixture's ticker stops within a second)
- `compute.rs`: `link_to_network_path_refused` (Windows only, `#[cfg(windows)]`: a junction or
  symlink in a root pointing at `\\127.0.0.1\nonexistent`; `compute/run` refuses it and the test
  finishes in well under the SMB timeout). Skip with a clear message if the test process may not
  create symlinks.

Each new test must fail without its fix.
