# P1-01: Core shared types, module stubs, P1 dependencies

Model: opus
Depends on: P0-15
Feature IDs: SP-03, SP-07, SP-09, D212 (types only)

## Goal
After this task `alexia-core` exports every type and trait V3-1 builds on: the brain contract
(`Turn`, `DraftFrame`, `Phase`, `Reply`, `Brain`, `Ask`, `BrainError`) and the provider contract
(`ChatRequest`, `ChatChunk`, `ChatDone`, `ProviderError`, `ModelInfo`, `Provider`, `Budget`).
It also creates every new core module of this phase as an empty stub and adds every new
dependency, so the later core tasks (P1-04..P1-08) each touch only their own file and never share
`lib.rs`, `Cargo.toml` or `Cargo.lock`.

## Interfaces
From INTERFACES.md §2.3, exactly, plus the additions marked **P1**:

```rust
// brain.rs
pub struct Turn { pub session: SessionId, pub origin: Origin, pub content: Content, pub received_at: Ms }
#[derive(Clone, Debug)]
pub enum DraftFrame { Delta(String), Restart, Phase(Phase) }
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Phase { Choosing, Asking, Retrying, Backup, Thinking, Writing, Tool }
pub type DraftSink = tokio::sync::mpsc::Sender<DraftFrame>;
pub struct OutFile { pub name: String, pub mime: String, pub path: PathBuf }
pub struct Reply { pub text: String, pub files: Vec<OutFile>, pub lane: Lane, pub model: Option<String>, pub spans: Vec<Span> }
#[derive(Debug, thiserror::Error)]
pub enum BrainError {
    #[error("{0}")] Unavailable(String),
    #[error("stopped")] Cancelled,
    /// P1: the chat lane decided this turn needs tools; nothing was shown or stored yet.
    #[error("needs the task lane")] NeedsTask,
    #[error(transparent)] Other(#[from] Error),
}
#[async_trait::async_trait]
pub trait Brain: Send + Sync {
    async fn reply(&self, turn: Turn, draft: DraftSink, cancel: CancellationToken) -> Result<Reply, BrainError>;
}
#[async_trait::async_trait]
pub trait Ask: Send + Sync {
    async fn confirm(&self, origin: &Origin, question: &Question, cancel: CancellationToken) -> bool;
}
pub struct Question { pub run: RunId, pub text: String, pub detail: Option<String> }

// provider.rs
pub struct ChatRequest { pub messages: Vec<(Role, MessageBody)>, pub system: Option<String>,
                         pub tools: Vec<alexia_mcp::types::Tool>, pub max_tokens: Option<u32> }
#[derive(Clone, Debug, PartialEq)]
pub enum ChatChunk { Text(String), Reasoning(String), ToolCall(ToolCall) }
#[derive(Clone, Debug)]
pub struct ChatDone { pub model: String, /** P1 */ pub provider: String, pub tokens_in: i64, pub tokens_out: i64,
                      pub cost: f64, pub first_byte_ms: Option<u32> }
#[derive(Debug, thiserror::Error)]
pub enum ProviderError { #[error("busy")] Busy { retry_after_ms: Option<u64> }, #[error("needs a key")] NeedsKey,
                         #[error("refused: {0}")] Refused(String), #[error("unreachable")] Unreachable,
                         #[error("stopped")] Cancelled, #[error("{0}")] Other(String) }
#[derive(Clone, Debug)]
pub struct ModelInfo { pub id: String, pub context: u32, pub free: bool, pub tools: bool, pub vision: bool }
#[async_trait::async_trait]
pub trait Provider: Send + Sync {
    fn id(&self) -> &str;
    async fn models(&self) -> Result<Vec<ModelInfo>, ProviderError>;
    async fn chat(&self, req: &ChatRequest, model: &str, out: tokio::sync::mpsc::Sender<ChatChunk>,
                  cancel: CancellationToken) -> Result<ChatDone, ProviderError>;
}
/// P1, SP-07: how long a channel can wait for the first byte. The router starts another
/// candidate each time this passes with nothing back (P1-06).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Budget { pub first_byte_ms: u32 }
impl Budget { pub const CHAT: Budget = Budget { first_byte_ms: 2_500 }; }
```

`lib.rs` re-exports: `pub use brain::*; pub use provider::*;` and declares
`pub mod openai; pub mod free; pub mod catalog; pub mod router; pub mod lane; pub mod chat;`.
`Turn`, `Reply`, `OutFile`, `Question`, `ChatRequest` derive `Clone, Debug`.

## Steps
1. Workspace `reqwest` gains the `multipart` feature (Telegram uploads, P1-09). Nothing else in
   `v3/Cargo.toml` changes.
2. `alexia-core/Cargo.toml`: add `async-trait`, `tokio-util`, `tracing`, `reqwest` (workspace).
   Why: the traits are used as `dyn` (§0.7), cancellation is a `CancellationToken`, the
   providers speak HTTPS. No other new crate: SSE is parsed by hand from `Response::chunk()`.
3. Write `brain.rs` and `provider.rs` as above.
4. Each stub file is the SPDX line and a `//!` line saying which task fills it
   (`//! P1-06: Router::hedged.`). Nothing else, so no `dead_code` warnings.
5. Write all five of PHASE.md's *INTERFACES.md additions* into INTERFACES.md (§2.3 for the
   core ones, §2.4 for the gateway ones, copying the shapes from P1-02's *Interfaces*, §5.3 for
   migration 2 as P1-03 defines it, §1.1 for the dashboard, §0.3 and §2.6 for item 5 from P1-03,
   P1-13 and P1-17's *Interfaces*), each marked `(V3-1)`. This task
   is the only P1 task that edits INTERFACES.md.
6. `cargo build --workspace` so `Cargo.lock` records reqwest's tree; commit the lock.
