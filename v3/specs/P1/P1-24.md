# P1-24: v2 agent: dangling tool ids at the ceiling

Model: sonnet
Depends on: none
Feature IDs: SP-16

## Goal
When the step ceiling cuts a turn partway through its calls, every call still gets a tool
result. In `packages/core/src/agent.ts` (the gate loop around `:928`), the loop `break`s with
`capped = true` once `steps.length >= ceiling`, and only the `gated` calls get a `role: 'tool'`
row before `return finish('ceiling')` (`:962`). The assistant row stored just before holds every
call id, so the session's history now has call ids with no result, and the next turn on a strict
provider is refused. After this task each call that was not run gets
`{ role: 'tool', callId, content: 'not run: step limit reached' }`, pushed and stored like the
others, before `finish('ceiling')`.

## Touch only these paths
- `packages/core/src/agent.ts`   (change)
- `packages/core/test/agent.test.ts`   (change)

## Must not touch
Everything under `v3/`, the rest of `packages/core` (`router.ts`, `provider.ts`, the store),
other packages and plugins.

## Interfaces
Unchanged. Uses the existing `Message` shape: `{ role: 'tool', callId: string, content: string }`,
and the result's `ended: 'ceiling'`.

## Steps
1. Replace `if (capped) return finish('ceiling')` (`:962`) with: when `capped`, for each
   `call` in `calls.slice(gated.length)` (in the model's order), build
   `const result: Message = { role: 'tool', callId: call.id, content: 'not run: step limit reached' }`,
   then `messages.push(result)`, `added.push(result)`, `store.append(session, result)` exactly
   as the loop above does; then `return finish('ceiling')`.
2. Do not emit `on.step` / `on.done` for the calls that were not run (they are not steps, and
   the ceiling counts steps).

## Tests
In `packages/core/test/agent.test.ts`:
- `the ceiling inside one turn runs what fits, then stops on the ceiling` (`:1188`): the tool
  row count becomes 3 (was 2); `tools.calls` is still `['notes.a', 'notes.b']`.
- New `the ceiling leaves no call without a result`: same script (`notes.a`, `notes.b`,
  `notes.c`, `maxSteps: 2`). From `store.history(session)`: the ids of every assistant row's
  `calls` equal, in order, the `callId`s of the tool rows; the last tool row's content is
  `'not run: step limit reached'`; no model turn followed (`served` has length 1).
- New `a ceiling hit before a turn's first call still answers it`: the `forever` script of
  `a model that will not stop meets the ceiling…` (`:276`, one `notes.read` call per turn,
  `maxSteps: 4`). The fifth turn's call is capped with nothing gated: `result.ended` is
  `'ceiling'`, `result.steps` has length 4, the history has 5 tool rows whose `callId`s equal
  the assistant rows' call ids in order, and the last is `'not run: step limit reached'`.
