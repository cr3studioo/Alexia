# P1-07: Lane classifier and the Lanes brain

Model: opus
Depends on: P1-01
Feature IDs: SP-03

## Goal
After this task core decides, in microseconds and without a model, whether a turn is plain chat
or a task, and `Lanes` is the `Brain` the gateway holds: chat turns go to the fast chat brain,
everything else to the task brain (the v2 bridge in V3-1, the Rust agent in V3-2). When the chat
brain says a turn needs tools after all (`BrainError::NeedsTask`), `Lanes` hands the same turn to
the task brain, so a wrong guess costs one short model call and never a wrong answer. This is how
"plain chat never enters the agent loop" holds without "tasks never get one".

## Interfaces
```rust
/// Rules only (Alexia.md *The model router*: "rules plus manual override"; a learned classifier
/// is a trap this early). `Command` for a leading `/`; `Task` when any rule below fires; else `Chat`.
pub fn lane(content: &Content) -> Lane;

pub struct Lanes { /* chat, task */ }
impl Lanes {
    pub fn new(chat: Arc<dyn Brain>, task: Arc<dyn Brain>) -> Lanes;
}
#[async_trait::async_trait]
impl Brain for Lanes {
    /// Chat → `chat.reply`; on `Err(NeedsTask)` → `task.reply` with the same turn and draft.
    /// Command and Task → `task.reply`. The returned `Reply.spans` start with
    /// `Span { name: "lane", .. }` and `Reply.lane` is the lane that actually answered.
    async fn reply(&self, turn: Turn, draft: DraftSink, cancel: CancellationToken) -> Result<Reply, BrainError>;
}
```

Task rules (any one fires):
1. `Content::Parts` with an image part (photos go to the task lane, CH-06).
2. A URL (`http://`, `https://`, or `www.`).
3. More than 400 characters, or more than 3 lines.
4. An imperative or request about the world, matched case-insensitively at a word boundary from
   a short list kept in `lane.rs`: remind, remember, schedule, search, look up, find, open,
   send, email, call, book, buy, order, download, install, run, create, make, write a, draft,
   summarise/summarize, translate, convert, set a timer, set an alarm, turn on, turn off,
   what's on, weather, news, price, latest, today's, tomorrow's, calendar, file, folder,
   screenshot, my screen. English plus the owner's Czech equivalents (připomeň, najdi, pošli,
   otevři, napiš, vyhledej, počasí, zprávy, kalendář).
5. A question about something the model can't know without looking: "what time", "how much
   is", "who won", "did … reply", "is it raining".

## Steps
1. Write `lane` with the lists as `const` slices; one pass over the lowercased text.
2. Write `Lanes`. The `"lane"` span measures `lane()` itself plus, on escalation, the time the
   chat brain spent before giving up (named `"chat-escalated"`), so the dashboard shows what a
   wrong guess cost.
3. On escalation nothing reaches the draft from the chat brain (P1-08 guarantees it: it decides
   before forwarding any text), so `task.reply` gets the same `DraftSink`.
