# P1-19: Watchdog hardening

Model: sonnet
Depends on: P1-16
Feature IDs: HB-12

## Goal
The P1-16 review found four weak spots in v3/crates/alexia-hub/src/watchdog.rs. After this task a
cancelled service gets a short graceful shutdown, the boot check spawns no process when there is
no gap, schtasks errors say what really failed, and a killed hub comes back within about a minute.

## Touch only these paths
- v3/crates/alexia-hub/src/watchdog.rs   (change)

## Must not touch
main.rs, Cargo.toml, other crates.

## Interfaces
No public signature changes.

## Steps
1. ~:151-153: on cancel, select! drops the service future at once, so its child token never gives
   it a graceful stop. After cancel, keep awaiting the future for up to 5 s, then drop it.
2. ~:96: offline_gap spawns PowerShell for the UTC offset on every call. Only work out the offset
   once a gap has been found.
3. ~:246: every non-zero schtasks exit becomes the "run this from an Administrator terminal"
   sentence. Say that only for access denied (exit code 1 with no task created is not proof:
   check the error text schtasks prints, or the /Create vs /Run step). For a failed /Run after a
   successful /Create, say the task was registered but did not start. Otherwise give the exit code.
4. ~:211: Task Scheduler's RestartOnFailure fires mainly when the task fails to launch, not when a
   running hub is killed. Add a repetition trigger every 1 minute (indefinitely) to the task XML.
   MultipleInstancesPolicy IgnoreNew already stops a second copy.
5. ~:254: an empty USERDOMAIN gives "\user". Use COMPUTERNAME then, or the plain user name.

## Tests
- cancelled_service_gets_grace: a service that sees its token cancelled and sets a flag before
  returning; the flag is set after supervise returns.
- task_xml_has_repetition: the XML holds a 1-minute repetition interval.
- user_id_without_domain: the user id is never "\name".
- offline_gap with no heartbeat file returns None without spawning (structure the code so the
  offset is a closure or argument the test can count).
