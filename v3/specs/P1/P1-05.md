# P1-05: Free chat catalog

Model: opus
Depends on: P1-04
Feature IDs: MO-04, D212

## Goal
After this task core knows which free models can hold a chat right now: each usable provider's
model list, fetched at start and every six hours (v2 D161), filtered to free text-chat models the
way v2's catalog does, and cached to disk so the hub works the moment it boots and when a list
endpoint is down. The router (P1-06) picks its candidates from here.

## Touch only these paths
- `v3/crates/alexia-core/src/catalog.rs`   (fill the stub)
- `v3/crates/alexia-core/tests/catalog.rs`   (create)

## Must not touch
`openai.rs`, `free.rs`, `router.rs`, `lib.rs`, other crates, `packages/`.

## Interfaces
```rust
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct Candidate { pub provider: String, pub model: String, pub context: u32,
                       /** a size in billions read from the id, v2 `sizeOf` */ pub size_b: Option<f32>,
                       pub router: bool }

pub struct Catalog { /* providers, cache path, RwLock<Vec<Candidate>> */ }
impl Catalog {
    pub const REFRESH_MS: u64 = 6 * 60 * 60 * 1000;
    /// Loads `cache` if it exists (a missing or unreadable file is an empty catalog, not an error).
    pub fn new(providers: Vec<Arc<dyn Provider>>, rows: Vec<FreeRow>, cache: PathBuf) -> Catalog;
    /// Fetch every usable provider's list now; a provider that fails keeps its cached entries.
    /// Writes the cache atomically (temp file + rename).
    pub async fn refresh(&self);
    /// `refresh` now, then every REFRESH_MS until cancelled.
    pub async fn run(&self, cancel: CancellationToken);
    pub fn candidates(&self) -> Vec<Candidate>;
    /// The ladder row for a provider id (the router reads `rpm`/`rpd` from it).
    pub fn row(&self, provider: &str) -> Option<FreeRow>;
}
/// v2's text-chat filter, ported: true for a model that holds a conversation in text.
pub fn chats(model_id: &str) -> bool;
/// v2's `sizeOf`: "llama-3.3-70b" → Some(70.0); "8x7b" → Some(56.0); none → None.
pub fn size_of(model_id: &str) -> Option<f32>;
```

Cache file: `layout.cache().join("v3-free-models.json")` (the hub passes the path), a JSON
`{"fetched_at": Ms, "candidates": [Candidate]}`.

## Steps
1. Port `chats` from v2: read `packages/core/src/catalog.ts` (`parse`, `routes`, `sizeOf`,
   `stature`, and the modality checks in `parse`). Drop embeddings, speech, image, guard and
   moderation models exactly as v2 does. Keep the regexes v2 uses; cite the v2 function in a
   comment above each port.
2. A model is a candidate when `ModelInfo.free`, `chats(id)`, and its row is usable.
3. `router` comes from the row (`FreeRow.router`) or v2's `routes()` on the id.
4. Seed: if there is no cache and every fetch fails, use a seed list ported from v2's
   `SEEDED` for the providers in the ladder (only free ones), so a first boot offline still
   has something to try.

## Tests
`tests/catalog.rs` (fake providers implementing `Provider`, temp dirs):
- `chats_keeps_text_drops_others`: a table of ≥ 12 ids taken from v2's own catalog tests
  (`packages/core/test/catalog.test.ts`), with v2's expected answers.
- `size_of_matches_v2`: the same for sizes.
- `refresh_writes_and_new_reads_cache`: refresh, drop, `new` again with providers that fail →
  same candidates.
- `failing_provider_keeps_its_entries`.
- `only_free_and_usable`: a paid model and an unusable (no key) provider are excluded.
- `seed_when_nothing_answers`.
