Model: opus

## Goal
After this task `alexia-gateway` exports the channel contract (`ChatRef`, `MsgRef`, `Inbound`,
`InKind`, `InFile`, `Outbound`, `Channel`, `Media`, `GatewayConfig`, `Error`) and has every
module of this phase as a stub with its final public signatures, so P1-09..P1-12 each fill one
file. `alexia-hub` gets its three new modules as stubs and every new dependency, so P1-13,
P1-15 and P1-16 each fill one file and only P1-17 edits `main.rs` again.

## Interfaces
`channel.rs` (re-exported from `lib.rs`):

```rust
#[derive(Clone, Debug, PartialEq, Eq, Hash)] pub struct ChatRef { pub chat: String }
#[derive(Clone, Debug, PartialEq, Eq, Hash)] pub struct MsgRef { pub id: String }
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum InKind { Message, Stop }
/// A file that came with a message, already downloaded under `layout.cache()`.
#[derive(Clone, Debug)] pub struct InFile { pub name: String, pub mime: String, pub path: PathBuf }
#[derive(Clone, Debug)]
pub struct Inbound { pub chat: ChatRef, pub msg: MsgRef, pub kind: InKind, pub from_owner: bool,
                     pub content: Content, pub files: Vec<InFile>, pub at: Ms }
#[derive(Clone, Debug)]
pub struct Outbound { pub text: String, pub files: Vec<OutFile>, /** send as a voice note */ pub voice: bool }

#[async_trait::async_trait]
pub trait Channel: Send + Sync {
    fn name(&self) -> &'static str;
    /// SP-07: how long this surface can wait for a first word.
    fn budget(&self) -> alexia_core::Budget;
    async fn next(&self, cancel: CancellationToken) -> Result<Vec<Inbound>>;
    async fn react(&self, chat: &ChatRef, msg: &MsgRef, emoji: &str) -> Result<()>;
    async fn typing(&self, chat: &ChatRef) -> Result<()>;
    async fn send(&self, chat: &ChatRef, out: &Outbound) -> Result<MsgRef>;
    /// Show `text` as the message being written. `None` clears it. Rate limits come back as
    /// `Error::RateLimited`; the gateway paces itself.
    async fn draft(&self, chat: &ChatRef, text: Option<&str>) -> Result<()>;
    async fn edit(&self, chat: &ChatRef, msg: &MsgRef, text: &str) -> Result<()>;
    async fn ask(&self, chat: &ChatRef, text: &str, cancel: CancellationToken) -> Result<Option<bool>>;
}

/// Voice in and out (CH-05). The hub implements it over `McpHost::call_capability`
/// (`voice.transcribe`, `voice.render`); tests use a fake. `None` = nothing installed can do it.
#[async_trait::async_trait]
pub trait Media: Send + Sync {
    async fn transcribe(&self, file: &InFile) -> Result<Option<String>>;
    async fn speak(&self, text: &str) -> Result<Option<OutFile>>;
}

#[derive(Clone, Debug)]
pub struct GatewayConfig { pub merge_ms: u64, pub draft_every_ms: u64, pub ack_emoji: String }
impl Default for GatewayConfig { /* 500, 300, "👀" */ }

#[derive(Debug, thiserror::Error)]
pub enum Error {
    #[error("{0}")] Service(String),                         // a sentence the owner can read
    #[error("rate limited")] RateLimited { retry_after_ms: u64 },
    #[error("another program is reading this bot's messages")] Conflict,   // 409
    #[error("the token was refused")] Unauthorized,           // 401
    #[error("unreachable")] Unreachable,
    #[error("stopped")] Cancelled,
    #[error(transparent)] Store(#[from] alexia_store::Error),
}
pub type Result<T> = std::result::Result<T, Error>;
```

## Steps
1. `alexia-gateway/Cargo.toml`: `alexia-store`, `alexia-core` (already), plus workspace `tokio`,
   `tokio-util`, `async-trait`, `serde`, `serde_json`, `thiserror`, `tracing`, `reqwest`. Why
   reqwest: the Telegram adapter's HTTPS (P1-09).
2. `alexia-hub/Cargo.toml`: add workspace `reqwest`, `async-trait`, `serde`, `serde_json`
   (bridge, latency) if not already present.
3. Write `channel.rs`, the stubs, and `lib.rs`: `mod channel; pub use channel::*; mod gateway;
   pub use gateway::Gateway; mod ask; mod voice; pub mod channels;`.
4. In `main.rs` add `mod bridge; mod latency; mod watchdog;` and nothing else. Each stub is the
   SPDX line, a `//!` line naming the task that fills it, and `#![allow(dead_code)]` only if
   clippy needs it (it shouldn't for empty modules).
5. `cargo build --workspace`; commit the lock.
