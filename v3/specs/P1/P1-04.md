# P1-04: OpenAI-compatible provider and v2's free ladder

Model: opus
Depends on: P1-01
Feature IDs: MO-03, MO-04, D212

## Goal
After this task core can talk to every free cloud provider v2 uses through one OpenAI-compatible
`Provider` (Alexia.md *Model providers*: one interface, a provider is a config row). `free.rs`
holds v2's free ladder, ported row for row from `packages/core/src/provider.ts` `PROVIDERS`,
restricted to providers that answer for free. Streaming is real: text arrives as chunks and the
first byte is timed, which is what hedging (P1-06) races on.

## Touch only these paths
- `v3/crates/alexia-core/src/openai.rs`   (fill the stub)
- `v3/crates/alexia-core/src/free.rs`   (fill the stub)
- `v3/crates/alexia-core/tests/openai.rs`   (create)

## Must not touch
`lib.rs`, `Cargo.toml` (P1-01 added reqwest), `provider.rs`, other crates, `packages/`.

## Interfaces
Uses `Provider`, `ChatRequest`, `ChatChunk`, `ChatDone`, `ProviderError`, `ModelInfo` (P1-01),
`alexia_store::secrets::get`.

```rust
// free.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Auth { Required, Optional, None }
#[derive(Clone, Debug)]
pub struct FreeRow {
    pub id: String,                    // v2's provider id, e.g. "groq"
    pub base_url: String,              // may contain "{account}" (v2's cloudflare-ai shape)
    pub models_path: Option<String>,
    pub headers: Vec<(String, String)>,
    pub auth: Auth,
    /// The whole provider is a free tier (Groq, Cerebras…). False = only `:free` / zero-priced
    /// models are free (OpenRouter and other aggregators).
    pub all_free: bool,
    pub rpm: Option<u32>, pub rpd: Option<u32>,
    pub router: bool,                   // a "random free model" endpoint, ranked last (v2 D159)
}
/// v2's ladder, rows with a free tier only. Order is v2's.
pub fn ladder() -> Vec<FreeRow>;
/// The key for a row: `secrets::get("_core", "provider_<id>")` (v2's `keyOf`).
pub fn key_for(row: &FreeRow) -> Option<String>;
/// Test hook: if `ALEXIA_FREE_PROVIDERS` names a JSON file, rows come from it instead
/// (`[{id, base_url, models_path?, auth, all_free, rpm?, rpd?, router?}]`, `auth` as
/// `"required"|"optional"|"none"`). Used by P1-18.
pub fn configured() -> Vec<OpenAiCompat>;

// openai.rs
pub struct OpenAiCompat { /* row, key, reqwest::Client */ }
impl OpenAiCompat {
    pub fn new(row: FreeRow, key: Option<String>, client: reqwest::Client) -> OpenAiCompat;
    pub fn row(&self) -> &FreeRow;
    /// true when `auth` is None/Optional or a key is present.
    pub fn usable(&self) -> bool;
}
impl Provider for OpenAiCompat { /* POST {base}/chat/completions, stream:true */ }
```

`configured()` builds one shared `reqwest::Client` (HTTP/2 allowed, `pool_idle_timeout` 90 s,
`tcp_keepalive` 30 s, connect timeout 5 s) so connections stay warm between messages.

## Steps
1. Read `packages/core/src/provider.ts` `PROVIDERS` and port every row whose `pricing` is
   `free` or that has free variants (`openrouter`, `groq`, `cerebras`, `google`, `mistral`,
   `nvidia`, `github`, and the keyless ones v2 lists: check each row's `auth`). Keep v2's
   headers (OpenRouter's `HTTP-Referer` / `X-Title`), `rpm`, `rpd`. Skip local runners
   (`ollama`, `llama`, `mlx`: D213, the GPU is not for chat) and every paid-only row (D212).
2. `chat`: body `{model, messages, stream: true, max_tokens?}`; `system` goes first as a
   `system` message; `Content::Parts` maps to OpenAI's `[{type:"text"},{type:"image_url"}]`.
   Tools are not sent in P1 (the chat lane has none); if `req.tools` is non-empty return
   `ProviderError::Other("tools are not sent on this path")`.
   `// ponytail: no tool calls on the fast path; V3-2's agent loop adds them.`
3. Read the body with `Response::chunk()` and parse SSE by hand: `data: {json}` lines,
   `data: [DONE]` ends. `choices[0].delta.content` → `ChatChunk::Text`;
   `delta.reasoning` / `reasoning_content` → `ChatChunk::Reasoning`. `first_byte_ms` = request
   sent → first non-empty delta (text or reasoning). `usage` from the last chunk if present.
4. Timeouts (v2 D163): 30 s to the first byte, 20 s between chunks → `ProviderError::Busy`
   with `retry_after_ms: None`. A stream that ends without `[DONE]` or a finish reason is a
   failure (v2 D158), not half an answer.
5. Status mapping, as v2 does (`provider.ts`): 429 and 503 → `Busy { retry_after_ms }` from
   `retry-after`; 401/403 → `NeedsKey` (key missing) or `Refused("the key was refused")`;
   400/404/422 → `Refused(<provider's message, first 200 chars>)`; connect errors →
   `Unreachable`; cancel → `Cancelled` (drop the response so the connection closes).
6. `models()`: GET `{base}{models_path}` → `ModelInfo { free: row.all_free || id ends with
   ":free" || pricing prompt and completion are "0" }`, context from `context_length` when
   present else 8192. No filtering here (P1-05 filters).
7. Never log a key, a header value or a message body. `tracing::debug!` provider id, model,
   status, timings only.

## Tests
`tests/openai.rs`, against a fake OpenAI server on `127.0.0.1:0` written with
`tokio::net::TcpListener` (no new dev-dependency; ~60 lines writing raw HTTP/1.1 responses):
- `streams_text_chunks_in_order`: three SSE deltas → three `Text` chunks, `ChatDone` with
  `first_byte_ms` set and the provider id.
- `reasoning_is_its_own_chunk`.
- `system_goes_first_and_images_map`: the fake records the request body; assert the shape.
- `status_429_is_busy_with_retry_after`: `retry-after: 3` → `Busy { retry_after_ms: Some(3000) }`.
- `status_401_is_needs_key`.
- `stream_without_done_is_failure`.
- `first_byte_timeout`: the fake waits; with the timeout lowered through a `#[doc(hidden)]`
  constructor `OpenAiCompat::with_timeouts(.., first_byte, between)` to 200 ms → `Busy`.
- `cancel_stops_reading`: cancel after the first chunk → `Cancelled` within 100 ms.
- `ladder_has_no_paid_or_local_rows`: no row id in `["ollama","llama","mlx"]`, every row is
  `all_free` or an aggregator with free variants.
- `env_override_replaces_ladder`: `ALEXIA_FREE_PROVIDERS` pointing at a temp JSON file.
- `keys_use_v2_names`: with `ALEXIA_SECRETS_IN_MEMORY=1`, a secret `_core/provider_groq` makes
  the groq row usable.
