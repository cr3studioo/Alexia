# P1-25: One time helper; brain spans measured from the turn

Model: opus
Depends on: P1-20, P1-22, P1-23, P0-25
Feature IDs: SP-09

## Goal
Two things, one pass over the same lines.

1. **Every brain span lands about 1.7e12 ms out (a bug).** The gateway adds `brain_start` to
   each `Reply.spans[i].start` (`alexia-gateway/src/gateway.rs:834`, "The brain measures from
   when it was handed the turn"), but `Lanes` (`lane.rs:150`), `FastChat` (`chat.rs:201` and
   on) and `V2Bridge` (`bridge.rs:352`, `:483`) write **epoch ms** there. The dashboard and
   `latency --check`'s coverage rule then break the way P1-20 described. Gateway tests miss it
   because their fake brains use small starts. After this task `Span.start` is defined as
   **ms since the brain was handed the turn**, every brain writes that, and one helper,
   `Span::since`, is the only way core and the hub build a timed span.
2. **One clock, one calendar, one text flattener.** "Epoch ms now" is written out in
   `alexia-core/src/{catalog.rs (now), chat.rs:391, lane.rs:187, router.rs:429}`,
   `alexia-gateway/src/gateway.rs:114`, `alexia-hub/src/{watchdog.rs, bridge.rs:641}`,
   `alexia-store/src/db.rs` (`now`) and inline in `alexia-store/src/import.rs` (~`:348`);
   Howard Hinnant's days-to-civil is copied in `watchdog.rs:63` (`civil`) and `latency.rs:104`
   (`utc`); `span()` is copied three times (`chat.rs:383`, `lane.rs:193`, `bridge.rs:581`);
   and a `Content`'s text is flattened three times (`chat.rs:355` `text_of`, `bridge.rs:535`
   `text_of`, `lane.rs:83`). After this task `now_ms`, `civil_utc` and `Content::text` live in
   `alexia-store` next to `Ms` and `Content`, `Span::since` in `alexia-core`, and every copy
   calls them.

This lands **before P1-17** (so the hub's wiring uses `alexia_store::now_ms` from the start and
no `main.rs` copy is ever written) and before P1-26 and P1-18 (P1-18 measures these spans).

## Interfaces
Added to `alexia_store` (INTERFACES.md §2.1, right after `pub type Ms = i64;`, and after
`pub enum Content`):

```rust
/// Unix epoch milliseconds, now; 0 if the clock reads before 1970.
pub fn now_ms() -> Ms;
/// The UTC calendar date and time of epoch `ms` (Howard Hinnant's days-to-civil):
/// (year, month 1..=12, day 1..=31, hour, minute, second). Negative `ms` is before 1970.
pub fn civil_utc(ms: Ms) -> (i64, i64, i64, i64, i64, i64);

impl Content {
    /// The text parts joined with "\n" (a `Text` as is); image parts are skipped.
    pub fn text(&self) -> String;
}
```

`alexia_core` (INTERFACES.md §2.3, the `Span` lines become):

```rust
/// One timed stretch of answering, for the latency dashboard (SP-09). `start` is ms since
/// the brain was handed the turn (a brain's spans); the gateway shifts them by when it called
/// the brain, so stored spans are ms since the turn's first receipt.
#[derive(Clone, Debug, Serialize)]
pub struct Span { pub name: &'static str, pub start: Ms, pub ms: u32 }
impl Span {
    /// From `from` to now, with `start` = `from − began` (saturating at 0) and `ms` capped at u32::MAX.
    pub fn since(name: &'static str, began: std::time::Instant, from: std::time::Instant) -> Span;
}
```

Callers holding a `tokio::time::Instant` pass `.into_std()`.

## Steps
1. `types.rs`: add `now_ms` (the body of `db.rs`'s `now()`), `civil_utc` (`latency.rs`'s `utc`
   arithmetic returning the tuple instead of a string) and `Content::text` (`chat.rs`'s
   `text_of`).
2. `db.rs`: delete `fn now()`, call `now_ms()`. `import.rs` (~`:348`): `let at = now_ms();`;
   drop the now-unused `SystemTime`/`UNIX_EPOCH` imports.
3. `catalog.rs` and `router.rs`: delete their `now`/`now_ms`, use `alexia_store::now_ms`.
   `router.rs`'s `elapsed_ms` (a `u32` duration, not a span) stays.
4. `gateway.rs`: delete `fn now_ms()`, `use alexia_store::now_ms`. Keep every `Instant` use and
   the `brain_start + s.start` shift at `:834` (it is right once the brains are).
5. `watchdog.rs`: delete `fn now_ms()`. `civil(ms, offset_min)` becomes a call to
   `civil_utc(ms + offset_min * 60_000)` keeping its `(y, m, d, h, mi)` return (drop seconds),
   or inline that into `gap_sentence`. Its tests stay as they are and pass.
6. `latency.rs`: `utc(ms)` formats `civil_utc(ms)` as `"{y:04}-{m:02}-{d:02} {h:02}:{mi:02}:{s:02}"`;
   `utc_known_dates` stays and passes.
7. `lib.rs`: `Span::since`. `chat.rs`: `let began = Instant::now()` is the existing `started`;
   every `span(name, now_ms(), d)` becomes `Span::since(name, began, from)` with `from` the
   `Instant` taken where the `now_ms()` was. The `writing` span is a literal:
   `start = first_byte.start + first_byte.ms as Ms`, `ms = total − first`. Delete `span`,
   `now_ms` (`day_of(now_ms())` and capture's `"at"` use `alexia_store::now_ms`) and `text_of`
   (`turn.content.text()`). The `invalidate` doc comment loses "on `Event::SettingsChanged`"
   (nothing publishes it for settings; the 10-minute timer is the mechanism).
8. `lane.rs`: `began = Instant::now()` on entry; `"lane"` and `"chat-escalated"` via
   `Span::since`. The inner brain's spans are measured from when **it** was handed the turn, so
   shift them: chat spans by `since(began, t_chat)`, task spans by `since(began, t_task)` where
   `t_task` is taken just before `self.task.reply` (after an escalation that is the chat
   attempt's whole duration later). Delete `now`, `span`. `lane()`'s own flattening loop keeps
   its early `return Lane::Task` on an image part and otherwise uses `content.text()`.
9. `bridge.rs`: `Run.sent` and the open tool's start become `Instant`s taken at the same
   places; `span(name, start, end)` calls become `Span::since(name, began, from)` with
   `began` taken at the top of `reply` (before `with_context`), and `end` "now" at the point
   the call is made today (a tool span closes on the event that closes it: build it there).
   Delete `span`, `text_of` (`.text()`), and `now_ms` (tests and the store row's `at` use
   `alexia_store::now_ms`).
10. INTERFACES.md §2.1 and §2.3 as above.

  `< 60_000`, and they are non-decreasing in the order prompt, recall-wait, first-byte, writing, store.

  `Reply.spans` = lane, chat-escalated, then the task span with `start >= 200` and `< 60_000`.

- `spans_are_offsets_from_the_turn`: a scripted run with one tool step and a delta; every span
  `start < 60_000` and the `bridge` span starts at `< 1_000`.

pass unchanged (a test that asserted an epoch-sized `start` is wrong and is fixed, saying so in
