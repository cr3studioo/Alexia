# P1-25: One time helper

Model: sonnet
Depends on: P1-20, P1-22, P1-23, P1-17, P0-25
Feature IDs: none

## Goal
One clock and one calendar function for every v3 crate. Today "epoch ms now" is written out in
`alexia-core/src/catalog.rs` (`now`), `alexia-gateway/src/gateway.rs` (`now_ms`),
`alexia-hub/src/watchdog.rs` (`now_ms`), `alexia-store/src/db.rs` (`now`) and inline in
`alexia-store/src/import.rs` (~`:348`), and Howard Hinnant's days-to-civil is copied in
`watchdog.rs:63` (`civil`) and `latency.rs:104` (`utc`). After this task both live in
`alexia-store` next to `Ms`, and every copy calls them.

`alexia-core/tests/catalog.rs`'s `cache()` stay), behaviour of any caller.

## Interfaces
Added to `alexia_store` (INTERFACES.md §2.1, right after `pub type Ms = i64;`):

```rust
/// Unix epoch milliseconds, now; 0 if the clock reads before 1970.
pub fn now_ms() -> Ms;
/// The UTC calendar date and time of epoch `ms` (Howard Hinnant's days-to-civil):
/// (year, month 1..=12, day 1..=31, hour, minute, second). Negative `ms` is before 1970.
pub fn civil_utc(ms: Ms) -> (i64, i64, i64, i64, i64, i64);
```

## Steps
1. `types.rs`: add both functions. `now_ms` is the body of `db.rs`'s `now()`.
   `civil_utc` is `latency.rs`'s `utc` arithmetic returning the tuple instead of a string.
2. `db.rs`: delete `fn now()`, call `now_ms()` (import it from `crate::types` / `crate`).
3. `import.rs` (~`:348`): `let at = now_ms();`; drop the now-unused `SystemTime`/`UNIX_EPOCH`
   imports.
4. `catalog.rs`: delete `fn now()`, use `alexia_store::now_ms()`.
5. `gateway.rs`: delete `fn now_ms()`, `use alexia_store::now_ms`. Keep `Instant` uses.
6. `watchdog.rs`: delete `fn now_ms()`. `civil(ms, offset_min)` becomes a call to
   `civil_utc(ms + offset_min * 60_000)` keeping its `(y, m, d, h, mi)` return (drop seconds),
   or inline that into `gap_sentence`. Its tests stay as they are and pass.
7. `latency.rs`: `utc(ms)` formats `civil_utc(ms)` as `"{y:04}-{m:02}-{d:02} {h:02}:{mi:02}:{s:02}"`;
   `utc_known_dates` stays and passes.
8. `main.rs`: if P1-17 wrote its own `SystemTime::now().duration_since(UNIX_EPOCH)` (e.g. for
   `prune_spans(now − 30 days)` or `offline_gap(.., now)`), replace it with `now_ms()`.
9. INTERFACES.md §2.1 as above.
