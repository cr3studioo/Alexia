# P4-28: computer: accessibility first, her own cursor

Model: opus
Depends on: P4-01
Feature IDs: PC-01, PC-02

## Goal
The `computer` plugin acts through accessibility first: pressing a button, setting a field,
toggling a checkbox or choosing a list item uses UI Automation patterns on Windows and AX actions
on macOS, so it is fast and the owner's mouse pointer stays where it is. The real pointer and
keyboard are used only when no pattern fits, and the pointer is put back afterwards. Wherever
she acts, her own cursor shows the spot (`cursor.show`, when a provider exists).

## Touch only these paths
- `plugins/computer/windows.js`   (change: Invoke/Value/Toggle/SelectionItem/ExpandCollapse patterns; pointer restore)
- `plugins/computer/macos.js`   (change: AXPress/AXValue/AXConfirm/AXPick; pointer restore)
- `plugins/computer/index.js`   (change: `press` and `do` prefer the accessible path; call `cursor.show`)
- `plugins/computer/ghost.js`   (create: the "show her cursor" helper over `alexia/capability/call`)
- `plugins/computer/test/ghost.test.js`   (create), `test/windows.test.js`, `test/macos.test.js`   (change)

## Must not touch
`decide.js`, `laya.js`, `task.js`, `replay.js`, `recipes.js` (unless a call site must change; then
one line, said in the report), other plugins, `plugin.json` except adding nothing (`cursor.show`
is optional: used through `alexia/capability/call` only when `alexia/answers` says it is there).

## Interfaces
- `windows.js`: `act(element, how)` where `how` ∈ `invoke | set_value(text) | toggle | select | expand`,
  returning `{done:true, via:"uia"}` or `{done:false}` when the element lacks the pattern.
- `macos.js`: the same `act` with `AXPress`, `AXValue` set, `AXConfirm`, `AXPick`.
- `index.js` `press`/`do`: try `act` first; on `{done:false}` fall back to today's click/type,
  then move the pointer back to where it was (Windows `GetCursorPos`/`SetCursorPos`; macOS
  `CGEventCreateMouseEvent` move). Result text says which way was used ("pressed through
  accessibility" / "clicked with the mouse").
- `ghost.js`: `show(x, y)` → `alexia/capability/call {cap:"cursor.show", arguments:{x,y,label:"Alexia"}}`,
  cached `alexia/answers` check every 60 s, never awaited longer than 200 ms (her cursor is a nicety).
- Setting `show_cursor` (toggle, default true).
