# P4-43: Owner: the Mac limb, paired, the hands on both computers

Model: sonnet
Depends on: P4-42, P4-15..P4-29 (all plugin tasks)
Feature IDs: HB-02, HB-03, HB-05, HB-06, HB-07, HB-08, HB-09, HB-18, TR-05, TR-07, PC-01..PC-20 (on the real devices)

## Goal
The phase works on the owner's real PC and Mac. The worker prepares a script and a checklist,
runs the PC half, and hands the owner the Mac half with exact steps; the results go in
`v3/ops/reports/P4-e2e.md`.

## Touch only these paths
- `v3/ops/reports/P4-e2e.md`   (create)
- `v3/ops/reports/p4-mac.sh`   (create: the Mac steps as a script the owner runs)

## Must not touch
Any code. A bug found is written up as a failed line with the error; the CEO makes a fix task.

## Interfaces
None new. Uses `alexia-hub devices *`, `alexia-limb *`, the plugins.

## Steps
**Worker, on this PC:**
1. Build the hub (`CARGO_TARGET_DIR=D:/alexia-target/P4-43 cargo build --release -p alexia-hub`),
   restart the real hub, run `alexia-hub devices pair`, put the printed text in the report's
   "Owner: do this" block (it expires in 5 min: the owner starts the pairing themselves, below).
2. On the PC: try each PC plugin once (window-deck layout save/apply, file-finder search, pc-care
   volume, shell `shell_read`, screen-ink box, screen-look "look at my screen", computer press via
   accessibility, documents edit copy) and record the result.

**Owner, on the Mac (exactly this, about 30 minutes; `p4-mac.sh` does steps 2–4):**
1. `git pull` the branch the CEO names; install Node if missing.
2. `cargo build --release -p alexia-limb` in `v3/`; `./target/release/alexia-limb plugins` and
   enable: computer, ocr, device-clipboard, device-notify, file-courier, screen-look, screen-ink,
   window-deck, file-finder (`alexia-limb plugins enable <id>` each), with
   `ALEXIA_PLUGINS_DIR=<checkout>/plugins`.
3. On the PC run `alexia-hub devices pair`; on the Mac run `alexia-limb pair "<the text>"` within 5 minutes.
4. `alexia-limb install` (starts at login). Grant Accessibility and Screen Recording to
   `alexia-limb` in System Settings → Privacy & Security when macOS asks.
5. From Telegram: "take a screenshot of my Mac", "what's on my Mac's screen", "move <file> from
   my Mac's Desktop to the PC". Sit at the Mac for 2 minutes and wait for a test notice
   (`alexia-hub say --test` or the CEO's equivalent): it must appear on the Mac, not Telegram.
   Copy text on the Mac, go to the PC within 2 minutes, paste (after `alexia-hub devices clipboard on`).
6. On the Mac: `alexia-limb kill` while a long task runs; confirm it stops; `/resume` on Telegram.
7. Write one line per step in the report: worked / failed + what was seen.

## Tests
The checklist itself; no automated test.

## Done when
- `v3/ops/reports/P4-e2e.md` has a line for every step above, filled by the worker (PC) and the owner (Mac)
- no code changed (`git diff --stat` shows only the two report files)

## Notes for the worker
- The owner's hands are needed for steps 1–7 of the Mac part; send the CEO the exact block to
  forward, and wait (status `blocked-owner`).
- Never put the pairing code in a committed file: the report says "paired at <time>" only.
