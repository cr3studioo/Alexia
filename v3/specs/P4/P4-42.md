## Goal
The phase's done-when item 1 (PHASE.md) as one test: the real hub wiring and a real limb in one
process on loopback, scripted model, fake Telegram, paused clock where it helps.

## Touch only these paths
- `v3/crates/alexia-hub/tests/mesh_day.rs`   (create)

## Must not touch
Any `src/` file. A failure is reported with the failing assertion, not patched here.

## Interfaces
Everything public from P4-02..P4-41. The limb side is built from `alexia-mesh` plus the limb's
serve code driven the way `alexia-limb/tests/limb.rs` drives it, or by running the built
`alexia-limb` binary (`env!("CARGO_BIN_EXE_alexia-limb")` is not available across crates: build it
with `cargo build -p alexia-limb` in the test's setup as `tests/common` builds fixtures) with
`ALEXIA_V3_DATA` pointing at a scratch folder and an ephemeral key switch (add none: if the limb
has no ephemeral switch, use a scratch keychain service name via its config and clean it up).

## Steps
Assert, in order, each bullet of PHASE.md *Done when* 1:
1. pair from the hub's URI; a stranger is refused;
2. the fixture tool is one model tool with `device`; a call without it runs on the active device;
3. owner active on the limb → `Say` reaches the limb's `notify.show` and not Telegram; a Telegram
   message → the next `Say` goes to Telegram;
4. a long fixture call is running; limb `kill` → stopped within 2 s; a scheduled job does not fire
   until `/resume`;
5. hub stopped → wake packet sent (to a test UDP listener) → fallback answers the fake Telegram
   after its deadline → hub restarted → turns appear once in the hub session, limb stops polling.
