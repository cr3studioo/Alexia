# P4-11: McpHost: remote servers through a dialer; offline is not a crash

Model: opus
Depends on: P3-35
Feature IDs: HB-02, HB-03

## Goal
`McpHost` can host a server whose stdio is not a process: for an added server with
`run: "mesh"`, it asks a `Dial` the binary installed for the two pipe ends, then treats it exactly
like a plugin (handshake, tools, calls, heartbeat, `alexia/*`). A dial that fails because the
device is offline leaves it `Stopped` and does not count toward the crash limit; when the hub
says the device is back, `restart` brings it up. `alexia-mcp` gains no dependency on the mesh.

## Touch only these paths
- `v3/crates/alexia-mcp/src/lib.rs`   (change: `Dial`, `HostConfig.dial`, `HostedTool.device`)
- `v3/crates/alexia-mcp/src/host.rs`   (change: `start_guest` for `run == "mesh"`, `Guest::Remote`, offline handling)

## Must not touch

## Interfaces
```rust
/// Opens the stdio of a server that is not a local process. `args` are the manifest's `entry.args`.
#[async_trait::async_trait]
pub trait Dial: Send + Sync {
    async fn dial(&self, id: &PluginId, args: &[String]) -> std::result::Result<(tokio::process::ChildStdin, tokio::process::ChildStdout), DialError>;
}
#[derive(Debug)] pub enum DialError { Offline, Refused(String) }
pub struct HostConfig { /* existing fields */ pub dial: Option<Arc<dyn Dial>> }
pub struct HostedTool { /* existing fields */ /// The run:"mesh" server it came from (its plugin id), else None.
    pub device: Option<String> }
```
- `run: "mesh"` with no `dial` set → refused at admit with "This device's link is not available here."
- `DialError::Offline` → state `Stopped`, log at info, no backoff counting, no `Unhealthy`.
- `DialError::Refused` → counts as a crash (as a failed spawn does).
- A remote guest has pid 0 (like wasm); `stop` closes the pipes.
- `add_server` accepts `run: "mesh"` (validation must not require an executable on PATH for it).
- A `mesh` server's tools are `HostedTool { device: Some(id) }`.

## Steps
1. `Guest::Remote` variant; `start_guest` branch before the process path.
2. Supervision: find where a failed start increments the crash window; skip for `Offline`.
3. `HostedTool.device` set where tools are built (`hosted(..)`).
4. Make `restart(id)` the documented way to bring a remote back (it already exists; test it).
