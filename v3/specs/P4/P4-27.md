# P4-27: screen-look: look at my screen, help, read any text

Model: sonnet
Depends on: P4-15
Feature IDs: PC-12, PC-13, PC-19

## Goal
"Look at my screen", "what does this error mean", "how do I turn this off here", "copy the text
in that picture": Alexia takes a screenshot of the front window (or the whole screen), reads the
text on it and describes it, then answers about it. It only uses capabilities: `computer.screenshot`,
`image.ocr`, `vision.describe`, so it works on whichever device has them.

## Touch only these paths
- `plugins/screen-look/**`

## Must not touch
`plugins/computer/**`, `plugins/ocr/**`, other plugins, any crate, `pnpm-lock.yaml`.

## Interfaces
- `screen.look {question?, whole_screen?:false}` → `{description, text, window:{app, title}}` (read-only)
- `screen.help {question}` → `{answer, steps?:[..]}`: look, then one sampling call
  (`sampling/createMessage`) with the description, OCR text and the question; the answer names
  controls by their visible labels. If `screen.draw` is available it may draw a box on the control
  for step 1 (`draw:true` default false).
- `screen.text {region?:{x,y,w,h}, whole_screen?}` → `{text}` (OCR only, no model).
- Skill: `skills/screen-help/SKILL.md` telling the model when to use these (the owner says "this",
  "here", "on my screen").
- Private moments: if `computer.screenshot` reports a locked screen or a private window (P3-34's
  front-window and lock fields), answer "Your screen is locked or private, so I didn't look."
- Missing capabilities degrade with the sentences from `docs/spec/capabilities.md`.

## Tests
`test/look.test.js` (capabilities faked through the SDK's test harness, as other plugins test
`alexia/capability/call`): `look_combines_ocr_and_description`, `help_makes_one_sampling_call`,
`text_region_crops`, `locked_screen_refused`, `no_vision_still_reads_text`, `skill_file_parses`.
