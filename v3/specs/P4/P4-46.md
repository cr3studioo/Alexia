# P4-46: Gateway: the current session and moving it, for the window

Model: sonnet
Depends on: P4-32
Feature IDs: none (gives P4-41 what it expects)

## Goal
P4-41 (the window joins the handoff) expects two Gateway methods that P4-32 did not add. After this
task they exist on top of P4-32's shared Routes table, with tests, so P4-41 can use them.

## Touch only these paths
- v3/crates/alexia-gateway/src/gateway.rs   (change: the two methods only)
- v3/crates/alexia-gateway/tests/follow.rs   (change: tests for them)

## Must not touch
Everything else, including ask.rs, channel.rs, channels/**, other crates.

## Interfaces
```rust
impl Gateway {
    /// The owner's conversation of the last `within_ms`, if any: its session and the face it is on.
    pub fn current_session(&self, within_ms: i64) -> Option<(SessionId, Origin)>;
    /// The owner wrote into `session` from `origin`: that session now continues there
    /// (same effect as a handoff through route(): the face follows, "Continued on <face>." if a
    /// turn is in flight).
    pub fn moved_to(&self, session: SessionId, origin: Origin);
}
```
Use P4-32's Routes table and Actor::move_to (gateway.rs about 276-314 and 785-805); do not add a second
record of where the owner is.

## Tests
- `current_session_is_the_last_owner_conversation`: none before any message; after an owner message on
  a channel, Some(that session, that origin); None after within_ms has passed.
- `moved_to_moves_the_followed_face`: after moved_to(session, Origin::Window), the next unprompted Say
  goes to the window, and current_session returns Origin::Window.
