# P4-19: window-deck: apps, windows, saved layouts

Model: sonnet
Depends on: P4-15
Feature IDs: PC-03, PC-04

## Goal
Alexia can list apps and windows, move, resize, snap, minimise, maximise and close windows, quit
an app, and save the current arrangement as a named layout to restore later ("my study layout").
The `computer` plugin already opens apps and focuses windows; this plugin does the rest without
touching it.

## Touch only these paths
- `plugins/window-deck/**`

## Must not touch
`plugins/computer/**` (P4-28/P4-29), any crate, `pnpm-lock.yaml`.

## Interfaces
- `window.list {}` → `{windows:[{id, app, title, x, y, w, h, minimized, monitor}], monitors:[{id, x, y, w, h, primary}]}` (read-only)
- `window.arrange {id, do:"move"|"resize"|"snap_left"|"snap_right"|"maximize"|"minimize"|"restore"|"close", x?, y?, w?, h?, monitor?}`
  (`close` asks the window to close, which lets the app ask to save; not destructive)
- `window.layout.save {name}` → `{saved, windows}`; `window.layout.apply {name}` → `{placed, missing:[app]}` (opens missing apps only if `open_missing:true`)
- `app.quit {app, force?:false}` (destructive; `force` only when the owner says so)
- Storage: table `layouts (name primary key, json, saved_at)`.
Windows backend: PowerShell with `Add-Type` user32 (`EnumWindows`, `GetWindowRect`, `SetWindowPos`,
`ShowWindow`, `PostMessage WM_CLOSE`). macOS: JXA with System Events (needs Accessibility).
Windows are matched on restore by app then title, then app alone.
