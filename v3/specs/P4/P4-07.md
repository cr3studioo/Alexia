# P4-07: Presence and wake-on-LAN

Model: sonnet
Depends on: P4-02
Feature IDs: HB-05, HB-10

## Goal
Two small pieces with no network state: how long since the owner touched this device (and
whether it is locked), the pure rule for "where is the owner now" (D-P4-7), and sending a
Wake-on-LAN magic packet. The hub and limb wire them later (P4-36, P4-37).

## Interfaces
```rust
// presence.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct Idle { pub idle_ms: u64, pub locked: bool }
/// This device: Windows via PowerShell (`[System.Windows.Forms]`-free: a one-line Add-Type of
/// GetLastInputInfo run through powershell.exe, CREATE_NO_WINDOW), macOS via `ioreg -c IOHIDSystem`
/// (HIDIdleTime, ns) and `ioreg -n Root -d1` / CGSession for locked. None if it cannot be read.
pub async fn idle_now() -> Option<Idle>;
/// Where the owner is (D-P4-7): the device with the smallest idle within `window_ms` (5 min),
/// ties to the hub; else the most recent channel message; else None.
#[derive(Clone, Debug, PartialEq, Eq)] pub enum Here { Device(DeviceId), Channel { channel: String, chat: String } }
pub struct Seen { pub device: DeviceId, pub idle_ms: u64, pub locked: bool, pub at: Ms }
pub struct Said { pub channel: String, pub chat: String, pub at: Ms }
pub fn here(devices: &[Seen], last_said: Option<&Said>, now: Ms, window_ms: u64) -> Option<Here>;
pub const WINDOW_MS: u64 = 300_000;
// wol.rs
pub fn parse_mac(s: &str) -> Option<[u8; 6]>;          // "aa:bb:cc:dd:ee:ff" or with '-'
pub fn magic_packet(mac: [u8; 6]) -> [u8; 102];
/// UDP broadcast to 255.255.255.255:9 and :7 from an unspecified local port, three times 100 ms apart.
pub async fn wake(macs: &[[u8; 6]]) -> Result<()>;
/// This computer's wired and wireless MAC addresses, for the hub's Hello (getmac /fo csv on
/// Windows, `ifconfig` on macOS). Empty if unknown.
pub async fn own_macs() -> Vec<String>;
```
A locked device counts as idle `u64::MAX` (the owner is not there).

## Steps
1. `here` first, as a pure function with the rules above.
2. `idle_now` per platform behind `cfg`; other platforms → None.
3. `magic_packet` (6 × 0xFF then 16 × MAC), `wake` with `tokio::net::UdpSocket` and `set_broadcast`.
   Bind the sending socket with `UdpSocket::bind((Ipv4Addr::UNSPECIFIED, 0))` (a send, not a
   listener; invariant 13 forbids the literal `0.0.0.0` in `src/`, so do not write it). If check 13
   still flags the line, escalate rather than weaken the check.
