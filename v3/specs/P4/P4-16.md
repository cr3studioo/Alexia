# P4-16: device-clipboard: clipboard, history

Model: sonnet
Depends on: P4-15
Feature IDs: PC-18, HB-07 (the device side)

## Goal
On each computer, Alexia can read and set the clipboard and keeps a short history of what was
copied (text only), skipping anything marked as a password. The hub uses `clipboard.get` /
`clipboard.set` to make the clipboard follow the owner between devices (P4-38).

## Touch only these paths
- `plugins/device-clipboard/**`

## Must not touch
Other plugins, any crate, `pnpm-lock.yaml` (no new npm dependency).

## Interfaces
Capabilities as in `docs/spec/capabilities.md` (P4-01): `clipboard.get`, `clipboard.set`,
`clipboard.history`. Tools: `clipboard_get`, `clipboard_set`, `clipboard_history`, `clipboard_clear_history`.
Settings: `history` toggle (default on), `keep_days` choice 1/7/30 (default 7).
Storage: table `clips (id, text, at, sha256)` in the plugin's namespace; at most 500 rows.

## Steps
1. Windows: `powershell -NoProfile -Command Get-Clipboard -Raw` / `Set-Clipboard -Value` (stdin, not
   argv, so long or quoted text is safe). Sensitive: `Get-Clipboard -Format` cannot see the
   exclusion flag; read `ExcludeClipboardContentFromMonitorProcessing` and `CanIncludeInClipboardHistory`
   formats via a small `Add-Type` (WinForms `Clipboard.ContainsData`). macOS: `pbpaste`/`pbcopy`;
   sensitive = `org.nspasteboard.ConcealedType` or `TransientType` present (via `osascript -l JavaScript`).
2. History: poll every 2 s while running (resident only if the `history` setting is on), store new
   non-sensitive text ≤ 100 KB, dedupe by hash, prune by `keep_days`.
3. Text only; images and files report `kind` without content.
