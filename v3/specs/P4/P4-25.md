# P4-25: browser-pilot: the extension

Model: opus
Depends on: P4-24
Feature IDs: HB-17, PC-11

## Goal
A Manifest V3 extension for Chrome and Edge that the owner loads unpacked from the plugin's
folder. It connects to the browser-pilot plugin on 127.0.0.1 with the pasted code and carries
out its requests in the owner's tabs: list, read, open, click, fill. It shows when Alexia is
acting and has an off switch.

## Touch only these paths
- `plugins/browser-pilot/extension/**`   (create: `manifest.json`, `background.js`, `content.js`, `options.html`, `options.js`, `icon-*.png`)
- `plugins/browser-pilot/test/extension.test.js`   (create)

## Must not touch
The plugin side (`index.js`, `socket.js`, `pilot.js`), other plugins, `pnpm-lock.yaml`.

## Interfaces
The protocol in P4-24. Manifest: `manifest_version: 3`, permissions `tabs`, `scripting`,
`storage`, `activeTab`; host permissions `<all_urls>` (needed to read and act on the owner's
pages; the options page says so plainly); no remote code; CSP default.
- `options.html`: paste the code and the port (from the plugin's settings), a status line, an
  "Alexia may act in this browser" switch (off = read-only: click/fill/open refused with a sentence).
- `background.js` (service worker): a WebSocket to `ws://127.0.0.1:<port>`, reconnect with backoff
  1 s → 30 s; keep the worker alive while connected (`chrome.alarms` ping every 25 s).
- `content.js` injected on demand with `chrome.scripting.executeScript`: `read` builds text and a
  list of visible controls with stable `ref`s (data attribute), skipping `input[type=password]`
  values; `click`/`fill` find by `ref`, or by visible text/label (exact, then case-insensitive
  contains, refusing if more than one matches); while acting, a small badge "Alexia" on the page.
- Never acts on `chrome://`, the Web Store, or other extensions' pages.

## Tests
`test/extension.test.js` (node:test with a fake `chrome` object and jsdom-free DOM stubs —
no new npm dependency: test the pure functions `content.js` exports for matching and text
building by loading it as a module with a tiny fake document): `manifest_is_mv3_minimal`,
`find_by_text_unique_or_refuse`, `password_values_skipped`, `act_switch_off_refuses`,
`protocol_answers_shape`, `refuses_chrome_pages`.

## Done when
- `pnpm check` passes at repo root
- `node --test plugins/browser-pilot/test` passes
- `node v3/ci/invariants.mjs` exits 0
- the extension loads unpacked in Chrome without manifest errors (the worker's own Chrome, if any;
  else the owner checks in P4-44 and the report says so)

## Notes for the worker
- Security task: the extension sees everything the owner sees. Keep its code small and readable;
  no analytics, no external requests except the loopback socket.
