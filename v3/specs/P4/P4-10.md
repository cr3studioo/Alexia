# P4-10: Limb: runs at login, logs, status

Model: sonnet
Depends on: P4-09
Feature IDs: HB-03

## Goal
The limb starts by itself when the owner logs in and restarts if it dies, on macOS (a launchd
user agent) and on another Windows computer (a Task Scheduler task at logon), the way the hub's
watchdog installs itself. Its log goes to a file the owner can find.

## Touch only these paths
- `v3/crates/alexia-limb/src/service.rs`   (fill)
- `v3/crates/alexia-limb/tests/service.rs`   (create)

## Must not touch
`cli.rs`, `main.rs` (P4-09 already calls `service::install()`/`uninstall()`), `alexia-hub/src/watchdog.rs`
(read it as the pattern; do not share code by editing it).

## Interfaces
```rust
pub fn install() -> Result<String, String>;     // Ok(sentence) e.g. "Alexia's limb will start when you log in."
pub fn uninstall() -> Result<String, String>;
/// The text written, for tests: a launchd plist or a schtasks XML.
pub fn unit_text(exe: &std::path::Path, log: &std::path::Path) -> String;
pub fn log_path() -> std::path::PathBuf;         // <limb data>/limb.log
```
macOS: `~/Library/LaunchAgents/dev.alexia.limb.plist`, `RunAtLoad`, `KeepAlive` (SuccessfulExit
false), `ProgramArguments [exe, "run"]`, stdout/stderr to `log_path()`; `launchctl bootstrap
gui/<uid>` (and `bootout` to uninstall). Windows: `schtasks /Create /TN "Alexia limb" /XML` at
logon, restart on failure 3×, hidden. Other OS: Err("Starting at login is not set up on this system.").

## Steps
1. Read `alexia-hub/src/watchdog.rs` for the Windows pattern and quoting.
2. Write both unit texts as pure functions; install/uninstall shell out (`CREATE_NO_WINDOW` on Windows).
3. `run` (already in P4-09) logs to stderr; launchd/schtasks redirect it. Rotate: if the log is
   over 10 MB at start, rename it to `limb.log.1`.

## Tests
`tests/service.rs`: `plist_is_valid_xml_with_run`, `schtasks_xml_has_logon_trigger_and_restart`,
`paths_are_quoted` (an exe path with a space), `install_on_unsupported_os_says_so` (cfg-gated).
Real install is not run in tests.
