# P4-20: file-finder: instant search, tidy folders

Model: sonnet
Depends on: P4-15
Feature IDs: PC-05, PC-06

## Goal
"Find the PDF about the lease from last spring" answers in about a second using the index the
operating system already keeps, and "tidy my Downloads" proposes a plan of moves (by type, age
and project) that runs only after the owner approves it, and can be undone.

## Touch only these paths
- `plugins/file-finder/**`

## Must not touch
Other plugins, any crate, `pnpm-lock.yaml`.

## Interfaces
- `file.search {query, kind?:"document"|"image"|"video"|"audio"|"archive"|"folder", folder?, modified_after?, limit?<=50}`
  → `{items:[{path, name, modified, size}]}` (read-only). Windows: Windows Search through
  `ADODB` `Provider=Search.CollatorDSO` (`SystemIndex`, `CONTAINS`/`FREETEXT`, `SCOPE`) in PowerShell;
  macOS: `mdfind` (with `-onlyin`). Results outside the owner's roots are dropped unless the
  scope is Everywhere.
- `folder.tidy {folder}` → `{plan_id, moves:[{from, to, why}]}` (read-only: it only proposes).
- `folder.tidy {folder, apply: plan_id}` → `{moved, skipped}` (destructive). Rules: installers
  older than 30 days → `Old installers`; documents/images/archives by type into subfolders;
  nothing younger than 1 day; never touches folders or hidden files. A plan expires after 1 h.
- `folder.tidy_undo {plan_id}` → moves back what it moved (log in table `moves`).

## Tests

`apply_only_known_plan`, `undo_restores`, `young_files_untouched`; live gated.
