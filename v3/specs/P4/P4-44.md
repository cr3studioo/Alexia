# P4-44: Owner: the PC off, wake, fallback, the browser extension

Model: sonnet
Depends on: P4-43
Feature IDs: HB-10, HB-11, HB-17, PC-11, TR-10, TR-11 (on the real devices)

## Goal
The two drills that need the owner's hands and power button: the PC goes away and the Mac takes
over Telegram, a wake packet brings the PC back (if enabled), and the Mac's turns land in the
PC's conversation; and the browser extension works in the owner's own browser. Also one check
each of local-only and a guest.

## Touch only these paths
- `v3/ops/reports/P4-fallback.md`   (create)
- `v3/ops/reports/P4-e2e.md`   (change: append the extension, local-only and guest lines)

## Must not touch
Any code.

## Interfaces
None new.

## Steps
**Owner, before (once):**
1. PC BIOS: enable Wake on LAN / Power on by PCI-E; Windows: Device Manager → network adapter →
   Power Management "Allow this device to wake the computer" and Advanced "Wake on Magic Packet".
   PC on Ethernet. (Skip if not wanted; the drill then checks fallback only.)
2. On the Mac: `alexia-limb secret set _core.telegram_bot_token` and
   `alexia-limb secret set provider_<id>` for at least one free provider (keys typed on the Mac).

**Fallback drill (owner, ~20 minutes):**
3. Put the PC to sleep (or shut it down). Note the time.
4. After about 3 minutes, message Alexia on Telegram. Expect an answer from the Mac starting
   "(The PC is off, …". Send two more messages.
5. If WoL is enabled: note whether the PC woke within ~2 minutes of step 3's outage. If not, wake
   it by hand.
6. When the PC's hub is back: within a minute, Telegram is answered by the PC again, the Mac
   stops (the limb's `status` says so), and the three exchanges are in the PC's conversation (open
   the window); a "While the PC was off…" message arrives once.

**Browser extension (owner, ~10 minutes):**
7. Chrome or Edge → Extensions → Developer mode → Load unpacked →
   `<checkout>/plugins/browser-pilot/extension`. Paste the code from the Browser plugin's settings
   in Alexia's window. Ask Alexia: "what tabs do I have open", "read this page", "click <a link
   you name>" (it asks first). Same on the Mac if wanted.

**Local-only and a guest (worker can run these with the owner watching):**
8. `/localonly on` from the window: a cloud-only request answers the local-only sentence; Telegram
   says it is pausing. `/localonly off`.
9. `/guest add Test` → send the code from a second Telegram account (the owner's or a family
   member's): the guest gets the greeting, can chat, and "what's on my calendar" is refused. `/guest remove`.

Write each step's result in the two reports (worked / failed / skipped + what was seen).
