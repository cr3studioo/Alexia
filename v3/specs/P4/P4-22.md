# P4-22: pc-care: system controls, maintenance, power

Model: sonnet
Depends on: P4-15
Feature IDs: PC-08, PC-09, PC-10

## Goal
"Turn the volume down", "dark mode on", "how much disk is left", "what starts with Windows",
"clean up temp files", "lock the PC", "sleep in 10 minutes": Alexia does these on Windows and the
Mac. Anything that changes the computer's state for good, or turns it off, asks first.

## Touch only these paths
- `plugins/pc-care/**`

## Must not touch
Other plugins, any crate, `pnpm-lock.yaml`.

## Interfaces
- `system.get {what}` / `system.set {what, value}` for `volume` (0–100), `mute` (bool),
  `brightness` (0–100, laptops/supported monitors), `dark_mode` (bool), `focus` (bool: Windows Focus
  assist / macOS Do Not Disturb where scriptable, else `isError` saying it can't). Windows: volume
  via a PowerShell `Add-Type` of the Core Audio `IAudioEndpointVolume` COM interface; brightness via
  `WmiMonitorBrightnessMethods`; dark mode via `HKCU\...\Themes\Personalize`. macOS: `osascript`.
- `system.care {check:"disk"|"startup"|"updates"|"temp"}` → a report (read-only);
  `{check:"temp", apply:true}` deletes files under the user temp folder older than 7 days that are
  not open (destructive); `{check:"startup", disable:<name>}` disables one startup item (destructive).
  `updates` only reports (Windows Update / `softwareupdate -l`), never installs.
- `power.do {action:"lock"|"sleep"|"restart"|"shutdown", in_s?}` — all destructive except `lock`;
  restart/shutdown announce "in 60 s" with a cancel tool `power.cancel`.
