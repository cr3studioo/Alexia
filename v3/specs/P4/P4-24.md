# P4-24: browser-pilot: the plugin and its local socket

Model: opus
Depends on: P4-15
Feature IDs: PC-11, HB-17

## Goal
Alexia can work in the owner's own browser: list tabs, read a page as text, open a page, click
and fill by what a control says. The plugin listens on 127.0.0.1 for the extension (P4-25),
which connects with a token the owner pastes once (D-P4-14). Because the plugin runs on whichever
computer it is installed on (the hub PC, or a Mac through its limb), the browser on every one of
the owner's computers becomes a limb.

## Touch only these paths
- `plugins/browser-pilot/{index.js, socket.js, pilot.js, plugin.json}`
- `plugins/browser-pilot/test/**` (except `test/extension.test.js`, P4-25's)

## Must not touch
`plugins/browser-pilot/extension/**` (P4-25), other plugins, any crate, `pnpm-lock.yaml`
(WebSocket: use Node's built-in `WebSocket` client? No — the plugin is the *server*: implement the
RFC 6455 server handshake and framing in `socket.js` on `node:http` upgrade, text frames only,
≤ 4 MiB messages; no npm dependency).

## Interfaces
Protocol (JSON text frames), the contract P4-25 implements:
```
extension → plugin, first frame: {"hello":1,"token":"<token>","browser":"chrome"|"edge","version":"<ext version>"}
plugin → extension: {"ok":true} or close 4001 "bad token"
plugin → extension request:  {"id":n,"do":"tabs"|"read"|"open"|"click"|"fill"|"focus","args":{..}}
extension → plugin answer:   {"id":n,"ok":true,"result":{..}} | {"id":n,"ok":false,"error":"<sentence>"}
```
`tabs` → `[{tabId, title, url, active}]`; `read {tabId?}` → `{title, url, text (≤ 200 KB), controls:[{ref, role, name}]}`
(active tab by default); `open {url, newTab?}`; `click {tabId?, ref | text}`; `fill {tabId?, ref | label, value}`;
`focus {tabId}`.
Tools/capabilities: `browser.tabs`, `browser.read` (read-only), `browser.open` (open world),
`browser.click`, `browser.fill` (open world, destructive false). Tool results never include
cookies or form values the page already had in password fields.
Settings: `token` (`status` key shown to the owner: generated on first start, 32 random bytes
base64url, regenerate with tool `browser_new_token`), `port` (status: the bound port).
Server: `http.createServer` on `127.0.0.1`, port 0 then remembered in own_dir and reused; the
`Origin` header must be `chrome-extension://<id>` or `extension://` (Edge) and the id must equal
the first one that presented a valid token (pinned in kv); only one extension connection at a time.
No browser connected → tools answer `isError` "Alexia's browser extension isn't connected. Open
the extension and paste the code from Alexia's Browser settings."
