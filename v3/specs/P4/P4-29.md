# P4-29: computer: recorded workflows

Model: opus
Depends on: P4-28
Feature IDs: PC-14

## Goal
"Watch me do this once": the owner starts a recording, does a task with mouse and keyboard, and
stops; Alexia turns it into a saved plan of named steps (press "Export", type into "File name",
choose "PDF") that the existing replay runs again later. A visible indicator is on the whole
time, password fields are never recorded, and nothing is kept until the owner names it.

## Touch only these paths
- `plugins/computer/record.js`   (create)
- `plugins/computer/index.js`   (change: tools `record_start`, `record_stop`, `record_cancel`)
- `plugins/computer/windows.js`, `plugins/computer/macos.js`   (change: event capture scripts)
- `plugins/computer/test/record.test.js`   (create)

## Must not touch
`replay.js` and the plan format (recordings must produce plans `replay.js` already runs),
`decide.js`, `laya.js`, other plugins.

## Interfaces
- `record_start {goal}` → starts capture; shows an indicator through `screen.draw` (a red dot
  "Recording" in a corner, refreshed) if available, else a toast via `notify.show`, else refuses:
  "I can't show that I'm recording on this computer, so I won't record."
- `record_stop {name?}` → `{steps:[..], name}`; saved with `save_plan` semantics under `name`
  (default: the goal). `record_cancel` → discards.
- Capture: Windows — a PowerShell process with UIA `FocusChanged` and `Invoke` event handlers plus
  a low-level mouse hook-free approach: on each mouse up / Enter, read
  `AutomationElement.FromPoint`/focused element (name, control type, automation id, window).
  macOS — JXA with `NSEvent.addGlobalMonitorForEventsMatchingMask` (needs Accessibility) and
  `AXUIElementCopyElementAtPosition`.
- Steps: click → `{do:"press", name, role, window}`; text typed into a field →
  `{do:"type", into:name, text}` (coalesced per field); keyboard shortcuts → `{do:"key", keys}`.
  A field whose control type is password (UIA `IsPassword`, AX subrole `AXSecureTextField`) →
  `{do:"type", into:name, text:"<ask>"}`: the replay asks the owner for it. Recording stops by
  itself after 10 minutes or 200 steps.
