# P4-02: `alexia-mesh` crate: types, errors, module stubs, dependencies, lockfile

Model: opus
Depends on: none
Feature IDs: HB-02, TR-05

## Goal
A new library crate `alexia-mesh` exists with the shared types every mesh task uses, one stub
file per later module (so no later task edits `lib.rs`), and every external dependency P4's Rust
needs, so `v3/Cargo.lock` changes in this task and in P4-37 only. The invariants script knows the
new crate and the limb's new edges.

## Touch only these paths
- `v3/crates/alexia-mesh/Cargo.toml`   (create)
- `v3/crates/alexia-mesh/src/lib.rs`   (create)
- `v3/crates/alexia-mesh/src/types.rs`, `src/error.rs`   (create)
- `v3/crates/alexia-mesh/src/{node,control,pair,qr,link,ops,presence,wol}.rs`   (create: stubs, a doc comment and nothing pub)

`src/types.rs` (re-exported from `lib.rs`):
```rust
pub use alexia_store::Ms;
/// A paired device's id: lowercase `a-z0-9-`, 1..=32 chars, made from its name at pairing
/// ("Vaclav's MacBook" → "vaclavs-macbook"; a clash gets "-2"). It is also the hub's plugin id for it.
#[derive(Clone, Debug, PartialEq, Eq, Hash, PartialOrd, Ord, Serialize, Deserialize)] #[serde(transparent)]
pub struct DeviceId(pub String);
impl DeviceId { pub fn from_name(name: &str, taken: &[DeviceId]) -> DeviceId; pub fn valid(s: &str) -> bool; }
/// connect's endpoint id: 64 lowercase hex.
#[derive(Clone, Debug, PartialEq, Eq, Hash, Serialize, Deserialize)] #[serde(transparent)]
pub struct EndpointId(pub String);
impl EndpointId { pub fn parse(s: &str) -> Option<EndpointId>; }
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)] #[serde(rename_all = "lowercase")]
pub enum Role { Hub, Limb }
/// connect's peer status.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)] #[serde(rename_all = "lowercase")]
pub enum Reach { Direct, Relayed, Offline }
/// What a device says about itself at pairing (connect's `payload`, ≤ 1024 B serialized).
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)] #[serde(rename_all = "camelCase")]
pub struct Hello { pub role: Role, pub platform: String, pub app_version: String, #[serde(default)] pub wake: Vec<String> /* MAC addresses "aa:bb:cc:dd:ee:ff", hub only */ }
#[derive(Clone, Debug, PartialEq)]
pub enum MeshEvent { Online { device: DeviceId, reach: Reach }, Offline { device: DeviceId }, Paired { device: DeviceId }, Revoked { device: DeviceId } }
/// A pairing the hub offers (HB-18).
#[derive(Clone, Debug)]
pub struct PairOffer { pub uri: String, pub code: String, pub expires_at: Ms, pub qr_text: String, pub qr_svg: String }
pub const PAIR_SCHEME: &str = "alexia-pair:1";
pub const LINK_PATH: &str = "/alexia/mcp/1";        // limb operation, POST, duplex ndjson
pub const OP_KILL: &str = "/alexia/kill/1";         // hub operation, POST {}
pub const OP_PRESENCE: &str = "/alexia/presence/1"; // hub operation, POST {"idleMs","locked"}
pub const OP_FACE: &str = "/alexia/face/1";         // hub operation, POST {"text","replyTo"?,"data"?}
pub const KEEPALIVE_MS: u64 = 5_000;
pub const KEYCHAIN_HUB: &str = "dev.alexia.hub.mesh";
pub const KEYCHAIN_LIMB: &str = "dev.alexia.limb.mesh";
```
`src/error.rs`: `pub enum Error { Connect(String), Refused(String), Unreachable, NotPaired, Store(#[from] alexia_store::Error), Io(#[from] std::io::Error), Bad(String) }`, `pub type Result<T>`.

## Steps
1. Create the crate (licence header on every file, `[lints] workspace = true`).
2. Types and errors as above; the eight stub modules declared `pub mod` in `lib.rs`.
3. Limb `Cargo.toml`; `main.rs` stays `fn main() {}` (P4-09 fills it).
4. `cargo build -p alexia-mesh -p alexia-limb`; commit the new `Cargo.lock`.
5. Update `invariants.mjs`; `--self-test` must still pass.

`hello_round_trips_and_fits_1024`, `role_and_reach_serde_lowercase`.
