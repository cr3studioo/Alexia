# P4-26: screen-ink: draws on screen, her cursor

Model: sonnet
Depends on: P4-15
Feature IDs: PC-20, PC-01 (the overlay)

## Goal
Alexia can point at things on the owner's screen: a box around a button, an arrow, a short label,
and her own cursor (a coloured dot with her name) where she is about to act, on a transparent
always-on-top layer that never takes a click. The `computer` plugin uses `cursor.show` (P4-28) so
the owner sees what she does without losing their own pointer.

## Touch only these paths
- `plugins/screen-ink/**`

## Must not touch
`plugins/computer/**`, other plugins, any crate, `pnpm-lock.yaml`.

## Interfaces
`screen.draw {shapes:[{kind:"box"|"arrow"|"text"|"dot", x, y, w?, h?, to?:{x,y}, text?, color?}], ttl_ms?<=60000 (default 8000)}` → `{drawn}`;
`screen.clear {}`; `cursor.show {x, y, label?:"Alexia"}` (moves her cursor with a 150 ms glide; hidden after 3 s idle).
Coordinates are screen pixels (the same space `computer.screenshot` reports).
Windows: one long-lived PowerShell process hosting a WPF window (`AllowsTransparency`,
`Topmost`, `WS_EX_TRANSPARENT | WS_EX_LAYERED | WS_EX_TOOLWINDOW` via `SetWindowLong`), fed draw
commands as JSON lines on stdin, spanning the virtual screen, DPI-aware. macOS: a JXA process
with an `NSWindow` at `NSScreenSaverWindowLevel`, `ignoresMouseEvents = true`, clear background.
The overlay process starts on first use and exits after 60 s with nothing drawn.

## Tests
`test/ink.test.js` (overlay process faked): `shapes_validated`, `ttl_capped`, `commands_are_json_lines`,
`overlay_exits_when_idle` (fake clock), `cursor_glide_steps`; live gated (`ALEXIA_LIVE=1`: draw a box for 2 s).
