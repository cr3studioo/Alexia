# P4-39: Kill switch from any device; local-only and guest commands

Model: opus
Depends on: P4-37, P4-34, P4-33, P4-36
Feature IDs: TR-07, TR-10, TR-11

## Goal
One word stops everything, from anywhere: `/kill` on Telegram or in the window, `alexia-hub kill`
on the PC, `alexia-limb kill` on the Mac. Every run stops, the scheduler pauses, every plugin on
every device is held, the Mac's fallback stops, and nothing starts again until the owner says
`/resume`. The same task adds the owner's switches for local-only (`/localonly on|off`) and guests
(`/guest add|list|remove`), and the Mac's `alexia-limb secret set` for fallback keys.

## Touch only these paths
- `v3/crates/alexia-hub/src/kill.rs`   (create)
- `v3/crates/alexia-hub/src/main.rs`   (change: `kill`, `resume`, `localonly`, `guest` subcommands; one wiring line)
- `v3/crates/alexia-hub/tests/kill.rs`   (create)
- `v3/crates/alexia-core/src/commands.rs`   (change: `/kill`, `/resume`, `/localonly`, `/guest`)
- `v3/crates/alexia-limb/src/cli.rs`   (change: `kill`, `secret set|clear <key>`)

## Must not touch
`agent.rs`, `permissions.rs`, `gateway.rs`, other limb files, other crates.

## Interfaces
- kv `_core`/`killed` = `{"at": Ms, "from": "<face>"}`; absent = not killed.
- `kill::kill(parts, from)`: set the flag; cancel every running run (the agent's run registry /
  cancellation tokens); `scheduler.pause()`; `host.hold(all plugin ids, including device servers)` (holding a
  device server closes its link, so nothing more is called on that device; the limb's own plugins
  stop when idle); publish `Event::Killed { at }` (new bus variant, allowed by §4's rule). Must finish within 2 s
  and needs no model call.
- `kill::resume(parts)`: clear the flag, `host.release()`, `scheduler.resume()`, `Event::Resumed`.
  Only from an owner face (never a guest, never the scheduler).
- At start, a set `killed` flag keeps the hub killed (resume is explicit).
- Limb `kill`: `send_op(hub, Kill)`; also locally stops the fallback brain and holds the limb's
  plugins; prints "Stopped. Say /resume to Alexia to start again." If the hub is unreachable it
  stops locally and says so.
- `/localonly on|off`: kv `_core`/`local_only`; on: hold plugins whose manifest `requires`
  `net.request` or `net.download`, pause Telegram after one message "Local-only is on: I'll stop
  using Telegram until you turn it off from this PC's window or `alexia-hub localonly off`."
  Off: release, resume.
- `/guest add <name>` → a 4-word code (from `alexia_mesh`-independent word list in commands.rs
  or a random 8-char code) shown once: "Ask <name> to send this to @<bot>: <code>". `list`,
  `remove <id>`.
- Limb `secret set <key>`: read without echo (as the hub does), store in this Mac's keychain
  under the hub's naming; allowed keys: `_core.telegram_bot_token`, `provider_<id>`.
