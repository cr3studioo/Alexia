## Goal
After this task every table and button on the board works on the hub: the core lists (chats,
models, routing, activity, last run, skills, learned skills, tools, library), their details and
their actions (new/open/forget chat, use a model, automatic, export or open a run, allow or
forget a skill), every plugin panel's `table` rows/detail and `action`/`rowActions` buttons, and
the "Learn this" offer after a task. INVENTORY B1–B4.

## Interfaces
- `POST /api/rows {plugin, key}` and `POST /api/detail {plugin, key, row}` → serve.ts
  3093–3168. `plugin == ""`: the core sources of v2 `surface.ts` `sources` (lines 344–880) on
  v3 data: `chats` (store `sessions`), `models` (`Catalog` rows, pins, `answered` counts from the
  ledger; v2 columns, `price` always free), `routing` (router order/pins), `activity` (store
  `runs` + `audit`, P2-19), `last_run`, `skills` (`Skills` with provenance and live state),
  `learned`, `tools` (`McpTooling::list`), `library` (P2D-08's rows are not needed here: v2
  reads the library cache; answer `{rows: []}` with v2's `note` when none is cached).
  A plugin: call the tool named by the widget's `rows`/`detail` key through `api.parts.tooling`
  with `Origin::Window`, as v2 does.
- `POST /api/action {plugin, key, row, approved}` → serve.ts 3024–3091. Core actions as v2
  `surface.ts` `actions` (1230–1297): `new_chat`, `open_chat` (`api.set_session`), `forget_chat`
  (refused for the open one, v2's sentence), `use_model` and `automatic` (router pins, as
  `alexia-hub models use`), `set_order`, `set_keyless`, `set_speed` (kv as v2), `set_spend` and
  `set_cross` (refused, D-P2D-6), `export_run` (the run as text, `trace` replay),
  `open_run_chat`, `allow_skill`/`allow_here`, `forget_skill`/`forget_here`. Plugin actions: the
  tool through the same permission gate as an agent call (`permissions::rule` with the tool's
  annotations and `reviewed`); a `Ruling::Ask` answers v2's `{ok:false, confirm:true, said}` and
  a repeat with `approved: true` runs it.
- `POST /api/learn {action, name, text}` → serve.ts 2837–2906: accept the pending lesson
  (`distil` through `api.parts.router` with the free models, then `save` into
  `layout.skills()`), `edit`, `forget`.
- `learned.rs`: `offer(..)` (P2D-01 signature) keeps the episode in `api.board` and returns
  `{about, outline}` when v2 `learnable` says yes and the session is not private; `distil`,
  `save`, `forget`, `outline` ported from v2 `learned.ts`.
