# P2D-04: State, setup and settings

Model: opus
Depends on: P2D-02
Feature IDs: SP-01, CO-02, TR-01

## Goal
After this task the window loads: `/api/state` answers everything v2's does, first run and
Settings save through `/api/setup`, and the permission, limits, adult, panels and search routes
answer in v2's shapes on the hub's own data. This is INVENTORY rows A1–A7, and it closes G4
(choosing folders Alexia may work in).

## Touch only these paths
- `v3/crates/alexia-api/src/state.rs`   (change: P2D-01's stub)
- `v3/crates/alexia-api/tests/state.rs`   (create)
- `v3/crates/alexia-hub/tests/contract/state.json`   (change: rows A1–A7 to `"answers"`)

## Must not touch
Other `alexia-api` modules (call their cross-area functions only), `lib.rs`, `Cargo.toml`,
any other crate, `packages/`.

## Interfaces
Routes (all JSON; shapes = the recorded cases):
- `GET /api/state` → serve.ts 1915–2041, key for key: `setup`, `modeTransition`
  (`local_models::transition`), `compute` (`compute::state`), `editor` (`editor::state`), `adult
  {confirmed,on}`, `layout` (kv `_core`/`layout` or `null`), `channels` (count of enabled plugins
  providing `channel.chat` whose declared secrets are all set), `app`, `commands`, `pins`,
  `messages` (the window session's history in v2's message shape), `spent: 0`, `cap: 0`,
  `warning`, `today`, the personality chip keys from `who()` (capability `persona.in_use` /
  `persona.not_her`, resolved by capability), `cross: false`, `ceilings`, `permissions {mode,
  modes, roots, everywhere, boundaries}`, `providers[]` from `free::ladder()` with `connected` and
  `keyStored` from the hub's secrets.
- `POST /api/setup` → serve.ts 2215–2360: `name` (≤ v2's `NAME_LONGEST`), `mode`, `theme`,
  `glass`, `glassLook`, `updates`, `layout`, `provider {id, key?, remove?}` (key into Credential
  Manager as `provider_<id>`, never echoed), answers as v2.
- `POST /api/permissions` → serve.ts 2446–2465: writes kv `_core`/`scope` in the shape
  `alexia_core::permissions` reads; `lift` clears `_core`/`boundaries`.
- `POST /api/ceilings` → serve.ts 2467–2503 (`steps`, `askAbove`; `daily > 0` refused, D-P2D-6).
- `POST /api/adult` → serve.ts 2045–2060 (kv `_core`/`adult`; off also clears the `uncensored` pin).
- `GET /api/panels` → `{tabs}` from v2 `panels.ts` `tabs({store})`, ported as a table.
- `GET /api/search?q=` → `{hits}`: v2 `palette.ts` `search` over `surface.ts` `searchable`
  (core tabs + plugin panes' labels), ported.

## Steps
1. Read each v2 handler and the helpers it calls (`setup()`, `who()`, `limitsNow()`,
   `connected()`, `keyedProviders()`, `commands()`, `pins()`, `today()`, `warning()`).
2. Port into `state.rs`, reading the same kv keys v2 wrote (the importer kept them, INTERFACES
   §6); where v3 already owns a key (`_core.scope`, `_core.display_name`), use v3's reader.
3. Flip A1–A7 in `state.json`; add cases for any shape branch you find that has none.
