## Goal
After this task there is a written, reproducible record that the app built from
`cr3studioo/v3` opens on this Windows 11 PC, runs only `alexia-hub` behind it, answers every
screen, does the PC actions, and shares its brain with Telegram. It is the phase's done-when 1,
3 and 4, checked on the real thing rather than in a test harness.

## Touch only these paths
- `v3/ops/reports/P2D-e2e.md`   (create)
- `v3/ops/reports/p2d-e2e.ps1`   (create: the script that runs the checks below and prints each result)

## Must not touch
Every source file. If a check fails, report it with evidence; do not fix it here.

## Interfaces
`p2d-e2e.ps1` (Windows PowerShell 5.1, no modules beyond the box):
1. **Build**: `pnpm install --frozen-lockfile`, `pnpm sidecar`, `pnpm tauri build --no-bundle`
   (or `pnpm app` if `--no-bundle` is unavailable; then use the exe, not the installer).
   Record the commit (`git rev-parse HEAD`) and build times.
2. **Before**: stop any v2 Alexia (`alexia.exe` from `%LOCALAPPDATA%\Alexia`) and note whether a
   hub is running (console or Task Scheduler) and on which port (`window.json`).
3. **Open**: start `src-tauri\target\release\alexia.exe`. Within 60 s: `window.json` exists and
   its port answers `GET /` with the page. Process check with `Get-CimInstance Win32_Process`:
   exactly one `alexia-hub.exe`; no `node.exe`/`alexia-core.exe` whose command line contains
   `boot.mjs` or `packages\core`; plugin `node.exe` processes are children of the hub.
4. **Every screen**: with the token read from the page (as P2D-02's `common::window` does), call
   one case per INVENTORY row against the live hub (reuse the contract cases'
   requests; skip destructive ones: `forget_chat`, plugin delete, model remove, library install,
   role switch, unpair, `/api/file` open) and record status and shape match. Print a table of
   row → pass/fail/skipped(reason).
5. **PC actions**: run `cargo test -p alexia-hub --features pc-actions --test pc_actions --
   --nocapture` (its own scratch hub, so it does not disturb the app's), and record the output.
6. **One brain**: send one Telegram message to the owner's bot through the Bot API is **not**
   done by the script (it would need the bot token). Instead, the script prints the line asking
   the owner to send "p2d ping" on Telegram, waits up to 5 minutes for `alexia-hub activity
   --last 5` or the store's newest Telegram turn to show it, and records whether the same hub pid
   answered it. If the owner does not answer within 5 minutes, record "not observed" and move on.
7. **Attach**: quit the app (tray Quit via `Stop-Process` on the shell only), start a hub from a
   console, start the app again: still exactly one `alexia-hub.exe`, same pid as the console's.
7b. **Start again** (T4, added by the CEO after P2D-14): with the app open, stop only the hub
   process the app started (by its pid), and record what the app shows. Then press its
   "Start again" button (via UI Automation on the app's own window only, found by its pid) and
   record that a new `alexia-hub.exe` starts and `window.json` answers again. If the button cannot
   be pressed through UI Automation, record that and the screen state as evidence.
8. **After**: leave the owner's environment as found (stop what the script started; do not
   install, do not change settings in `%LOCALAPPDATA%\AlexiaHub` except what the screens' GETs
   read).

`P2D-e2e.md`: date, commit, machine (Windows build, RAM, GPU from `nvidia-smi
--query-gpu=name,memory.total --format=csv`), each step's result, the screen table, the
pc_actions output summary, failures with evidence, and what the owner must still do (PHASE.md
*Owner needs*).

## Notes for the worker
- Hard rules: never install over the owner's v2 app, never run `alexia-hub install`, never
  release, never touch `main`. The unbundled exe is enough.
- Do not use the owner's keychain or bot token in the script; reads of the live hub go through
  the window API with the page's token only.
- If the build fails for lack of a tool (WebView2 SDK, MSVC, NSIS), record exactly what is
  missing; that is a finding for item 6 of the phase brief.
- 16 GB RAM: do not run this while other workers compile.
- PC safety (P2D-12, P2D-16..18): never type into, click in, focus or close a window you did not
  open; close only processes you started, by pid. Never use Notepad (it reopens the owner's
  unsaved tabs). pc_actions uses Character Map; leave it that way.
