# P2D-01: alexia-api: server, gate, static shell, hub wiring, INTERFACES

Model: opus
Depends on: P2-39
Feature IDs: SP-01, CO-02

## Goal
After this task `alexia-hub run` serves the v2 window: `packages/ui` from a loopback port with
the token injected, every `/api/*` call checked exactly as v2 checks it (token, Host, JSON body,
the guard), and every INVENTORY route registered, answering a stub until its area task lands.
It creates the `alexia-api` crate with one module per screen so the area tasks never share a
file, takes the one-hub lock, writes `window.json`, and writes every P2D interface into
INTERFACES.md, including the ones P2D-03 implements.

Every stub handler answers `501 {"ok":false,"said":"This part of Alexia is not on the hub yet."}`.
Each `*State` is `#[derive(Default)] pub(crate) struct XState {}` in its module.

Hub (`main.rs`):
- Step 12 (after step 11): build `ApiParts`, `Api::new`, bind
  `tokio::net::TcpListener::bind(("127.0.0.1", port))` where `port` is `ALEXIA_WINDOW_PORT`
  (u16) or 0, write `<data>/window.json` = `{"port":<bound port>,"pid":<std::process::id()>}`
  atomically (write `.tmp`, rename), spawn `api.serve(listener, root.child_token())` under the
  tracker, delete `window.json` on shutdown.
- Before step 1: open `<data>/hub.lock` with `share_mode(0)` (Windows,
  `std::os::windows::fs::OpenOptionsExt`) and keep it for the process; on a sharing violation,
  exit 1 with `Another Alexia hub is already running on this computer.` Off Windows: keep the
  handle; a lock failure is ignored (tests on CI).
- `ALEXIA_UI_DIR`: absolute path of the folder holding `index.html`; unset → `ui_dir: None`.

Static shell (`statics.rs`), exactly serve.ts 272–298 and 1859–1872: the same path table plus
`^/([a-z][a-z0-9-]*)\.js$` → `dist/src/<name>.js`; `text/*` assets get the first `__TOKEN__`
replaced by the token; others are bytes. A missing file falls through to the API rules. With
`ui_dir: None`, `/` answers `503 text/plain "The window's files were not found. Set ALEXIA_UI_DIR."`.

Gate (`gate.rs`), in this order, for every path not answered as a static asset:
1. `x-alexia-token` ≠ token, or `Host` not starting `127.0.0.1` → `403 text/plain "not for you"`.
2. Non-GET/HEAD body: parse JSON; failure → `400 {"ok":false,"said":"That request body is not JSON."}`;
   an empty body is `{}`; a non-object is `{}`.
3. `guard.ts` `refuse(path, method, body)` ported exactly: the `ROUTES` table (guard.ts 100–437)
   with each route's `otherwise`/per-action rules and sentences, the `/api/local-models/<id>`
   fallback (line 440), and its result as `{"ok":false,"said":..,"confirm":true?}` with its status.
   A path in no row is refused as guard.ts refuses it.
4. Dispatch; no match → `404`, empty body.
Body limit: 64 MiB (`DefaultBodyLimit`).

## Steps
1. Write the INTERFACES.md additions (PHASE.md *INTERFACES.md additions*), copying P2D-03's
   types from `P2D-03.md` *Interfaces* word for word. Commit that first.
2. Create the crate, `json.rs`, `statics.rs`, `gate.rs` (port guard.ts; keep its sentences).
3. Create every area module as a stub with `routes()` registering every INVENTORY row of that
   area (path + method) to the 501 stub, its `*State`, and the cross-area stubs above.
   `chat::routes` registers `POST /api/chat`; `local_models::routes` registers
   `DELETE /api/local-models/{id}`.
4. Hub wiring (lock, step 12, `window.json`, `Arc<Skills>` kept: `let skills = Arc::new(skills);
   tooling.add_builtin(skills.clone())`). The window's questions are not wired here: P2D-05
   swaps `Asker::new` for `Asker::with_window` and reads them back with `Asker::window()`.
5. Tests.

## Notes for the worker
- v2's server: `packages/core/src/serve.ts` 1842–1914 (the request path), 272–298 (STATIC);
  `packages/core/src/guard.ts` (the whole file). Keep every sentence as v2 has it.
- The token never goes to `tracing`, `window.json` or an error message.
- The invariant: no route names a plugin. Screens that serve a plugin (editor, research) find it
  by capability or widget type, never by id.
- Windows: `share_mode(0)` makes a second `CreateFile` fail with `ERROR_SHARING_VIOLATION` (32).
  Bind `127.0.0.1`, never `0.0.0.0` or `localhost` (no firewall prompt, no IPv6 surprise).
