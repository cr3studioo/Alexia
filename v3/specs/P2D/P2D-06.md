# P2D-06: Plugins screen: panes, settings, trust, install, servers

Model: opus
Depends on: P2D-02
Feature IDs: SP-01, EX-12, TR-03

## Goal
After this task the Plugins and Settings screens show every plugin the hub runs, with its
settings, status widgets, problems and skills, and the owner can enable, disable, delete,
restart and trust a plugin, change its settings (including `password` ones, into Credential
Manager), upload a file setting, install a plugin folder and add an MCP server. INVENTORY P1–P7;
closes G2 (the computer plugin's `allow_input`) and G3 (trust).

## Interfaces
```rust
// alexia-mcp host.rs (new)
impl McpHost {
    /// Copies a plugin folder into the extensions dir, validates its manifest, scans it in
    /// disabled. Err with v2's sentence when the manifest is refused or the id exists.
    pub async fn install_folder(&self, from: &Path) -> Result<PluginId, Error>;
    /// An MCP server that is not a plugin folder (v2 `servers.ts` `addServer`): kv
    /// `_core`/`servers` [{id,name,run,args}], hosted like a plugin with no manifest extras,
    /// unreviewed until trusted.
    pub async fn add_server(&self, id: &str, name: &str, run: &str, args: &[String]) -> Result<PluginId, Error>;
    pub fn servers(&self) -> Vec<ServerEntry>;
}
#[derive(Clone, Debug, serde::Serialize, serde::Deserialize)]
pub struct ServerEntry { pub id: String, pub name: String, pub run: String, pub args: Vec<String> }
```
Routes (shapes = the recorded cases):
- `GET /api/plugins` → `{panes, problems, skills, unreviewed, offers, skillProblems}` (serve.ts
  2534–2547; `panes` as v2 `plugins.ts` `panes()`: per plugin its manifest summary, state,
  settings with current values (`password` values never sent: v2's `set: bool`), panel widgets,
  `status` widgets' text).
- `POST /api/plugin {id, action}` → serve.ts 2599–2627 (`enable`, `disable`, `delete` = purge,
  `restart`); enabled list persisted to kv `_core`/`enabled` as the hub reads it.
- `POST /api/install {path}` → serve.ts 2629–2641.
- `POST /api/server {id,name,run,args,action}` → serve.ts 2789–2835; `trust` →
  `McpHost::set_reviewed(id, true)`.
- `POST /api/settings {plugin,key,value}` → serve.ts 2908–2934: validated against the manifest
  (type, min/max, options), stored with `Store::set_setting`, `password` into Credential Manager
  as `<plugin>.<key>` (P2-48's naming), then `alexia/settings/changed` to the plugin.
- `POST /api/upload {plugin,key,name,data}` → serve.ts 2936–2980 (`file` setting; bytes into
  the plugin's own dir).
- `GET /api/plugin-file?plugin=&path=` → serve.ts 3199–3229 (realpath inside the plugin's own
  dir, else 403/404 as v2).
