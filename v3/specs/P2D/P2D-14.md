# P2D-14: Coverage and loopback checks

Model: sonnet
Depends on: P2D-04, P2D-05, P2D-06, P2D-07, P2D-08, P2D-09, P2D-10, P2D-11, P2D-12, P2D-13
Feature IDs: none

## Goal
After this task CI fails if the hub stops answering any INVENTORY row (a row with no contract
case, or a case still pending) or if the window API is ever bound to anything but `127.0.0.1`.
These two checks are what keep P2D's done-when true after the phase.

## Touch only these paths
- `v3/ci/invariants.mjs`   (change: checks 12 and 13, their `--self-test` lines, the header comment)
- `v3/crates/alexia-hub/tests/contract/gate.json`   (change: only to flip T4 once P2D-13's check is recorded, see Steps)

## Must not touch
Every crate's `src/`, other contract files, `v3/specs/`, `packages/`, `src-tauri/`.

## Interfaces
- **Check 12, INVENTORY coverage.** Read `v3/specs/P2D/INVENTORY.md`; collect row ids from the
  first cell of every table row matching `^\| (S|A|C|P|B|L|M|R|E)\d+ \|` plus `T4`. Read every
  `v3/crates/alexia-hub/tests/contract/*.json`. Hit for each id with no case, and for each case
  with `"hub": "pending"`. Message: `INVENTORY <id>: no contract case` /
  `contract <file> <row> "<name>": still pending`.
- **Check 13, loopback only.** In `v3/crates/*/src/**/*.rs`, a hit for any line containing
  `0.0.0.0`, `[::]`, `"::"` or `"localhost"` used in a bind, and for any `TcpListener::bind(`
  whose argument does not contain `127.0.0.1` or `Ipv4Addr::LOCALHOST` on the same line.
  Comment lines are skipped as for the other checks.
- `--self-test` gains one planted hit and one clean case for each.

## Steps
1. Add the checks. Run them; fix nothing in other paths: report any hit to the coordinator.
2. T4 (`start-core-again`) is a shell event, not an HTTP call: flip its `gate.json` case to
   `"answers"` with `"source": "hand"` and `"from": "P2D-13 report"` once P2D-13's report shows
   the restart/re-attach observed; otherwise leave it pending and say so.

## Tests
- `node v3/ci/invariants.mjs --self-test` proves both checks catch their planted violations.

## Done when
- cargo fmt --all --check passes in v3/
- cargo clippy --workspace --all-targets -- -D warnings passes in v3/
- cargo test --workspace passes in v3/
- `node v3/ci/invariants.mjs` prints `invariants: ok`
- `node v3/ci/invariants.mjs --self-test` passes
