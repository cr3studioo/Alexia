# P2D-18: Computer plugin: after opening a page, target the browser only once it is in front

Model: opus
Depends on: P2D-17
Feature IDs: none (owner A-19 item 5)

## Goal
P2D-17's review found that a plan's `open_url` step (plugins/computer/task.js `following().openUrl`,
around line 231) takes `desktop.front()` straight after the page opens and makes that window the
typing target. If the browser is not in front yet, the target becomes whatever window is in front
(for example the owner's own app), and the guard then ACCEPTS typing into it. After this task, an
`open_url` step only re-targets to a window that came to the front because of the open, and when it
cannot tell, later typing is refused, never sent to an unknown window.

plugins/computer/macos.js.

## Interfaces
- Before opening, read `front()` (pid A). After opening, poll `front()` for up to 5 s (every
  250 ms, honouring the abort signal) until the front pid differs from A; that pid becomes the
  target.
- If it never changes: when A is already a browser window the page opened in (A's process name is
  a known browser: msedge, chrome, firefox, brave, opera, vivaldi, arc, safari), target A;
  otherwise set the target to a state the guard REFUSES (not "no pid", which means unguarded).
  Add that refuse state explicitly if it does not exist (for example a pid of -1 that never
  matches, with the guard's refusal sentence).
- The step that ends with the refuse state says so in plain words in the plan's progress:
  "The page opened, but I could not tell which window it is in, so I will not type into it."

## Steps
1. Read P2D-17's report and task.js `following`.
2. Implement the poll and the fallback above, in every place that re-targets after open_url.
3. Tests with a fake desktop: front changes after a delay (targets the new pid); front never
   changes and A is a browser (targets A); front never changes and A is not a browser (later type
   is refused, nothing sent); abort during the poll stops it.

## Tests
- `open_url waits for the browser to come to the front`
- `open_url into the browser already in front keeps it`
- `open_url that brings nothing forward refuses later typing`
- `open_url polling stops on abort`
