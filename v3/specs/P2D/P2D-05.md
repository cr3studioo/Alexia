# P2D-05: Chat in the window: stream, stop, approve, commands, files

Model: opus
Depends on: P2D-02, P2D-03
Feature IDs: SP-01, TR-01, AC-10

## Goal
After this task the owner chats in the window with the same brain Telegram uses. `/api/chat`
streams v2's SSE frames from a turn run by the hub's `Lanes` with `Origin::Window`; tool steps,
progress (with the plan for the pill), notes and Allow/Deny questions appear as in v2; Stop and
Approve work; slash commands run; files a tool made can be downloaded, opened or shown in
Explorer; "That wasn't her" reaches the persona capability. INVENTORY C1–C7, closes G5 and G7.

## Interfaces
- `POST /api/chat` body as v2 `reply(sent)` reads it (serve.ts 3577–3700: `text`, `uploads`,
  `private`, …). Refused with `423 {"ok":false,"busy":true,"said":..}` when `api.busy()`,
  `local_models::busy(api)` or a window run is live (v2's two sentences). Else `200
  text/event-stream`, `cache-control: no-store`, frames `data: <json>\n\n`:
  `{"delta":s}`, `{"restart":true}`, `{"phase":{..}}` (v2's phase names for `Phase`),
  `{"note":s}`, `{"ask":s}`, `{"switch":{..}}` (router fallback, if `Router` reports one),
  `{"step":{"n","name","args"}}`, `{"step":{"n","name","progress":ToolProgress}}`,
  `{"step":{"n","name","text","ok","files":[{id,name,mime,openable}]}}`, `{"learned":name}`,
  `{"learn":{about,outline}}` (when `learned::offer` returns `Some`), `{"error":s}`,
  `{"done":{"model","bubble"?,"spent":0,"cap":0,"today","warning","steps","ended"}}`.
  Never `paid` or `paused` (D-P2D-6).
- The turn: `Turn` with `origin: Origin::Window`, `session: api.session()`, the uploads as
  `InFile`s saved under `layout` uploads (v2 `attach.ts` limits `MOST_FILES`, `MOST_PER_FILE`,
  `MOST_TOGETHER`, same sentences); `WindowQuestions::attach(run, tx)` for the run, `detach` at
  the end. The brain is `api.parts.brain`; the window's frames come from its `DraftFrame`s.
- `POST /api/stop` → `{"stopping":bool}`: cancels the window's run, `WindowQuestions::cancel_open`.
- `POST /api/approve {allowed}` → `{"ok":bool}` via `WindowQuestions::answer`.
- `POST /api/command {input, approved}` → serve.ts 2396–2445, through `commands::run` with
  `Origin::Window`; `new_chat` changes `api.set_session`.
- `POST /api/not-her {said}` → serve.ts 2982–3022, capability `persona.not_her`.
- `offers.rs`: `Offers::keep(&self, files: &[Produced]) -> Vec<Value>` gives each file a random
  id (in memory, as v2 `Offers`), `get(id) -> Option<Offer>`.
- `GET /api/file?id=` → bytes, v2's headers (serve.ts 3231–3262); `410` if gone, `404` unknown.
- `POST /api/file {id, action}` → `open` refused `409` for files that run when opened (v2
  `openable`: same extension list); else `explorer.exe <path>` or `explorer.exe /select,<path>`,
  detached, `CREATE_NO_WINDOW` not set (Explorer must show), answer `{"ok":true}`.

## Steps
1. Port `reply` (serve.ts 3577–3975) minus paid/pause/preview-cost branches; keep the order of
   frames and every sentence.
2. Map `DraftFrame` → frames; offers for outcome files; after an answered turn call
   `crate::learned::offer` (P2D-07 fills it; P2D-01's stub returns `None`).
3. Stop, approve, command, not-her, file routes. Hub: the `with_window` line.
4. After an answered window turn, hand the exchange to capabilities `memory.capture` and
   `reply.finished` as v2 does (fire and forget), unless the session is private.
