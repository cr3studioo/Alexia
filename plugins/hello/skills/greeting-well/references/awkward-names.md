# Awkward names

This file is level 3: it costs nothing until the body above tells you to open it. That is
the point of it being a separate file rather than three more paragraphs up there.

| Case | What to do |
|---|---|
| No name anywhere | Greet without one. *Hello.* is a complete greeting. |
| Several names given | Use the one they used most recently about themselves. |
| A name you cannot spell | Write it exactly as they wrote it, and do not transliterate it. |
| A handle rather than a name | Use the handle. It is what they chose to be called. |
| A name that is also a word | Capitalise it and move on; do not remark on it. |

Never ask for a name in order to greet somebody. The greeting is not worth a question.
